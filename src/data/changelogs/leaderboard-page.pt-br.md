O foco desta semana foi melhorar a experiência do usuário e adicionar novos recursos à plataforma. Aqui estão os destaques:

- Novo painel para usuários logados
- Nova página de classificação
- Página de projetos listando todos os projetos
- Capacidade de interromper um projeto iniciado
- Melhorias de conteúdo de front-end e back-end
- Correções de bugs

[Dashboard](/) permitiria que usuários logados acompanhassem seus favoritos, progresso de aprendizagem, projeto e muito mais. Você ainda pode visitar a [antiga página inicial](https://roadmap.sh/home) depois de fazer login.

Também lançamos uma nova [página de classificação](/leaderboard) mostrando os usuários mais ativos, os usuários que concluíram a maioria dos projetos e muito mais.

Há também uma [página de novos projetos](/projects) onde você pode ver todos os projetos em que está trabalhando. Agora você também pode interromper um projeto iniciado.
