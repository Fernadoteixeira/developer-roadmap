# Testes Não Funcionais

O teste não funcional é um tipo de teste de software para testar parâmetros não funcionais, como confiabilidade, teste de carga, desempenho e responsabilidade do software. O objetivo principal dos testes não funcionais é testar a velocidade de leitura do sistema de software de acordo com parâmetros não funcionais. Os parâmetros dos testes não funcionais nunca são testados antes dos testes funcionais.
