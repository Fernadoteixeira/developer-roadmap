# YouTrack

YouTrack é um software de gerenciamento de projetos desenvolvido pela JetBrains. Está na forma de um plugin que pode ser anexado aos IDEs JetBrains, como o Intellij Idea, e ajuda a criar e atribuir tarefas a uma equipe de desenvolvimento, bem como acompanhar o andamento do trabalho.

Visite os seguintes recursos para saber mais:

- [@oficial@YouTrack](https://www.jetbrains.com/youtrack/)
