# Automação de back-end

O teste de back-end é um método de teste que verifica o lado do servidor ou banco de dados de aplicativos ou software da web. O teste de back-end visa testar a camada de aplicativo ou de banco de dados para garantir que o aplicativo da web ou software esteja livre de defeitos de banco de dados, como impasse, corrupção de dados ou perda de dados.
