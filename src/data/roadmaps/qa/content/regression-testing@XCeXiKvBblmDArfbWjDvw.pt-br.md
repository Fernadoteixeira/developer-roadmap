# Teste de regressão

O teste de regressão é um tipo de teste de software para confirmar se um programa recente ou alteração de código não afetou negativamente os recursos existentes. O teste de regressão é uma técnica de teste de caixa preta. Os casos de teste são executados novamente para verificar se a funcionalidade anterior do aplicativo está funcionando bem e se as novas alterações não produziram nenhum bug.
