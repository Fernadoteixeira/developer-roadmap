# Compatibilidade

Compatibilidade nada mais é do que a capacidade de existir ou viver juntos. Teste de compatibilidade é um tipo de teste de software para verificar se o seu software é capaz de ser executado em diferentes hardwares, sistemas operacionais, aplicativos, ambientes de rede ou dispositivos móveis.
