# XCUITeste

O teste de aplicativos móveis e, mais especificamente, o teste de interface do usuário do aplicativo, envolve verificar como a interface se comporta quando as ações do usuário são executadas e, em seguida, comparar os resultados com os resultados esperados. Aqui, os testadores tentam replicar exatamente como um usuário interagiria com o aplicativo e validariam o estado da IU. O XCUITest permite escrever casos de teste para esses fins usando dois conceitos fundamentais.
