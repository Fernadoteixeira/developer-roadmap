# CI/CD

Integração Contínua é um método de desenvolvimento de software onde os membros da equipe integram seu trabalho pelo menos uma vez ao dia. Uma compilação automatizada verifica cada integração para detectar erros neste método. Na Integração Contínua, o software é construído e testado imediatamente após a confirmação do código. Em um projeto grande com muitos desenvolvedores, os commits são feitos muitas vezes durante o dia. A cada commit, o código é construído e testado.

Entrega Contínua é um método de engenharia de software no qual uma equipe desenvolve produtos de software em um ciclo curto. Ele garante que o software possa ser facilmente lançado a qualquer momento. O principal objetivo da entrega contínua é construir, testar e lançar software com boa velocidade e frequência. Ajuda a reduzir o custo, o tempo e o risco de entrega de alterações, permitindo atualizações frequentes na produção.
