# Newman

Postman é uma plataforma API para construir e usar APIs. O Postman simplifica cada etapa do ciclo de vida da API e agiliza a colaboração para que você possa criar APIs melhores e mais rapidamente. É um cliente de API que facilita aos desenvolvedores criar, compartilhar, testar e documentar APIs. Com esta solução de código aberto, os usuários podem criar e salvar solicitações HTTP/s simples e complexas e ler suas respostas.

Newman é um Collection Runner de linha de comando para Postman. Ele permite que você execute e teste uma coleção Postman diretamente da linha de comando. Ele foi desenvolvido com extensibilidade para integrá-lo aos seus servidores de integração contínua e sistemas de construção.
