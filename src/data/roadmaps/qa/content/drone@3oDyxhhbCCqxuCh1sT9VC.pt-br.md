# Drone

Drone é um serviço CI/CD oferecido pela Harness. Cada compilação é executada em um contêiner Docker isolado e o Drone se integra a muitos repositórios populares de gerenciamento de código-fonte, como GitHub, BitBucket e GitLab

Visite os seguintes recursos para saber mais:

- [@oficial@Drone](https://www.drone.io/)
- [@official@Documentação do Drone](https://docs.drone.io/)
- [@official@Drone Guia de primeiros passos](https://docs.drone.io/server/overview/)
