# Bitbucket

Bitbucket é um serviço de hospedagem e repositório de código-fonte baseado em Git que é a alternativa da Atlassian a outros produtos como GitHub, GitLab etc.

Bitbucket oferece opções de hospedagem via Bitbucket Cloud (servidores da Atlassian), Bitbucket Server (no local do cliente) ou Bitbucket Data Center (número de servidores no cliente no local ou ambiente de nuvem)
