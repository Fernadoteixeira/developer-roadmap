# Raposa Sem Cabeça

Headless Browser Testing é um processo de execução de testes de navegador sem o tipo de UI ou GUI do navegador. No teste de navegador headless, para realizar testes entre navegadores, o testador pode executar casos de teste com precisão e sucesso, sem exigir o navegador no qual o aplicativo precisa ser testado.

Visite os seguintes recursos para saber mais:

- [@article@Usando o modo Headless no Firefox](https://hacks.mozilla.org/2017/12/using-headless-mode-in-firefox/)
