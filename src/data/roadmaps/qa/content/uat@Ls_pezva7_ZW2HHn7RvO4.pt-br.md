# UAT

O Teste de Aceitação do Usuário (UAT) é um tipo de teste realizado pelo usuário final ou cliente para verificar/aceitar o sistema de software antes de mover o aplicativo de software para o ambiente de produção. O UAT é feito na fase final de teste após a conclusão dos testes funcionais, de integração e do sistema.
