# TeamCity

TeamCity é um serviço CI/CD fornecido pela JetBrains. TeamCity pode ser usado como uma oferta SaaS ou autogerenciado usando seus próprios recursos.

Visite os seguintes recursos para saber mais:

- [@oficial@TeamCity](https://www.jetbrains.com/teamcity/)
- [@official@TeamCity Documentação ](https://www.jetbrains.com/help/teamcity/teamcity-documentation.html)
- [@article@TeamCity Tutoriais](https://www.jetbrains.com/teamcity/tutorials/)
- [@article@TeamCity Portal de aprendizagem](https://www.jetbrains.com/teamcity/learn/)
