# Teste de acessibilidade

No controle de qualidade de software, o teste de acessibilidade é a prática de confirmar se um aplicativo pode ser usado pelo maior número possível de pessoas, incluindo pessoas com deficiências, como deficiência visual, problemas auditivos e condições cognitivas.
