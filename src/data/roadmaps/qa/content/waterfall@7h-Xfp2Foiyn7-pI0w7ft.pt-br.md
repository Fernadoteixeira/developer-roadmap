# Modelo Cachoeira

O Modelo Waterfall é um modelo sequencial que divide o desenvolvimento de software em fases pré-definidas. Cada fase deve ser concluída antes que a próxima fase possa começar, sem sobreposição entre as fases. Cada fase é projetada para realizar atividades específicas durante a fase SDLC.
