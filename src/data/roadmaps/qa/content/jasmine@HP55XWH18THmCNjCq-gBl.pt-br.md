# Jasmim

Jasmine é uma estrutura JavaScript BDD (desenvolvimento orientado a comportamento) muito popular para testes unitários de aplicativos JavaScript. Ele fornece utilitários que podem ser usados ​​para executar testes automatizados para código síncrono e assíncrono. Não depende de nenhuma outra estrutura JavaScript. Não requer um DOM.
