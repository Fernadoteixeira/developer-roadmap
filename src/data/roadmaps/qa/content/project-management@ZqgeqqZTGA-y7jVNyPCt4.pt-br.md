# Gerenciamento de projetos

Um projeto é um esforço temporário para criar um produto, serviço ou resultado exclusivo. Um projeto é temporário porque tem início e fim definidos, e é único porque possui um conjunto específico de operações projetadas para atingir um objetivo.

Gerenciamento de Projetos é uma disciplina de planejamento, organização, motivação e controle dos recursos para atingir objetivos específicos do projeto. O principal objetivo do gerenciamento de projetos é atingir os objetivos e metas do projeto, tendo em mente o escopo, o tempo, a qualidade e o custo do projeto. Facilita o fluxo de trabalho do projeto com colaboração da equipe em um único projeto.
