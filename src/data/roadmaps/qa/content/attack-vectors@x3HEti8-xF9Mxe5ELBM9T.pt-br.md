# Vetores de ataque

Esta métrica reflete o contexto pelo qual a exploração de vulnerabilidades é possível. Este valor da métrica (e consequentemente a pontuação base) será maior quanto mais remoto (lógica e fisicamente) um invasor puder estar para explorar o componente vulnerável. A suposição é que o número de possíveis invasores para uma vulnerabilidade que poderia ser explorada em uma rede é maior do que o número de possíveis invasores que poderiam explorar uma vulnerabilidade que requer acesso físico a um dispositivo e, portanto, justifica uma pontuação base maior.
