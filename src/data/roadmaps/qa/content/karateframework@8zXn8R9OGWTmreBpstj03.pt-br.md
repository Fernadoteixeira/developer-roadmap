# Estrutura do Karatê

Karate é a única ferramenta de código aberto que combina automação de testes de API, simulações, testes de desempenho e até mesmo automação de UI em uma estrutura única e unificada. A sintaxe BDD popularizada pelo Cucumber é neutra em termos de linguagem e fácil até mesmo para não programadores. Asserções e relatórios HTML são integrados e você pode executar testes em paralelo para aumentar a velocidade.

Há também um executável independente de plataforma cruzada para equipes que não se sentem confortáveis ​​com Java. Você não precisa compilar código. Basta escrever testes em uma sintaxe simples e legível - cuidadosamente projetada para HTTP, JSON, GraphQL e XML. E você pode combinar automação de teste de API e UI no mesmo script de teste.

Também existe uma API Java para aqueles que preferem integrar programaticamente os ricos recursos de automação e asserção de dados do Karate.
