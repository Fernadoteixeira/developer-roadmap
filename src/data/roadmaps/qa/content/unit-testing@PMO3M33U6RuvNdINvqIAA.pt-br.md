# Teste de unidade

O teste de unidade é onde **unidades** individuais (módulos, funções/métodos, rotinas, etc.) de software são testadas para garantir sua correção. Esses testes de baixo nível garantem que os componentes menores sejam funcionalmente corretos, ao mesmo tempo que alivia a carga dos testes de nível superior. Geralmente, um desenvolvedor escreve esses testes durante o processo de desenvolvimento e eles são executados como testes automatizados.
