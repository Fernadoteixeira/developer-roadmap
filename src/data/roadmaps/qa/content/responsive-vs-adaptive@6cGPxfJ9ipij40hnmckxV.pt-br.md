# Responsivo vs adaptativo

Existem duas abordagens para garantir que um site seja otimizado para telas de celulares, tablets, laptops e PCs: design responsivo e design adaptativo. Embora ambos tenham como objetivo resolver o mesmo problema, eles usam estratégias diferentes.

# O que é design responsivo?

Um site criado com design responsivo oferece o mesmo site para todos os dispositivos, mas esse site é fluido e mudará seu layout e aparência com base no tamanho e na orientação do dispositivo.

Os desenvolvedores usam CSS para garantir que cada página do site possa ser reformatada com base no tamanho da janela de visualização do usuário e precise apenas criar uma base de código para o site. Eles usam algo chamado pontos de interrupção para informar ao site quando ajustar para acomodar diferentes tamanhos de tela.

A maioria dos novos sites agora usa responsivo, o que ficou mais fácil para designers e desenvolvedores menos experientes, graças à disponibilidade de temas acessíveis através de sistemas CMS como WordPress, Joomla e Drupal.

O design responsivo não oferece tanto controle quanto o adaptativo, mas exige muito menos trabalho de construção e manutenção. Os layouts responsivos também são fluidos e, embora os adaptativos possam usar e usem porcentagens para dar uma sensação mais fluida ao dimensionar, eles podem novamente causar um salto quando uma janela é redimensionada.

# O que é design adaptativo?

No design adaptativo, um layout de site diferente é criado para a tela de cada dispositivo. À medida que carrega, o site reconhece o tamanho da tela e exibe o layout que foi feito para aquela viewport. Na verdade, você pode criar uma experiência de usuário diferente para cada um dos seis tamanhos de tela comuns, de muito pequeno a muito grande: 320px, 480px, 760px, 960px, 1200px e 1600px.

Adaptável é útil para modernizar um site existente, a fim de torná-lo mais adequado para telefones celulares. Isso permite que você assuma o controle do design e do desenvolvimento web para múltiplas viewports específicas. O número de viewports que você escolhe projetar depende inteiramente de você, de sua empresa e de seu orçamento geral. No entanto, ele oferece um certo controle (por exemplo, sobre o conteúdo e o layout) que você não terá necessariamente ao usar um design responsivo.
