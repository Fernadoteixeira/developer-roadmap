# Ferramentas de desenvolvimento do Chrome

Trata-se de um conjunto de ferramentas integradas ao navegador para ajudar os desenvolvedores front-end a diagnosticar e resolver vários problemas em seus aplicativos - como JavaScript e bugs lógicos, problemas de estilo CSS ou até mesmo fazer alterações rápidas e temporárias no DOM.

Para entrar nas ferramentas de desenvolvimento, clique com o botão direito e clique em **Inspecionar** (ou pressione `ctrl+shift+c`/`cmd+opt+c`) para entrar no painel Elementos. Aqui você pode depurar problemas de CSS e HTML. Se você quiser ver mensagens registradas ou interagir com javascript, entre na aba **Console** das abas acima (ou pressione `ctrl+shift+j`/`cmd+opt+j` para entrar diretamente). Outro recurso muito útil nas ferramentas de desenvolvimento do Chrome é o Lighthouse (para verificar o desempenho) — falaremos mais sobre isso mais tarde.

NOTA: Este não é um recurso específico do Chrome, e a maioria dos navegadores (baseados no Chromium ou não) terá seu próprio conjunto de ferramentas de desenvolvimento bastante semelhante.
