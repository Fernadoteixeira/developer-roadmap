# Autorização de autenticação

`Authentication` é o processo de verificação de que um indivíduo, entidade ou site é quem afirma ser. A autenticação no contexto de aplicações web é comumente realizada através do envio de um nome de usuário ou ID e um ou mais itens de informações privadas que apenas um determinado usuário deve saber.

`Authorization` pode ser definido como "o processo de verificação de que uma ação ou serviço solicitado foi aprovado para uma entidade específica" (NIST). `Authorization` é diferente da autenticação, que é o processo de verificação da identidade de uma entidade. Ao projetar e desenvolver uma solução de software, é importante manter essas distinções em mente. Um usuário que foi autenticado (talvez fornecendo um nome de usuário e uma senha) muitas vezes não está autorizado a acessar todos os recursos e executar todas as ações que sejam tecnicamente possíveis através de um sistema.
