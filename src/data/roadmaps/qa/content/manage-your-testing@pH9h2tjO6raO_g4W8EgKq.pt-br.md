# Gerencie seus testes

Gerenciamento de testes é um processo de gerenciamento das atividades de teste para garantir testes de alta qualidade e de alta qualidade do aplicativo de software. O método consiste em organizar, controlar, garantir a rastreabilidade e visibilidade do processo de teste para entregar a aplicação de software de alta qualidade. Ele garante que o processo de teste de software seja executado conforme o esperado.
