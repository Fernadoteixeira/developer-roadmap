# Gerenciamento de segredos

O gerenciamento de segredos é uma forma sistemática de gerenciar, armazenar, proteger e recuperar credenciais para qualquer sistema, banco de dados e outros serviços. Credenciais como senhas, chaves SSH, certificados, chaves de API, códigos de backup e muito mais.
