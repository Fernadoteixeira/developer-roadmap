# TDD - Desenvolvimento Orientado a Testes

Test Driven Development (TDD) é uma abordagem de desenvolvimento de software na qual casos de teste são desenvolvidos para especificar e validar o que o código fará. Em termos simples, os casos de teste para cada funcionalidade são criados e testados primeiro e se o teste falhar, o novo código é escrito para passar no teste e tornar o código simples e livre de erros.
