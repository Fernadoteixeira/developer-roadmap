# Devtools do navegador

Todo navegador moderno inclui um poderoso conjunto de ferramentas de desenvolvedor. Essas ferramentas fazem uma série de coisas, desde inspecionar HTML, CSS e JavaScript carregados no momento até mostrar quais ativos a página solicitou e quanto tempo levaram para carregar. Este artigo explica como usar as funções básicas das ferramentas de desenvolvimento do seu navegador.
