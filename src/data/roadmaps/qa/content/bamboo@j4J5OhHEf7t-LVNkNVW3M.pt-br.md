# Bambu

Bamboo é um serviço CI/CD fornecido pela Atlassian. O Bamboo é usado principalmente para automatizar compilações, testes e lançamentos em um único fluxo de trabalho.

Visite os seguintes recursos para saber mais:

- [@oficial@Bambu](https://www.atlassian.com/software/bamboo)
- [@oficial@Documentação de Bambu](https://confluence.atlassian.com/bamboo/bamboo-documentation-289276551.html)
- [@article@Bamboo Guia de primeiros passos](https://confluence.atlassian.com/bamboo/getting-started-with-bamboo-289277283.html)
