# Teste de Sanidade

O teste de sanidade é um tipo de teste de software realizado após o recebimento de uma construção de software, com pequenas alterações no código ou funcionalidade, para verificar se os bugs foram corrigidos e se nenhum outro problema foi introduzido devido a essas alterações. O objetivo é determinar se a funcionalidade proposta funciona aproximadamente conforme o esperado. Se o teste de integridade falhar, a construção será rejeitada para economizar tempo e custos envolvidos em testes mais rigorosos.
