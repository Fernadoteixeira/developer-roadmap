# Inspetor Fantasma

Ghost Inspector é uma ferramenta de teste automatizado sem código que permite criar e executar facilmente testes automatizados de navegador para sites e aplicativos da web. Esses testes realizam ações em um navegador da mesma forma que um usuário real faria para garantir que tudo está funcionando corretamente.
