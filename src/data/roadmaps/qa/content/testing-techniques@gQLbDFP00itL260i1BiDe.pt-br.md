# Técnicas de Teste

Técnicas de Teste são métodos aplicados para avaliar um sistema ou componente com o objetivo de verificar se ele atende aos requisitos determinados. O teste de um sistema ajuda a identificar lacunas, erros ou qualquer tipo de requisito ausente que seja diferente dos requisitos reais. Essas técnicas garantem a qualidade geral do produto ou software, incluindo desempenho, segurança, experiência do cliente e assim por diante.
