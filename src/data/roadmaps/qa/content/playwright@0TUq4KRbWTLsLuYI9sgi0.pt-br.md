# Dramaturgo

Playwright é uma biblioteca de automação de testes de código aberto desenvolvida inicialmente por colaboradores da Microsoft. Ele oferece suporte a linguagens de programação como Java, Python, C# e NodeJS. Playwright vem com licença Apache 2.0 e é mais popular com NodeJS com Javascript/Typescript.

Visite os seguintes recursos para saber mais:

- [@official@site do dramaturgo](https://playwright.dev/)
- [@article@Playwright Tutorial: Aprenda noções básicas e configuração](https://www.browserstack.com/guide/playwright-tutorial)
