# Seguro

Scaled Agile Framework (SAFe) é uma base de conhecimento on-line disponível gratuitamente que permite aplicar práticas lean-ágil em nível empresarial. Ele fornece uma experiência simples e leve para desenvolvimento de software. É um conjunto de organizações e padrões de fluxo de trabalho destinados a orientar as empresas no dimensionamento de práticas enxutas e ágeis. Está dividido em três segmentos que são Equipe, Programa e Portfólio.
