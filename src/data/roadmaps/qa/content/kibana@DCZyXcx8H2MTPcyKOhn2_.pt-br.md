# Kibana

Kibana é uma interface de usuário gratuita e aberta que permite visualizar seus dados do Elasticsearch e navegar no Elastic Stack. Faça qualquer coisa, desde rastrear a carga de consultas até entender como as solicitações fluem pelos seus aplicativos.
