# XP

Extreme Programming (XP) é um framework ágil de desenvolvimento de software que visa produzir software de maior qualidade e maior qualidade de vida para a equipe de desenvolvimento. XP é o mais específico dos frameworks ágeis em relação às práticas de engenharia apropriadas para desenvolvimento de software.
