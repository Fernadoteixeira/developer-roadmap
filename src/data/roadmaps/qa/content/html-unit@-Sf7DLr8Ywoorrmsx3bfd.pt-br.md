# HtmlUnit

HtmlUnit é um "navegador sem GUI para programas Java". Ele modela documentos HTML e fornece uma API que permite invocar páginas, preencher formulários, clicar em links, etc... assim como você faz em seu navegador "normal". Possui um suporte JavaScript bastante bom (que está em constante melhoria) e é capaz de funcionar mesmo com bibliotecas AJAX bastante complexas, simulando Chrome, Firefox ou Internet Explorer dependendo da configuração utilizada.

HtmlUnit não é uma estrutura genérica de teste de unidade. É especificamente uma forma de simular um navegador para fins de teste e deve ser usado em outra estrutura de teste, como JUnit ou TestNG.
