# Fascínio

Allure Report é uma ferramenta de relatório de teste multilíngue flexível e leve. Ele fornece relatórios gráficos claros e permite que todos os envolvidos no processo de desenvolvimento extraiam o máximo de informações do processo de teste diário.

Visite os seguintes recursos para saber mais:

- [@oficial@Allure](https://qameta.io/)
- [@official@Allure Docs](https://docs.qameta.io/allure-report/)
