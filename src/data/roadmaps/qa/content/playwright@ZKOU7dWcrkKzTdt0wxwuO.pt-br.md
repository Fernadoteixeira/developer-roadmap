# Dramaturgo

Playwright é uma biblioteca de código aberto para automatizar navegadores web construída pela Microsoft, semelhante ao Selenium, é comumente usada para testar aplicativos web. Ele é construído sobre o tempo de execução do .NET Core e fornece ligações para C#, permitindo que os desenvolvedores escrevam testes para aplicativos da web em C# ou outras linguagens .NET. O Playwright foi projetado para ser rápido e confiável e permite que os desenvolvedores executem testes em vários navegadores.
