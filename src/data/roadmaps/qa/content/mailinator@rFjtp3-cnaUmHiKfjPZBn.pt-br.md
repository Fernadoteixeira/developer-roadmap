# Mailinador

Mailinator permite que desenvolvedores e equipes de teste de controle de qualidade testem automaticamente seus fluxos de trabalho de SMS e e-mail, como verificações 2FA, inscrições e redefinições de senha, com trilhões de caixas de entrada ao seu alcance. Quer você faça testes manuais, use uma API ou uma estrutura como Selenium, Cypress, Playwright ou Puppeteer - o Mailinator fechará o ciclo nos testes de e-mail/SMS.
