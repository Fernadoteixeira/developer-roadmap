# IDE Selênio

Selenium IDE é uma ferramenta de teste de automação web de código aberto do Selenium Suite usada principalmente para fins de controle de qualidade. Funciona como uma extensão do Firefox e não requer nenhum conhecimento de programação e casos de teste podem ser criados simplesmente interagindo com o navegador.

O próprio Selenium é uma ferramenta de teste automatizada de código aberto usada para testar aplicativos da web em vários navegadores. É construído principalmente em Java e oferece suporte a vários navegadores e linguagens de programação. O Selenium IDE foi desenvolvido para agilizar a criação de scripts de automação. É uma ferramenta de prototipagem rápida e pode ser usada por engenheiros sem nenhum conhecimento de programação. Devido à sua simplicidade, o Selenium IDE é melhor usado como uma ferramenta de prototipagem e não como uma solução completa para desenvolver e manter conjuntos de testes complexos.
