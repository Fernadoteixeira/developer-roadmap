# Selênio

Selenium é uma ferramenta de código aberto que automatiza navegadores da web. Ele fornece uma interface única que permite escrever scripts de teste em linguagens de programação como Ruby, Java, NodeJS, PHP, Perl, Python e C#, entre outras.
