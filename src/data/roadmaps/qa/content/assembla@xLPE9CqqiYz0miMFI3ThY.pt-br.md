# Montar

Assembla é um amplo conjunto de aplicativos para desenvolvimento de software, permitindo equipes ágeis distribuídas. Ele permite que as equipes de desenvolvimento gerenciem, iniciem e mantenham projetos, aplicativos e sites ágeis.

Visite os seguintes recursos para saber mais:

- [@artigo@Assembla](https://get.assembla.com/projects/)
