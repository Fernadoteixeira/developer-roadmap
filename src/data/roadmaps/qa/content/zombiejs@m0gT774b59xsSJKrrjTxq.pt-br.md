# Zumbi.js

Zombie.js permite que você execute testes de unidade ou integração sem um navegador real. Em vez disso, ele usa um navegador simulado onde armazena o código HTML e executa o JavaScript que você pode ter em sua página HTML. Isso significa que uma página HTML não precisa ser exibida, economizando um tempo precioso que de outra forma seria ocupado renderizando-a.
