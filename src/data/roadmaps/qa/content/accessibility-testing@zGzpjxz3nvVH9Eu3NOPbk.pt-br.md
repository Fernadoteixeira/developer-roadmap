# Teste de acessibilidade

O Teste de Acessibilidade é definido como um tipo de Teste de Software realizado para garantir que o aplicativo testado seja utilizável por pessoas com deficiência auditiva, daltonismo, velhice, visão subnormal e outros grupos desfavorecidos.
