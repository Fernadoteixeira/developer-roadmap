# Teste de segurança

O teste de segurança é um processo que visa revelar falhas nos mecanismos de segurança de um sistema de informação que protege os dados e mantém a funcionalidade conforme pretendido. Devido às limitações lógicas dos testes de segurança, passar no processo de teste de segurança não é uma indicação de que não existam falhas ou de que o sistema satisfaça adequadamente os requisitos de segurança.

Os requisitos de segurança típicos podem incluir elementos específicos de confidencialidade, integridade, autenticação, disponibilidade, autorização e não repúdio. Os requisitos de segurança reais testados dependem dos requisitos de segurança implementados pelo sistema. O termo teste de segurança tem vários significados diferentes e pode ser concluído de várias maneiras diferentes. Como tal, uma Taxonomia de Segurança ajuda-nos a compreender estas diferentes abordagens e significados, fornecendo um nível base a partir do qual trabalhar.
