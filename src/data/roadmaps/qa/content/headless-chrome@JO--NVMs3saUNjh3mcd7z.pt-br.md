# Cromo sem cabeça

Headless Chrome é uma maneira de executar o navegador Chrome em um ambiente headless sem a IU completa do navegador. Um dos benefícios de usar o Headless Chrome (em vez de testar diretamente no Node) é que seus testes de JavaScript serão executados no mesmo ambiente que os usuários do seu site.
