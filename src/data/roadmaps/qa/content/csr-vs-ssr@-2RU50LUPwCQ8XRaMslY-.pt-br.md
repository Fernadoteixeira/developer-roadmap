# RSE vs SSR

CSR significa Client Side Rendering e SSR significa Server Side Rendering. As páginas CSR são computadas em sua máquina e depois mostradas pelo seu navegador enquanto no caso de SSR, o servidor envia pronto para mostrar o conteúdo HTML diretamente. Principalmente os aplicativos React, Vue e Angular são exemplos de CSR (tecnicamente é possível que eles sejam executados no modo SSR também) e quase todas as pilhas de tecnologia mais antigas são SSR como PHP, ruby ​​on rails, java, dot net, etc. Do ponto de vista do usuário, os aplicativos CSR levam mais tempo para renderizar, mas compensam evitando recarregamentos de página posteriores (SPA), enquanto os aplicativos SSR geralmente têm um tempo de carregamento inicial mais rápido, mas recarregam a página inteira com frequência.
