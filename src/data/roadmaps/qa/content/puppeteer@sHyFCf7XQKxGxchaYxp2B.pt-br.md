# Marionetista

Puppeteer é uma biblioteca Node que fornece uma API de alto nível para controlar navegadores Headless Chrome ou Chromium por meio do protocolo DevTools. Ele também pode ser configurado para usar Chrome ou Chromium completo (sem headless).
