# Executa o escopo

Uma ferramenta simples para monitorar APIs complexas. Verifique se a estrutura e o conteúdo das suas chamadas de API atendem às suas expectativas. Asserções poderosas e flexíveis oferecem controle total sobre a definição de uma chamada de API bem-sucedida.

Crie monitores simples com dados dinâmicos até mesmo para os casos de uso mais complexos. Mais do que uma simples correspondência de strings, crie validações de API sem nenhum código e use-as em ambientes locais de desenvolvimento, preparação e produção.
