# Serviços de hospedagem de repositório

Existem diferentes serviços de hospedagem de repositórios, sendo os mais famosos GitHub, GitLab e BitBucket. Eu recomendaria criar uma conta no GitHub porque é onde a maior parte do trabalho do OpenSource é feita e a maioria dos desenvolvedores.

Visite os seguintes recursos para saber mais:

- [@opensource@GitHub: Onde o mundo cria software](https://github.com)
- [@opensource@GitLab: Itere mais rápido, inove junto](https://gitlab.com)
- [@article@BitBucket: A solução Git para equipes profissionais](https://bitbucket.com)
- [@feed@Explore as principais postagens sobre controle de qualidade](https://app.daily.dev/tags/qa?ref=roadmapsh)
