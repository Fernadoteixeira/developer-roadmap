# Vegeta

Vegeta é uma ferramenta versátil de teste de carga HTTP criada a partir da necessidade de perfurar serviços HTTP com uma taxa de solicitação constante. Ele pode ser usado como utilitário de linha de comando e como biblioteca.

Visite os seguintes recursos para saber mais:

- [@opensource@Vegeta](https://github.com/tsenart/vegeta)
