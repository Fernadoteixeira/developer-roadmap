# Trello

Trello é uma ferramenta de colaboração popular, simples e fácil de usar que permite organizar projetos e tudo relacionado a eles em quadros. Com o Trello você encontra todo tipo de informação, como:

- O que está sendo trabalhado?
- Quem está trabalhando em quê?
- Que progresso o projeto está fazendo

Visite os seguintes recursos para saber mais:

- [@official@Trello](https://trello.com/en)
