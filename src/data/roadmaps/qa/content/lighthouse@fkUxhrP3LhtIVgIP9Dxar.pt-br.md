# Farol

Lighthouse é uma ferramenta automatizada de código aberto para melhorar a qualidade das páginas da web. Você pode executá-lo em qualquer página da web, pública ou que exija autenticação. Possui auditorias de desempenho, acessibilidade, aplicativos web progressivos, SEO e muito mais. Você pode executar o Lighthouse no Chrome DevTools, na linha de comando ou como um módulo Node. Você fornece ao Lighthouse um URL para auditoria, executa uma série de auditorias na página e, em seguida, gera um relatório sobre o desempenho da página. A partir daí, use as auditorias fracassadas como indicadores de como melhorar a página. Cada auditoria possui um documento de referência que explica por que a auditoria é importante e como corrigi-la.
