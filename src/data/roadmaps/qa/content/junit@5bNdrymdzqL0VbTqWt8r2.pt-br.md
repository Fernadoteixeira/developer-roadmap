# JUnit

JUnit é conhecido como uma estrutura de teste de unidade usada para a linguagem de programação Java. JUnit tem desempenhado um papel crucial no desenvolvimento do desenvolvimento orientado a testes e faz parte de uma família de estruturas de teste unitário. JUnit é útil para escrever testes repetíveis para as unidades de código do seu aplicativo. JUnit estimula a ideia de “testar primeiro, depois codificar”. A abordagem de teste explica –teste um pouco + codifique um pouco = JUnit. JUnit auxilia o programador aumentando a produtividade e a estabilidade dos trechos de código do programa. Isso ajudará a reduzir o tempo do testador, que é gasto na depuração do código.
