# Teste de Integração

Teste de Integração é um tipo de teste onde os módulos de software são integrados logicamente e testados como um grupo. Um projeto de software típico consiste em vários módulos de software codificados por diferentes programadores. Este nível de teste visa expor defeitos na interação entre esses módulos de software quando integrados. O Teste de Integração concentra-se na verificação da comunicação de dados entre esses módulos.
