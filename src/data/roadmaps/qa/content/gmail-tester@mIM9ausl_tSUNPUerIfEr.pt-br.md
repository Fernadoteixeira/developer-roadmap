# Testador do Gmail

Gmail-tester é um cliente Gmail Node.js simples que verifica/retorna mensagens de e-mail diretamente de qualquer conta do Gmail (privada e corporativa).

Visite os seguintes recursos para saber mais:

- [@opensource@Gmail-tester Pacote](https://www.npmjs.com/package/gmail-tester)
- [@article@Usando o gmail-tester + Puppeteer para pesquisar a caixa de entrada do Gmail](https://medium.com/@sergtimosh/using-gmail-tester-puppeteer-to-poll-gmail-inbox-65bbee17618c)
