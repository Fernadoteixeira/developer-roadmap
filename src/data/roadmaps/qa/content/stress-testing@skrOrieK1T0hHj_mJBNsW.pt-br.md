# Teste de estresse

`Stress Testing` é um tipo de `Performance Testing`. O objetivo do teste de estresse é identificar o ponto de ruptura da aplicação sob teste sob carga normal extrema.

por exemplo Injetar um grande volume de solicitações por segundo em uma API pode causar a interrupção de seu serviço, gerar HTTP 503 Serviço indisponível ou causar outras consequências.
