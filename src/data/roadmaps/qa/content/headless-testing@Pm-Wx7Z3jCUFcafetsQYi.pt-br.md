# Teste sem cabeça

O teste headless ocorre quando os testes ponta a ponta são realizados sem carregar a interface do usuário do navegador. Como o navegador funciona como um navegador típico, mas não faz uso da interface do usuário, ele é considerado altamente adequado para testes automatizados.

Alguns exemplos de casos em que se pode usar testes de navegador headless incluem:

- Automatização de respostas a eventos HTML, como envio de formulários, eventos de teclado, cliques do mouse, etc.
- Raspagem da Web
- Geração de capturas de tela de páginas da web
