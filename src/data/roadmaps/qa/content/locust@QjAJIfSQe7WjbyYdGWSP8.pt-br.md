# Gafanhoto

Locust é uma ferramenta de teste de desempenho fácil de usar, programável e escalável. Você define o comportamento de seus usuários em código Python normal, em vez de ficar preso em uma UI ou linguagem restritiva específica de domínio. Isso torna o Locust infinitamente expansível e muito amigável ao desenvolvedor. Abaixo estão alguns dos recursos do Locust.

- Escreva cenários de teste em Python antigo
- Distribuído e escalável - suporta centenas de milhares de usuários simultâneos
- UI baseada na Web
- Pode testar qualquer sistema
- Hackeável
