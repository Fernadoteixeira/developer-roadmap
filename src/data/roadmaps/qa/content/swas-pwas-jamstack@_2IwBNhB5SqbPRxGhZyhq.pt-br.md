# SWAs, PWAs e JAMstack

## SWAs

Um aplicativo da Web estático é qualquer aplicativo da Web que pode ser entregue diretamente ao navegador do usuário final, sem qualquer alteração do conteúdo HTML, CSS ou JavaScript no lado do servidor. Embora isso possa abranger sites muito planos e imutáveis, como um site corporativo, os aplicativos da Web estáticos geralmente se referem a sites ricos que utilizam tecnologias no navegador em vez de no servidor para fornecer conteúdo dinâmico.

## PWAs

Em sua essência, os Progressive Web Apps são apenas aplicativos da web. Usando aprimoramento progressivo, novos recursos são habilitados em navegadores modernos. Usando service workers e um manifesto de aplicativo web, seu aplicativo web se torna confiável e instalável. Se os novos recursos não estiverem disponíveis, os usuários ainda terão a experiência principal.

Os Progressive Web Apps oferecem uma oportunidade única de oferecer uma experiência na web que seus usuários irão adorar. Usando os recursos da web mais recentes para oferecer recursos aprimorados e confiabilidade, os Progressive Web Apps permitem que o que você cria seja instalado por qualquer pessoa, em qualquer lugar, em qualquer dispositivo com uma única base de código.

## Jamstack

Jamstack é uma abordagem arquitetônica que separa a camada de experiência da web dos dados e da lógica de negócios, melhorando a flexibilidade, escalabilidade, desempenho e capacidade de manutenção.
Jamstack elimina a necessidade de lógica de negócios para ditar a experiência na web. Ele permite uma arquitetura combinável para a web onde lógica personalizada e serviços de terceiros são consumidos por meio de APIs.
