# Teste de caixa cinza

O teste de caixa cinza é uma técnica de teste de software para testar um produto ou aplicativo de software com conhecimento parcial da estrutura interna do aplicativo. O objetivo do teste de caixa cinza é pesquisar e identificar defeitos devido à estrutura inadequada do código ou ao uso impróprio de aplicativos.
