# Vigília Noturna

Nightwatch.js é uma estrutura de teste automatizado de código aberto alimentada por Node.js e fornece soluções E2E (ponta a ponta) completas para testes de automação com Selenium Javascript, seja para aplicativos da web, aplicativos de navegador e sites.

Visite os seguintes recursos para saber mais:

- [@official@Nightwatch.js Site](https://nightwatchjs.org/)
- [@article@NightwatchJS Tutorial: primeiros passos com testes de automação](https://www.browserstack.com/guide/nightwatch-framework-tutorial)
