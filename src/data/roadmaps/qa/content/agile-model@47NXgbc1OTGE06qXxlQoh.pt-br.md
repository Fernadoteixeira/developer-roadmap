# Modelo Ágil

O modelo ágil refere-se a uma abordagem de desenvolvimento de software baseada no desenvolvimento iterativo. Os métodos ágeis dividem as tarefas em iterações ou partes menores que não envolvem diretamente o planejamento de longo prazo. O escopo e os requisitos do projeto são definidos no início do processo de desenvolvimento. Os planos relativos ao número de iterações, à duração e ao escopo de cada iteração são claramente definidos com antecedência.

A metodologia Ágil de desenvolvimento de software é um dos processos mais simples e eficazes para transformar uma visão de uma necessidade de negócio em soluções de software.
