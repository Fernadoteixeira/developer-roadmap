# Teste de segurança

Teste de segurança é um tipo de teste de software que revela vulnerabilidades, ameaças ou riscos em um aplicativo de software e evita ataques maliciosos de intrusos. O objetivo dos testes de segurança é identificar todas as possíveis lacunas e fraquezas do sistema de software que possam resultar em perda de informações, receitas, reputação nas mãos dos funcionários ou de pessoas de fora da organização.
