# Ápio

Appium é uma estrutura de código aberto que permite que os QAs conduzam testes automatizados de aplicativos em diferentes plataformas, como Android, iOS e Windows. Ele é desenvolvido e suportado pela Sauce Labs para automatizar aplicativos móveis nativos e híbridos. É uma ferramenta de automação móvel multiplataforma, o que significa que permite que o mesmo teste seja executado em múltiplas plataformas.
