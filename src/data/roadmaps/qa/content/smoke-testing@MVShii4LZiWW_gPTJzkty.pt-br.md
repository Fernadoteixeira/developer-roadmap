# Teste de fumaça

Smoke Testing é um processo de teste de software que determina se a construção do software implantado é estável ou não. O teste de fumaça é uma confirmação para a equipe de controle de qualidade prosseguir com mais testes de software. Consiste em um conjunto mínimo de testes executados em cada compilação para testar as funcionalidades do software.
