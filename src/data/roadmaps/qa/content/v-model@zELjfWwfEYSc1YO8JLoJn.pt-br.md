# VModelo

O Modelo V é um modelo SDLC altamente disciplinado que possui uma fase de testes paralela a cada fase de desenvolvimento. O modelo V é uma extensão do modelo cascata em que o desenvolvimento e o teste de software são executados de forma sequencial. Também é conhecido como Modelo de Validação ou Verificação.
