# Ájax

AJAX significa JavaScript e XML assíncronos. Resumindo, é o uso do objeto XMLHttpRequest para comunicação com servidores. Ele pode enviar e receber informações em vários formatos, incluindo JSON, XML, HTML e arquivos de texto.
