# SoapUI

SoapUI é a ferramenta de teste funcional líder mundial para testes SOAP e REST. Com sua interface gráfica fácil de usar e recursos de classe empresarial, o SoapUI permite criar e executar testes funcionais, de regressão e de carga automatizados de maneira fácil e rápida.

Visite os seguintes recursos para saber mais:

- [@oficial@SoapUI](https://www.soapui.org/)
- [@official@SoapUI Docs](https://www.soapui.org/getting-started/)
