# Noções básicas de HTML/CSS/JavaScript

HTML significa Linguagem de Marcação de Hipertexto. É usado na frente e dá estrutura à página web, que você pode estilizar usando CSS e tornar interativa usando JavaScript.

CSS ou Cascading Style Sheets é a linguagem usada para estilizar o front end de qualquer site. CSS é uma tecnologia fundamental da World Wide Web, junto com HTML e JavaScript.

JavaScript permite adicionar interatividade às suas páginas. Você deve ter visto exemplos comuns em sites: controles deslizantes, interações de cliques, pop-ups e assim por diante.
