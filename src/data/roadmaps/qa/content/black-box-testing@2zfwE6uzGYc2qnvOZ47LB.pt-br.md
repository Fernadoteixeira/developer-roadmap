# Teste de caixa preta

Black Box Testing é um método de teste de software no qual as funcionalidades dos aplicativos de software são testadas sem o conhecimento da estrutura interna do código, detalhes de implementação e caminhos internos. O teste Black Box concentra-se principalmente na entrada e saída de aplicativos de software e é inteiramente baseado em requisitos e especificações de software. Também é conhecido como Teste Comportamental.
