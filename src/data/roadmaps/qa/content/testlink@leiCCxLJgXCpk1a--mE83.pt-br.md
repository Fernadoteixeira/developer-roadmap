# TestLink

TestLink é a ferramenta de gerenciamento de testes de código aberto baseada na web mais amplamente usada. Ele sincroniza a especificação de requisitos e a especificação de teste juntas. O testador pode criar projetos de teste e documentar casos de teste usando esta ferramenta. Com TestLink você pode criar uma conta para vários usuários e atribuir diferentes funções de usuário.

Visite os seguintes recursos para saber mais:

- [@official@TestLink](https://testlink.org/)
