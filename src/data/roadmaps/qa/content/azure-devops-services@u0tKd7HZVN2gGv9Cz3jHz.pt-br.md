# Azure DevOps

O Azure DevOps é desenvolvido pela Microsoft como um serviço completo de gerenciamento do ciclo de vida de aplicativos e CI/CD. O Azure DevOps fornece serviços de desenvolvedor para permitir que as equipes planejem o trabalho, colaborem no desenvolvimento de código e criem e implantem aplicativos.
