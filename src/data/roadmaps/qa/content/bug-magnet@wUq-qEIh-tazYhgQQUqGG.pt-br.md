# Ímã de insetos

O teste exploratório trata de explorar o software navegando por caminhos aleatórios e descobrindo o que ele pode e o que não pode fazer. Em testes exploratórios, tentamos verificar quão bem o sistema reage a entradas especiais/inválidas e casos extremos. O Bug Magnet o ajudará a configurar validações de dados e vários cenários de entrada que podem causar problemas.

Visite os seguintes recursos para saber mais:

- [@article@Bug Magnet Website](https://bugmagnet.org/)
- [@article@Bug Magnet: extensão do Chrome para testes exploratórios](http://www.testingjournals.com/bug-magnet-extension-exploratory-testing/)
