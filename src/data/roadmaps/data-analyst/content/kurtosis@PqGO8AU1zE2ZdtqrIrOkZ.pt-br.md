# Curtose

Compreender os formatos de distribuição é parte integrante das responsabilidades diárias de um analista de dados. Quando inspecionam dados estatísticos, uma característica importante que consideram é a curtose da distribuição. Nas estatísticas, a curtose identifica o peso das caudas da distribuição e a nitidez do pico. Uma compreensão adequada da curtose pode ajudar os analistas no gerenciamento de riscos, na detecção de valores discrepantes e fornece uma visão mais profunda das variações. Portanto, ser proficiente na interpretação de medidas de curtose de uma forma de distribuição é uma habilidade significativa que todo analista de dados deve dominar.
