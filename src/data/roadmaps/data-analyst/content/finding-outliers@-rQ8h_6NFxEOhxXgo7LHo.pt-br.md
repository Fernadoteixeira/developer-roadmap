# Encontrando valores discrepantes

No campo da análise de dados, a limpeza de dados é uma etapa essencial e preliminar. Este processo envolve a correção ou remoção de quaisquer erros, imprecisões ou irrelevâncias presentes nos dados brutos obtidos, tornando-os mais adequados para análise. Um aspecto crucial deste processo é “encontrar valores discrepantes”. Outliers são pontos de dados incomuns ou surpreendentes que se desviam significativamente do restante dos dados. Embora possam ser o resultado de mera variabilidade ou erro, muitas vezes atrairão os dados agregados para eles, distorcendo os resultados e impedindo a precisão da análise dos dados. Portanto, identificar e tratar adequadamente esses valores discrepantes é crucial para garantir a confiabilidade das tarefas subsequentes de análise de dados.
