# Logística

A regressão logística é uma das técnicas fundamentais que um analista de dados deve compreender no aprendizado de máquina. Este método é um algoritmo de análise preditiva baseado no conceito de probabilidade. É usado para categorizar dados em classes distintas, tornando-o particularmente útil para problemas de classificação binária. Deve-se entender que apesar do nome, a regressão logística é utilizada em problemas de classificação, não em tarefas de regressão. Os analistas de dados usam esse algoritmo para construir modelos de aprendizado de máquina para resolver vários problemas do mundo real, como spam de e-mail, credibilidade dos solicitantes de empréstimos, desenvolvimento de estratégias de marketing e assim por diante.
