# Tendência Central

A análise descritiva é um ramo significativo no campo da análise de dados e, neste âmbito, o conceito de Tendência Central desempenha um papel vital. Como analistas de dados, compreender a tendência central é de suma importância, pois oferece um rápido resumo dos dados. Ele fornece informações sobre o ponto central em torno do qual os dados numéricos são distribuídos. Os três principais tipos de tendência central incluem média, mediana e moda. Estas medidas são utilizadas por analistas de dados para identificar tendências, fazer comparações ou tirar conclusões. Portanto, uma compreensão da tendência central equipa os analistas de dados com ferramentas essenciais para interpretar e dar sentido aos dados estatísticos.
