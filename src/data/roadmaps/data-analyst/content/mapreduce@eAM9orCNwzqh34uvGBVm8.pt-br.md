# MapReduce

MapReduce é uma técnica de processamento de dados proeminente usada por analistas de dados em todo o mundo. Isso lhes permite lidar com grandes conjuntos de dados com dados complexos e não estruturados de forma eficiente. MapReduce divide um problema de big data em subtarefas menores (Map) e então usa esses resultados para criar uma saída em um formato mais utilizável (Reduce). Essa técnica é particularmente útil na condução de análises exploratórias, bem como no tratamento de operações de big data, como processamento de texto, processamento de gráficos ou algoritmos de aprendizado de máquina mais complicados.
