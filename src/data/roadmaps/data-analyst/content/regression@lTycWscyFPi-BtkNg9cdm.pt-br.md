# Regressão

Como analista de dados, compreender a regressão é de suma importância. A análise de regressão é uma forma de técnica de modelagem preditiva que investiga a relação entre variáveis ​​dependentes e independentes. É usado para previsão, modelagem de séries temporais e localização da relação de efeito causal entre variáveis. Em essência, as técnicas de regressão são usadas por analistas de dados para prever uma variável de resultado contínua (variável dependente) com base em uma ou mais variáveis ​​preditoras (variáveis ​​independentes). O objetivo principal é entender como o valor típico da variável dependente muda quando qualquer uma das variáveis ​​independentes é variada, enquanto as demais variáveis ​​independentes são mantidas fixas. Essa compreensão da regressão leva a análise de dados de uma posição reativa para uma posição mais poderosa e preditiva, equipando os analistas de dados com uma ferramenta integral em seu trabalho.
