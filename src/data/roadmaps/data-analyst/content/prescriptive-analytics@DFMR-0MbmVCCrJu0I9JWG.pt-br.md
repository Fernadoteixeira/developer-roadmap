# Análise Prescritiva

A análise prescritiva, um tipo crucial de análise de dados, é essencial para a tomada de decisões baseadas em dados em contextos empresariais e organizacionais. Como analista de dados, o objetivo da análise prescritiva é recomendar várias ações usando previsões com base em parâmetros conhecidos para ajudar os tomadores de decisão a compreender os resultados prováveis. A análise prescritiva emprega uma combinação de técnicas e ferramentas como algoritmos, aprendizado de máquina, procedimentos de modelagem computacional e estruturas de árvore de decisão para permitir a tomada de decisões automatizada. Portanto, a análise prescritiva não só antecipa o que irá acontecer e quando irá acontecer, mas também explica porque irá acontecer, contribuindo para a importância do papel de um analista de dados numa organização.
