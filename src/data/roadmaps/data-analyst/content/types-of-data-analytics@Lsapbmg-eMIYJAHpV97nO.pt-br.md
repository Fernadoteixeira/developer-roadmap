# Introdução aos tipos de análise de dados

A análise de dados provou ser uma parte crítica da tomada de decisões em empreendimentos comerciais modernos. É responsável por descobrir, interpretar e transformar dados em informações valiosas. Diferentes tipos de análise de dados analisam visões passadas, presentes ou preditivas das operações de negócios.

Os Analistas de Dados, como embaixadores deste domínio, empregam estes tipos, para responder a diversas questões:

- Análise Descritiva _(o que aconteceu no passado?)_
- Análise de diagnóstico _(por que isso aconteceu no passado?)_
- Análise Preditiva _(o que acontecerá no futuro?)_
- Análise Prescritiva _(como podemos fazer isso acontecer?)_
