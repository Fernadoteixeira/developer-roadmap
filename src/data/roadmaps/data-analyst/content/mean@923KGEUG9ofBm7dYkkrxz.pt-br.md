# Significar

Tendência central refere-se à medida estatística que identifica um único valor como representativo de toda uma distribuição. A média ou média é uma das medidas de tendência central mais populares e amplamente utilizadas. Para um analista de dados, calcular a média é uma tarefa rotineira. Este valor único fornece ao analista um instantâneo rápido dos dados e pode ser útil para posterior manipulação de dados ou análise estatística. A média é particularmente útil na previsão de tendências e padrões em conjuntos de dados volumosos ou no ajuste de fatores de influência que podem distorcer a representação “verdadeira” dos dados. É a média aritmética de um intervalo de valores ou quantidades, calculada como a soma total de todos os valores dividida pelo número total de valores.
