# Média

Ao focar na análise de dados, compreender os principais conceitos estatísticos é crucial. Entre estes, a tendência central é um elemento fundamental. Tendência Central refere-se à medida que determina o centro de uma distribuição. A média é uma ferramenta estatística comumente usada pela qual os analistas de dados discernem tendências e padrões. Como uma das formas mais reconhecidas de tendência central, descobrir a “média” envolve somar todos os valores de um conjunto de dados e dividir pelo número de valores. Isto fornece aos analistas um valor “típico”, em torno do qual os dados restantes tendem a agrupar-se, facilitando uma melhor tomada de decisões com base nos dados existentes.
