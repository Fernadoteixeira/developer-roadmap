# Visualização de dados

A visualização de dados é um fragmento fundamental das responsabilidades de um analista de dados. Envolve a apresentação de dados em formato gráfico ou pictórico que permite aos tomadores de decisão ver as análises visualmente. Esta prática pode ajudá-los a compreender conceitos difíceis ou a estabelecer novos padrões. Com a visualização interativa, os analistas de dados podem levar o processo de análise de dados a um nível totalmente novo – detalhar tabelas e gráficos para obter mais detalhes e alterar interativamente quais dados são apresentados ou como são processados. Assim, forma um elo crucial na cadeia de conversão de dados brutos em insights acionáveis, que é uma das principais funções de um analista de dados.
