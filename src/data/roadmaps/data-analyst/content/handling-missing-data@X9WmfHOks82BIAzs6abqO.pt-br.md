# Tratamento de dados ausentes na limpeza de dados

Ao trabalhar com dados do mundo real como analista de dados, é bastante comum encontrar valores ausentes ou nulos. Este fenômeno é conhecido como “Dados faltantes” no campo da análise de dados. A falta de dados pode afetar gravemente os resultados de um processo de análise de dados, uma vez que reduz o poder estatístico, o que pode distorcer a fiabilidade e a robustez dos resultados.

A falta de dados faz parte da etapa de 'Limpeza de Dados', que é uma parte crucial do Pré-processamento na Análise de Dados. Envolve identificar dados incompletos, incorretos ou irrelevantes e, em seguida, substituir, modificar ou excluir esses dados sujos. A limpeza bem-sucedida de valores ausentes pode aumentar significativamente a qualidade geral dos dados, oferecendo, portanto, insights valiosos e confiáveis. É essencial para um Analista de Dados compreender as diferentes técnicas para lidar com dados faltantes, como diferentes tipos de imputações com base na natureza dos dados e na questão de pesquisa.
