# SUBSTITUIR / SUBSTITUIR

No Microsoft Excel, as funções REPLACE e SUBSTITUTE são ferramentas poderosas usadas para modificar dados de texto dentro de células. Ambas as funções servem para alterar o texto, mas são utilizadas em diferentes cenários com base na natureza das alterações necessárias.

A função SUBSTITUTE é usada para substituir ocorrências de uma substring especificada por uma nova substring. Ele permite a substituição de texto com base em caracteres correspondentes em vez de posição, tornando-o ideal para alterar instâncias específicas de texto dentro de uma string.

A função REPLACE é usada para substituir parte de uma sequência de texto por outra sequência de texto, com base em sua posição no texto original. É particularmente útil quando você precisa substituir um segmento específico de texto por um novo texto, começando em uma posição designada.
