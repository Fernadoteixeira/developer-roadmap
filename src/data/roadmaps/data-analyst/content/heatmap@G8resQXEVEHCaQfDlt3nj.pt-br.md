# Mapa de calor

Os mapas de calor são um componente crucial da visualização de dados que os analistas de dados empregam regularmente em suas análises. Como uma das muitas representações gráficas possíveis de dados, os mapas de calor mostram a correlação ou escala de variação entre duas ou mais variáveis ​​em um conjunto de dados, tornando-os extremamente úteis para reconhecimento de padrões e detecção de valores discrepantes. Os valores individuais dentro de uma matriz são representados em um mapa de calor como cores, com diferentes intensidades indicando o grau ou a intensidade de uma ocorrência. Resumindo, um analista de dados usaria um mapa de calor para decodificar dados multivariados complexos e transformá-los em um visual de fácil compreensão que auxilia na tomada de decisões.
