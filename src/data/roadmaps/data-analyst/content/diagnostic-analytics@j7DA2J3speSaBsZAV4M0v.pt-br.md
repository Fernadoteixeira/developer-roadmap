# Análise de diagnóstico

A análise diagnóstica, como um tipo crucial de análise de dados, concentra-se no estudo do desempenho passado para entender por que algo aconteceu. Esta é parte integrante do trabalho realizado pelos analistas de dados. Por meio de técnicas como detalhamento, descoberta de dados, correlações e análise de causa-efeito, os analistas de dados que utilizam análise de diagnóstico podem olhar além das tendências gerais e identificar a causa raiz das alterações observadas nos dados. Consequentemente, isto permite que as empresas abordem questões operacionais e estratégicas de forma eficaz, permitindo-lhes compreender as razões por detrás de tais questões. Para todo analista de dados, a habilidade de realizar análise de dados diagnósticos é um ativo indispensável que aprimora sua capacidade de análise.
