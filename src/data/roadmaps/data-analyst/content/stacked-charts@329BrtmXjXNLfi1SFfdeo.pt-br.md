# Gráfico empilhado

Um gráfico empilhado é uma ferramenta essencial para um analista de dados na área de visualização de dados. Este tipo de gráfico apresenta dados quantitativos de maneira visualmente atraente e permite aos usuários comparar facilmente diferentes categorias e ao mesmo tempo comparar os tamanhos totais. Esses gráficos são altamente eficazes ao tentar medir relações entre parte e todo, exibindo totais acumulados ao longo do tempo ou ao apresentar dados com múltiplas variáveis. Os analistas de dados costumam usar gráficos empilhados para detectar padrões, tendências e anomalias que podem auxiliar na tomada de decisões estratégicas.
