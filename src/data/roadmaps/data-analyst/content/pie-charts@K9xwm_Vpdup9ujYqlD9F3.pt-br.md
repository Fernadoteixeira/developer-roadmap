# Gráfico de pizza

Como analista de dados, é crucial compreender e usar com eficiência várias formas de visualização de dados. Entre estes, os gráficos de pizza representam uma ferramenta significativa. Essencialmente, os gráficos de pizza são gráficos estatísticos circulares divididos em fatias para ilustrar proporções numéricas. Cada fatia do bolo corresponde a uma categoria específica. A beleza do gráfico circular reside na sua simplicidade e apelo visual, tornando-o uma forma eficaz de transmitir proporções relativas ou percentagens num relance. Para um analista de dados, é particularmente útil quando você deseja mostrar uma distribuição simples de dados categóricos. Porém, como qualquer ferramenta, é importante usar gráficos de pizza com sabedoria – de preferência, quando seu conjunto de dados tiver menos de sete categorias e as proporções entre as categorias forem distintas.
