# DATADIF

A função `DATEDIF` é uma ferramenta extremamente valiosa para um analista de dados no Excel ou no Planilhas Google, pois fornece a capacidade de calcular a diferença entre duas datas. Esta função aceita três parâmetros: data de início, data de término e o tipo de diferença necessária (medida em anos, meses, dias, etc.). Na análise de dados, especialmente ao lidar com dados de séries temporais ou quando você precisa descobrir tendências em períodos específicos, a função `DATEDIF` é um recurso necessário. O reconhecimento de sua funcionalidade permitirá ao analista de dados manipular ou moldar os dados de forma progressiva e eficiente.

`DATEDIF` ainda é tecnicamente compatível, mas não será exibido como uma opção. Para obter informações adicionais, consulte a página "Ajuda" do Excel.
