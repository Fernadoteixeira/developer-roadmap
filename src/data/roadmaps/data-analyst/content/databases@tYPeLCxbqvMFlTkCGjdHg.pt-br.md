# Bancos de dados

Por trás de cada analista de dados forte, não existe apenas uma rica variedade de dados, mas um conjunto de bancos de dados robustos que permitem uma coleta de dados eficaz. Os bancos de dados são um aspecto fundamental da coleta de dados em um mundo onde a capacidade de gerenciar, organizar e avaliar grandes volumes de dados é crítica. Como analista de dados, a compreensão e utilização de bases de dados é fundamental na captura dos dados necessários para a realização de análises qualitativas e quantitativas, previsão de tendências e tomada de decisões baseadas em dados. O conhecimento profundo dos bancos de dados, portanto, pode ser considerado um componente-chave do arsenal de um analista de dados. Esses bancos de dados podem variar de bancos de dados relacionais como SQL a bancos de dados NoSQL como MongoDB, cada um desempenhando uma função exclusiva no processo de coleta de dados.
