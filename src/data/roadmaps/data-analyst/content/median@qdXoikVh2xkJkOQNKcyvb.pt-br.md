# Mediana

Mediana significa o valor médio em um conjunto de dados quando organizado em ordem crescente ou decrescente. Como analista de dados, compreender, calcular e interpretar a mediana é crucial. É especialmente útil ao lidar com valores discrepantes em um conjunto de dados, pois a mediana é menos sensível a valores extremos. Assim, fornecendo um valor “central” mais realista para distribuições distorcidas. Esta medida é um reflexo fiável do conjunto de dados e é amplamente utilizada em áreas como imobiliário, economia e finanças para interpretação de dados e tomada de decisões.
