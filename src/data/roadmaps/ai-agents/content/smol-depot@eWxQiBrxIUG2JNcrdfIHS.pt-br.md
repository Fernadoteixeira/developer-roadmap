# SmolDepot

Smol Depot é um kit de código aberto que permite agrupar todas as partes de um pequeno agente de IA em um só lugar. Você mantém prompts, configurações e arquivos de código juntos em uma única pasta e, em seguida, aponta a ferramenta Depot para essa pasta para ativar o agente. A ferramenta lida com tarefas como carregar modelos, salvar histórico de bate-papo e chamar APIs externas, para que você não precise escrever esse código cola sozinho. Um comando simples pode copiar um modelo inicial, permitindo que você se concentre na lógica e nos prompts que tornam seu agente especial. Como tudo reside em arquivos simples, você pode acompanhar as alterações com o Git e compartilhar o agente como qualquer outro projeto.
