# Percepção/Informação do usuário

A percepção, também chamada de entrada do usuário, é a primeira etapa de um loop de agente. O agente escuta e coleta dados do mundo exterior. Esses dados podem ser texto digitado por um usuário, palavras faladas, imagens de câmeras, leituras de sensores ou conteúdo da web obtido por meio de uma API. O objetivo é transformar sinais brutos em um formato claro e utilizável. O agente pode limpar o texto, traduzir a fala em texto, redimensionar uma imagem ou eliminar o ruído dos valores do sensor. Uma boa percepção significa que o agente inicia seu ciclo com fatos, não com suposições. Se a entrada estiver errada ou pouco clara, as etapas posteriores também falharão. Portanto, o manejo cuidadoso da percepção mantém todo o ciclo do agente no caminho certo.
