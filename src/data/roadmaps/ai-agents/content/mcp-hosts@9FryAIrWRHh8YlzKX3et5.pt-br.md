# Hosts MCP

Hosts MCP são computadores ou serviços que executam o Model Context Protocol. Eles lidam com chamadas recebidas, carregam o manifesto MCP, verificam solicitações e transmitem dados entre usuários, ferramentas e modelos de linguagem. Os hosts podem armazenar mensagens recentes em cache, rastrear o uso de tokens e adicionar verificações de segurança ou de cobrança antes de enviar avisos ao modelo. Eles expõem um endpoint de API para que os aplicativos possam se conectar facilmente. Você pode executar um host em seu laptop para teste ou implantá-lo em plataformas de nuvem para escalar. O host atua como uma ponte confiável onde agentes, ferramentas e dados se encontram.
