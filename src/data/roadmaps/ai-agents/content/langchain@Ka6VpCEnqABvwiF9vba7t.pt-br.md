# LangChain

LangChain é uma biblioteca Python e JavaScript que ajuda você a colocar grandes modelos de linguagem para funcionar em produtos reais. Ele fornece peças prontas para tarefas comuns do agente, como conversar com muitas ferramentas, manter memória de curto prazo e chamar uma API externa quando o modelo precisar de dados atualizados. Você combina essas partes como blocos de Lego: escolha um modelo, adicione um modelo de prompt, encadeie as etapas e, em seguida, envolva a cadeia em um “agente” que pode escolher qual etapa executar a seguir. Conectores integrados vinculam-se a OpenAI, Hugging Face, armazenamentos de vetores e bancos de dados SQL, para que você possa pesquisar documentos ou extrair dados da empresa sem escrever muito código cola. Isso permite que você passe rapidamente da ideia para o bot funcional, ao mesmo tempo que permite trocar peças se suas necessidades mudarem.
