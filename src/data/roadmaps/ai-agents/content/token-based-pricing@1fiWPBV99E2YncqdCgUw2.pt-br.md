# Preço baseado em token

O preço baseado em token é quantos serviços de modelo de linguagem cobram pelo uso. Um token é um pequeno pedaço de texto, com aproximadamente quatro caracteres ou parte de uma palavra. O serviço conta cada token que entra no modelo (seu prompt) e cada token que sai (a resposta). Em seguida, multiplica esse total por um preço listado por mil tokens. Alguns planos definem um preço para tokens de entrada e um preço maior ou menor para tokens de saída. Como a conta aumenta com cada token, os usuários geralmente encurtam os prompts, cortam palavras extras ou limitam o comprimento da resposta para gastar menos.
