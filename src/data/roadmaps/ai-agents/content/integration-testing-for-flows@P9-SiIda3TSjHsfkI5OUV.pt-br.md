# Teste de integração para fluxos

O teste de integração para fluxos verifica se um agente de IA funciona bem desde a primeira entrada do usuário até a ação final, em todas as etapas intermediárias. Ele une todas as partes do sistema – compreensão da linguagem natural, planejamento, memória, ferramentas e resultados – e as executa juntas em cenários reais. Os casos de teste seguem caminhos comuns e extremos que um usuário pode seguir. O objetivo é detectar erros que só aparecem quando as peças interagem, como dados errados transmitidos entre módulos ou problemas de temporização. As boas práticas incluem a criação de conjuntos de testes automatizados, o uso de serviços reais ou simulados e o registro de cada etapa para facilitar a depuração. Quando os testes de integração são aprovados, você ganha a confiança de que todo o fluxo parece tranquilo e confiável para os usuários.
