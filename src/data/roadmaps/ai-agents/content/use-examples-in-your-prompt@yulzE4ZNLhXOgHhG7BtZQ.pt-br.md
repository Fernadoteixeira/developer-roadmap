# Use exemplos em seu prompt

Uma maneira clara de orientar uma IA é colocar uma ou duas amostras curtas em seu prompt. Mostre uma pequena entrada e a saída exata que você espera. A IA estuda esses pares e copia seu padrão. Use palavras simples na amostra, mantenha o formato estável e rotule cada parte para que o modelo saiba qual é qual. Se precisar de uma lista, mostre uma lista; se precisar de uma mesa, inclua uma mesa pequena. Bons exemplos eliminam suposições, reduzem erros e evitam que você escreva regras longas.
