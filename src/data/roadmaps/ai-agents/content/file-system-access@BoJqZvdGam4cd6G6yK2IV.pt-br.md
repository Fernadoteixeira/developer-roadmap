# Acesso ao sistema de arquivos

O acesso ao sistema de arquivos permite que um agente de IA leia, crie, altere ou exclua arquivos e pastas em um computador ou servidor. Com esse poder, o agente pode abrir um arquivo de texto para extrair dados, escrever um novo relatório, salvar logs ou organizar arquivos antigos sem ajuda humana. Ele também pode mover arquivos entre pastas para manter tudo organizado. Esta ferramenta é útil para tarefas como processamento de dados, geração de relatórios e tarefas de backup. São necessárias verificações de segurança rigorosas para que o agente acesse apenas os arquivos corretos, evite dados privados e não possa danificar o sistema por engano.
