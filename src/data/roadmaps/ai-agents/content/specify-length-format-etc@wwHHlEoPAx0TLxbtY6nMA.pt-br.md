# Especifique o comprimento e o formato

Ao atribuir uma tarefa a uma IA, deixe claro quanto tempo a resposta deve ter e que formato ela deve assumir. Diga “Escreva 120 palavras” ou “Apresente as etapas em uma lista numerada”. Se você precisar de uma tabela, indique os nomes e a ordem das colunas. Se você quiser marcadores, mencione isso. Dizer à IA para usar texto simples, JSON ou markdown evita suposições e economiza tempo. Limites claros de comprimento mantêm a resposta focada. Um formato fixo torna mais fácil para pessoas ou outros softwares lerem e usarem o resultado. Sempre coloque essas regras perto do início do seu prompt para que a IA as considere importantes.
