# Remoto / Nuvem

A implantação remota ou na nuvem coloca o servidor MCP em um provedor de nuvem em vez de em uma máquina local. Você empacota o servidor como um contêiner ou máquina virtual, escolhe um serviço como AWS, Azure ou GCP e fornece computação, armazenamento e um endereço HTTPS público. Um balanceador de carga distribui o tráfego, enquanto o escalonamento automático adiciona ou remove cópias do servidor conforme a demanda muda. Você protege o endpoint com TLS, chaves de API e firewalls e envia logs e métricas para as ferramentas de monitoramento do provedor. Essa configuração permite que o servidor lide com muitos usuários, as atualizações são mais fáceis e você evita limites de hardware local, embora deva monitorar os custos e proteger dados confidenciais.
