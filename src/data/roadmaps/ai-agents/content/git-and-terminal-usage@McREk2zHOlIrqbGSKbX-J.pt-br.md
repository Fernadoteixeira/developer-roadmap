# Uso de Git e Terminal

Git e o terminal são ferramentas essenciais para agentes e desenvolvedores de IA. O Git permite rastrear alterações no código, trabalhar com ramificações e colaborar com segurança com outras pessoas. Ele armazena instantâneos do seu trabalho para que você possa desfazer erros ou mesclar ideias. O terminal (linha de comando) permite mover arquivos, executar programas, configurar servidores e controlar ferramentas como o Git rapidamente, sem uma GUI.
