# Armazenamento de perfil de usuário

O armazenamento de perfil de usuário é a parte da memória de um agente de IA que contém fatos estáveis ​​sobre cada usuário, como nome, faixa etária, idioma, escolhas anteriores e objetivos de longo prazo. O agente salva esses dados em um arquivo ou pequeno banco de dados para poder carregá-los sempre que o mesmo usuário retornar. Ao manter o perfil separado dos registros de conversas de curto prazo, o agente pode lembrar as preferências sem misturá-las com o histórico temporário de bate-papo. O perfil é atualizado somente quando o usuário declara uma nova preferência duradoura ou quando informações antigas são alteradas, o que ajuda a evitar desvios ou inchaço.
