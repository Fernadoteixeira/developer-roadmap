# palheiro

Haystack é uma estrutura Python de código aberto que ajuda você a criar agentes de pesquisa e resposta a perguntas rapidamente. Você conecta suas fontes de dados, escolhe um modelo de linguagem e configura pipelines que encontram a melhor resposta para a consulta de um usuário. Haystack lida com tarefas como indexação de documentos, recuperação de passagens, execução do modelo e classificação de resultados. Ele funciona com muitos back-ends como Elasticsearch, OpenSearch, FAISS e Pinecone, para que você possa escalar de um laptop para um cluster. Você pode adicionar recursos como resumo, tradução e bate-papo de documentos colocando nós extras no pipeline. A estrutura também oferece APIs REST, uma interface web e tutoriais claros, facilitando o teste e a implantação do seu agente na produção.
