# Rastreamento/rastreamento da Web

A raspagem e o rastreamento da Web permitem que um agente de IA colete dados de muitas páginas da Web sem ajuda humana. O agente envia uma solicitação para uma página, lê o HTML e extrai as partes solicitadas, como preços, manchetes ou detalhes de produtos. Ele pode então seguir os links da página para acessar mais páginas e repetir as mesmas etapas. Esse loop cria um conjunto de dados grande e atualizado em minutos ou horas, em vez de dias. As empresas o utilizam para rastrear preços de mercado, os pesquisadores o utilizam para coletar fatos ou tendências e os desenvolvedores o utilizam para alimentar dados novos em outros modelos de IA. Um bom código de scraping também respeita as regras do site, como o robots.txt, e evita atingir os servidores muito rápido, por isso funciona de maneira suave e justa.
