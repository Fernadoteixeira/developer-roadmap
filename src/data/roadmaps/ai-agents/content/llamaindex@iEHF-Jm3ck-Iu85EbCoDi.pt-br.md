# LhamaIndex

LlamaIndex é um kit de ferramentas Python de código aberto que ajuda você a fornecer a um modelo de linguagem acesso aos seus próprios dados. Você carrega arquivos como PDFs, páginas da web ou linhas de banco de dados. O kit de ferramentas divide o texto em pedaços, transforma-os em vetores e os armazena em um armazenamento de vetores escolhido, como FAISS ou Pinecone. Quando um usuário faz uma pergunta, o LlamaIndex encontra os melhores pedaços, adiciona-os ao prompt e envia o prompt ao modelo. Esse fluxo é chamado de geração aumentada de recuperação e permite que um agente dê respostas baseadas em seu conteúdo. A biblioteca oferece classes simples para ferramentas de carregamento, indexação, consulta e composição, para que você escreva menos código clichê. Ele também funciona com outras estruturas, incluindo LangChain, e oferece suporte a modelos OpenAI ou Hugging Face. Com algumas linhas de código você pode construir um chatbot, sistema de perguntas e respostas ou outro agente que conheça seus documentos.
