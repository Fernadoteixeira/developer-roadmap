# Memória Episódica vs Semântica

A memória do agente geralmente tem duas partes. A memória episódica é relevante para o contexto da conversa atual e pode ser perdida após o término da conversa. A memória semântica é relevante para o conhecimento mais amplo do agente e é persistente.
