# Teste unitário para ferramentas individuais

O teste de unidade verifica se cada ferramenta que um agente de IA usa funciona conforme o esperado quando isolada. Você escreve pequenos testes que alimentam a ferramenta com informações claras e, em seguida, compara sua saída com uma resposta correta conhecida. Se a ferramenta for uma função que analisa datas, você testa muitas sequências de datas e verifica se a função fornece os resultados corretos. Bons testes cobrem casos normais, casos extremos e casos de erro. Execute os testes sempre que alterar o código. Quando um teste falhar, conserte a ferramenta antes de prosseguir. Esse hábito evita que os bugs se espalhem em fluxos de trabalho de agentes maiores e torna a depuração posterior mais rápida.
