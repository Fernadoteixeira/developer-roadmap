# Definição de ferramenta

Uma ferramenta é qualquer habilidade ou função que um agente de IA pode chamar para realizar um trabalho. Pode ser tão simples quanto uma calculadora matemática ou tão complexo quanto uma API que busca dados meteorológicos ao vivo. Cada ferramenta tem um nome, uma breve descrição do que faz e uma lista clara das entradas de que necessita e dos resultados que retorna. O planejador do agente lê esta definição para decidir quando usar a ferramenta. Boas definições de ferramentas são precisas e não deixam margem para dúvidas, de modo que o agente não irá adivinhá-las ou utilizá-las indevidamente. Eles também estabelecem limites, como quantas vezes uma ferramenta pode ser chamada ou quantos dados podem ser extraídos, o que ajuda a controlar custos e erros. Pense na definição de uma ferramenta como um cartão de receita que o agente segue sempre que precisa dessa habilidade.
