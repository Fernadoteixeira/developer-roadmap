# O que são ferramentas?

Ferramentas são habilidades ou recursos extras que um agente de IA pode utilizar para concluir um trabalho. Uma ferramenta pode ser qualquer coisa, desde uma API de pesquisa na web até uma calculadora, um banco de dados ou um mecanismo de tradução de idiomas. O agente envia uma solicitação à ferramenta, obtém o resultado e usa esse resultado para seguir em frente. As ferramentas permitem que um pequeno modelo central lide com tarefas que seriam difíceis ou lentas por conta própria. Eles também ajudam a manter as respostas atualizadas, precisas e baseadas em dados reais. Escolher a ferramenta certa e saber quando usá-la são partes essenciais para construir um agente inteligente.
