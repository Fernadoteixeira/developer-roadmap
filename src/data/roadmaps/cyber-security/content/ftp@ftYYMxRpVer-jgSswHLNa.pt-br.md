# Protocolo de transferência de arquivos (FTP)

FTP é um protocolo de rede padrão usado para transferir arquivos de um host para outro através de uma rede baseada em TCP, como a Internet. Originalmente desenvolvido na década de 1970, é um dos primeiros protocolos para transferência de arquivos entre computadores e continua amplamente utilizado até hoje.

O FTP opera em um modelo cliente-servidor, onde um computador atua como cliente (o remetente ou solicitante) e o outro atua como servidor (o receptor ou provedor). O cliente inicia uma conexão com o servidor, geralmente fornecendo um nome de usuário e uma senha para autenticação, e então solicita uma transferência de arquivo.
