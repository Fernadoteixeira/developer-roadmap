# JavaScript

JavaScript (frequentemente abreviado como JS) é uma linguagem de programação de alto nível amplamente utilizada. É predominantemente utilizado para criar e aprimorar os elementos interativos de páginas web, tornando-se parte integrante do espaço de desenvolvimento web. JavaScript era inicialmente conhecido como LiveScript e foi criado por Brendan Eich em 1995, mas mais tarde foi renomeado para JavaScript.
