# WPS

Wi-Fi Protected Setup (WPS) é um padrão de segurança de rede projetado para facilitar a conexão de dispositivos a uma rede sem fio segura. Ele permite que os usuários adicionem dispositivos a uma rede Wi-Fi usando um processo de configuração simples, normalmente envolvendo pressionar um botão WPS no roteador e no dispositivo ou inserir um PIN. Embora o WPS simplifique o processo de conexão, ele possui vulnerabilidades de segurança conhecidas, que podem ser potencialmente exploradas para obter acesso não autorizado à rede.
