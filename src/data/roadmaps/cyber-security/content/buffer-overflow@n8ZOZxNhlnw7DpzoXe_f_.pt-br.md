# Estouro de buffer

Buffer Overflow é um tipo de vulnerabilidade que ocorre quando um programa ou processo tenta gravar mais dados em um buffer – uma área de armazenamento temporário na memória – do que pode conter. Esse estouro pode fazer com que dados extras substituam locais de memória adjacentes, levando potencialmente a comportamento não intencional, falhas ou violações de segurança.
