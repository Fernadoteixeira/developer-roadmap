# Falso Negativo/Falso Positivo

Um falso positivo acontece quando a ferramenta de segurança identifica erroneamente uma não ameaça como uma ameaça. Por exemplo, pode disparar um alarme para a atividade de um usuário legítimo, indicando um ataque potencial quando não há nenhum. Um elevado número de falsos positivos pode causar desvio desnecessário de recursos e tempo, investigando falsos alarmes. Além disso, pode causar frustração ao usuário se atividades legítimas forem bloqueadas.

Um falso negativo ocorre quando a ferramenta de segurança não consegue detectar uma ameaça ou ataque real. Isso pode fazer com que um ataque real passe despercebido, causando danos ao sistema, violações de dados ou outras consequências negativas. Um elevado número de falsos negativos indica que o sistema de segurança precisa ser melhorado para capturar ameaças reais de forma eficaz.

Para ter um sistema de segurança cibernética eficaz, os profissionais de segurança visam maximizar os verdadeiros positivos e os verdadeiros negativos, ao mesmo tempo que minimizam os falsos positivos e os falsos negativos. Equilibrar esses aspectos garante que as ferramentas de segurança mantenham sua eficácia sem causar interrupções indevidas na experiência do usuário.
