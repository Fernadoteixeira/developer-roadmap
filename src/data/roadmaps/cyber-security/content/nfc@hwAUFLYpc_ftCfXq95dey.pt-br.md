# NFC

**Near Field Communication (NFC)** é uma tecnologia sem fio de curto alcance que permite que dispositivos se comuniquem e troquem dados em distâncias muito curtas, normalmente de até 10 cm (4 polegadas). NFC é comumente usado para aplicações como pagamentos sem contato, emissão de bilhetes eletrônicos e transferência de dados entre dispositivos. Ele opera a uma frequência de 13,56 MHz e suporta vários modos, incluindo comunicação ponto a ponto, emulação de cartão e modos de leitor/gravador. NFC permite interações rápidas e seguras com configuração mínima, tornando-o conveniente para pagamentos móveis, controle de acesso e compartilhamento de informações.
