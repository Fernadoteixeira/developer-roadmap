# O que é injeção SQL?

**Injeção de SQL** é um tipo de vulnerabilidade de segurança de aplicativos Web que permite que um invasor injete código SQL malicioso no banco de dados de um aplicativo Web, potencialmente levando ao acesso, modificação ou exclusão não autorizada de dados.
