# Baseado em MAC

**Controle de acesso obrigatório (MAC)** é um modelo de segurança no qual o acesso aos recursos é governado por políticas predefinidas definidas pelo sistema ou organização, e não por usuários individuais. No MAC, as decisões de acesso são baseadas em rótulos ou classificações de segurança atribuídos aos usuários e aos recursos, como níveis de sensibilidade ou níveis de autorização. Os usuários não podem alterar esses controles de acesso; eles são aplicados pelo sistema para manter padrões de segurança rígidos e impedir acesso não autorizado. O MAC é frequentemente usado em ambientes de alta segurança, como sistemas governamentais ou militares, para garantir que os dados e recursos sejam acessados ​​apenas por indivíduos com autorização apropriada.
