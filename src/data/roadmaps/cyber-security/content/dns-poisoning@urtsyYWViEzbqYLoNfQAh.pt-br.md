# Envenenamento de DNS/Spoofing de DNS/Envenenamento de cache DNS

A falsificação de DNS ou envenenamento de cache DNS ocorre quando informações falsas são inseridas no cache de um servidor DNS. Isso faz com que as consultas DNS retornem endereços IP incorretos, direcionando os usuários para sites errados. Os hackers exploram isso para redirecionar o tráfego para sites maliciosos. O problema persiste até que as informações armazenadas em cache sejam corrigidas. Quando o cache está envenenado, ele direciona mal o tráfego até que as informações incorretas sejam corrigidas. Esta técnica explora vulnerabilidades no sistema DNS e pode se espalhar para outros servidores, causando problemas generalizados.
