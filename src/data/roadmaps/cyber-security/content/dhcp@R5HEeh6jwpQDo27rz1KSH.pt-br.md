# Protocolo de configuração dinâmica de host (DHCP)

O Dynamic Host Configuration Protocol (DHCP) é um protocolo de gerenciamento de rede usado para atribuir automaticamente endereços IP e outros detalhes de configuração de rede, como máscaras de sub-rede, gateways padrão e servidores DNS, a dispositivos em uma rede. Quando um dispositivo, como um computador ou smartphone, se conecta a uma rede, ele envia uma solicitação ao servidor DHCP, que atribui dinamicamente um endereço IP disponível em um intervalo definido e fornece as informações de configuração necessárias. Este processo simplifica o gerenciamento da rede, eliminando a necessidade de atribuição manual de endereços IP e reduzindo o risco de conflitos de IP, garantindo que os dispositivos possam ingressar perfeitamente na rede e se comunicar com outros dispositivos e serviços.
