# Prevenção contra perda de dados (DLP)

Prevenção contra perda de dados (DLP) refere-se a um conjunto de estratégias, ferramentas e processos usados ​​pelas organizações para garantir que dados confidenciais não sejam perdidos, acessados ​​ou utilizados indevidamente por usuários não autorizados. As soluções DLP monitoram, detectam e bloqueiam a movimentação de informações críticas fora da rede de uma organização, ajudando a prevenir violações de dados, vazamentos e outros incidentes de segurança.
