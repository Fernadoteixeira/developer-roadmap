# Chave Privada vs Chave Pública

**Chaves públicas** e **chaves privadas** são componentes criptográficos usados ​​na criptografia assimétrica.

- **Chave Pública:** Esta chave é compartilhada abertamente e usada para criptografar dados ou verificar uma assinatura digital. Ele pode ser amplamente distribuído e usado por qualquer pessoa para enviar mensagens criptografadas ao proprietário da chave ou para verificar suas assinaturas digitais.

- **Chave Privada:** Esta chave é mantida em segredo pelo proprietário e é usada para descriptografar dados criptografados com a chave pública correspondente ou para criar uma assinatura digital. Deve ser protegido rigorosamente para manter a segurança das comunicações criptografadas e da autenticação.

Juntos, eles permitem comunicações e autenticação seguras, onde a chave pública criptografa ou verifica, e a chave privada descriptografa ou assina.
