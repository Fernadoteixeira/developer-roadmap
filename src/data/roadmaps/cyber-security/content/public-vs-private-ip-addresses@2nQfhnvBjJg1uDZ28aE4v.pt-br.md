# Endereços IP públicos versus privados

Endereços públicos são endereços IP atribuídos a dispositivos acessíveis diretamente pela Internet, permitindo-lhes comunicar com redes e serviços externos. Em contraste, os endereços privados são usados ​​em redes locais e não são roteáveis ​​pela Internet, proporcionando uma maneira para os dispositivos dentro de uma rede privada se comunicarem entre si enquanto conservam o espaço de endereços IP públicos. Os endereços públicos são únicos na Internet, enquanto os endereços privados são reutilizados em diferentes redes locais e normalmente são gerenciados pela tradução de endereços de rede (NAT) para fazer interface com redes públicas.
