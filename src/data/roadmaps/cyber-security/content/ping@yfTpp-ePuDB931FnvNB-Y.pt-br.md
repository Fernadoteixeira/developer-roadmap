# ping

**Ping** é um utilitário de rede usado para testar a acessibilidade e a capacidade de resposta de um dispositivo em uma rede. Ele envia pacotes de solicitação de eco do Internet Control Message Protocol (ICMP) para um host de destino e mede o tempo que leva para uma resposta de eco ser recebida. O Ping é comumente usado para diagnosticar problemas de conectividade de rede, determinar a latência da rede e verificar se um servidor ou dispositivo específico está online. Uma resposta de ping bem-sucedida indica que o dispositivo alvo está acessível, enquanto falhas ou atrasos podem sugerir problemas de rede, como perda de pacotes ou problemas de roteamento.
