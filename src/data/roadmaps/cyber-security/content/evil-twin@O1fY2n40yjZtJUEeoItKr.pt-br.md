# O que é o ataque Evil Twin

Um Evil Twin é um tipo de ataque à rede sem fio em que um invasor configura um ponto de acesso Wi-Fi não autorizado que imita uma rede Wi-Fi legítima. O ponto de acesso não autorizado tem o mesmo SSID (nome de rede) que a rede legítima, dificultando a distinção entre os dois pelos usuários. O objetivo do invasor é enganar os usuários para que se conectem ao ponto de acesso não autorizado, permitindo-lhes interceptar informações confidenciais, injetar malware ou lançar outros tipos de ataques.
