# Ataque Deauth

Um ataque de desautenticação (Deauth) é um tipo de ataque de negação de serviço (DoS) específico para redes sem fio. Envolve o envio de quadros de desautenticação falsos para um cliente ou ponto de acesso Wi-Fi, forçando o cliente a se desconectar da rede. O invasor utiliza essa técnica para interromper a comunicação entre o cliente e o ponto de acesso, muitas vezes com a intenção de capturar dados, lançar novos ataques ou simplesmente causar interrupção.
