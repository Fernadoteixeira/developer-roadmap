# Público

Uma **nuvem pública** é um serviço de computação oferecido por provedores terceirizados pela Internet, onde recursos como servidores, armazenamento e aplicativos são compartilhados entre vários usuários ou organizações. Normalmente é gerenciado pelo provedor de serviços em nuvem e oferece escalabilidade, economia e facilidade de acesso, com os usuários pagando apenas pelos recursos que consomem. As nuvens públicas são ideais para empresas e indivíduos que precisam de recursos de computação flexíveis e sob demanda, sem a sobrecarga do gerenciamento da infraestrutura física. Exemplos populares incluem Amazon Web Services (AWS), Microsoft Azure e Google Cloud Platform (GCP).
