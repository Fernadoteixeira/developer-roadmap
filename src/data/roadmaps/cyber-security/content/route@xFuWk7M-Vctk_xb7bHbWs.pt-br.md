# rota

O comando `route` é um utilitário de rede usado para visualizar e manipular a tabela de roteamento IP em sistemas Unix e Windows. Ele permite que os usuários exibam as rotas atuais que os pacotes de dados seguem, bem como adicionem, modifiquem ou excluam rotas para o tráfego de rede. Este comando é frequentemente usado na solução de problemas e configuração de rede para controlar como os dados fluem entre diferentes redes e sub-redes. Ao especificar rotas manualmente, os administradores podem definir caminhos específicos para o tráfego de rede, ignorando rotas padrão e otimizando o desempenho ou a segurança.
