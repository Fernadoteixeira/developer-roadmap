# SSH

SSH (Secure Shell) é um protocolo de rede criptográfico usado para login remoto seguro e outros serviços de rede seguros em uma rede não segura. Ele fornece um canal seguro em uma rede insegura usando criptografia forte para proteger a conexão contra espionagem, adulteração e ataques man-in-the-middle. SSH é comumente usado para login remoto de linha de comando, execução remota de comandos e transferências seguras de arquivos. Normalmente é executado na porta TCP 22 e substitui protocolos mais antigos e menos seguros, como o Telnet. O SSH usa criptografia de chave pública para autenticação e oferece suporte a vários métodos de autenticação, incluindo senhas e autenticação baseada em chave. É uma ferramenta fundamental para administradores de sistemas, desenvolvedores e qualquer pessoa que necessite de acesso remoto seguro aos sistemas.
