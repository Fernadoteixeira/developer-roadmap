# VirtualBox

VirtualBox é um software de virtualização gratuito e de código aberto desenvolvido pela Oracle. Ele permite que os usuários executem vários sistemas operacionais simultaneamente em uma única máquina física. O VirtualBox oferece suporte a uma ampla variedade de sistemas operacionais convidados, incluindo várias versões de Windows, Linux, macOS e muito mais. Ele fornece recursos como instantâneos para fácil preservação do estado do sistema, pastas compartilhadas para troca de arquivos entre sistemas host e convidados e suporte a dispositivos USB. O VirtualBox é popular entre desenvolvedores, profissionais de TI e entusiastas por testar software, executar aplicativos legados e experimentar diferentes sistemas operacionais sem a necessidade de hardware físico separado.
