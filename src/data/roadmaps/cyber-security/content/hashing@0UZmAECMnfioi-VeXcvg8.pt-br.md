# Hashing

Hashing é um processo criptográfico que converte dados de entrada de qualquer tamanho em uma sequência de caracteres de tamanho fixo, normalmente um número hexadecimal. Essa saída, chamada de valor hash ou resumo, é exclusiva dos dados de entrada e serve como uma impressão digital. Ao contrário da criptografia, o hash é um processo unilateral, o que significa que é computacionalmente inviável reverter o hash para obter os dados originais. Na segurança cibernética, o hashing é amplamente utilizado para armazenamento de senhas, verificação de integridade de dados e assinaturas digitais. Algoritmos de hash comuns incluem MD5 (agora considerado inseguro), SHA-256 e bcrypt. O hash ajuda a detectar alterações não autorizadas nos dados, pois mesmo uma pequena alteração na entrada produz um valor de hash significativamente diferente. No entanto, a força de uma função hash é crucial, uma vez que algoritmos fracos podem ser vulneráveis ​​a ataques de colisão, onde diferentes entradas produzem o mesmo hash, comprometendo potencialmente as medidas de segurança que dependem da singularidade dos valores hash.
