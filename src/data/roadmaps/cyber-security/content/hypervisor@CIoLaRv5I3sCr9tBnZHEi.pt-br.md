# Hipervisor

Um hipervisor, também conhecido como monitor de máquina virtual (VMM), é um software ou firmware que permite a criação e o gerenciamento de máquinas virtuais (VMs) abstraindo o hardware subjacente. Ele permite que várias VMs sejam executadas em uma única máquina física, cada uma operando de forma independente com seu próprio sistema operacional e aplicativos. Os hipervisores facilitam uma melhor utilização dos recursos, permitindo que um servidor físico hospede vários ambientes virtuais, otimizando a eficiência do hardware.
