# XSS

Cross-Site Scripting (XSS) é uma vulnerabilidade comum de aplicativos da web em que os invasores injetam scripts maliciosos no conteúdo de sites confiáveis. Esses scripts são executados nos navegadores das vítimas, potencialmente roubando dados confidenciais, sequestrando sessões de usuários ou desfigurando sites. Os ataques XSS vêm em três tipos principais: armazenados (persistentes), refletidos (não persistentes) e baseados em DOM. O XSS armazenado incorpora permanentemente código malicioso em um servidor, enquanto o XSS refletido ocorre quando a entrada do usuário é imediatamente retornada por um aplicativo da web. XSS baseado em DOM manipula o modelo de objeto de documento no navegador. As estratégias de prevenção incluem validação de entrada, codificação de saída e implementação de cabeçalhos de política de segurança de conteúdo para mitigar o risco de vulnerabilidades XSS.
