# Portas comuns e seus usos

Portas comuns são pontos finais de comunicação padronizados usados ​​por vários protocolos e serviços de rede. Na segurança cibernética, compreender essas portas é crucial para configurar firewalls, detectar ameaças potenciais e gerenciar o tráfego de rede. Algumas portas amplamente utilizadas incluem 80 e 443 para tráfego web HTTP e HTTPS, 22 para acesso remoto seguro SSH, 25 para transmissão de e-mail SMTP e 53 para resolução de nomes DNS. O FTP normalmente usa a porta 21 para controle e a 20 para transferência de dados, enquanto as portas 137-139 e 445 estão associadas ao compartilhamento de arquivos SMB. Os serviços de banco de dados geralmente usam portas específicas, como 3306 para MySQL e 1433 para Microsoft SQL Server. Os profissionais de segurança cibernética devem estar familiarizados com essas portas comuns e com seus comportamentos esperados para monitorar com eficácia as atividades de rede, identificar anomalias e proteger os sistemas contra possíveis ataques direcionados a serviços específicos.
