# SSO

Single Sign-On (SSO) é um método de autenticação que permite aos usuários acessar vários aplicativos ou sistemas com um conjunto de credenciais de login. Ele permite que os usuários façam login uma vez e obtenham acesso a vários sistemas conectados sem inserir novamente as credenciais. O SSO aprimora a experiência do usuário reduzindo o cansaço das senhas, simplifica o gerenciamento de acesso para departamentos de TI e pode melhorar a segurança centralizando os controles de autenticação. Normalmente usa protocolos como SAML, OAuth ou OpenID Connect para compartilhar com segurança informações de autenticação entre diferentes domínios. Embora o SSO ofereça conveniência e possa fortalecer a segurança quando implementado corretamente, ele também apresenta um ponto único de falha se comprometido, tornando críticas medidas de segurança robustas para o sistema SSO.
