# Falsificação

Spoofing é uma forma de engano em que alguém ou algo finge ser outra pessoa, dispositivo ou entidade para enganar ou obter vantagem. Em tecnologia e segurança cibernética, muitas vezes envolve a falsificação de informações como endereço IP, e-mail ou site para induzir um usuário ou sistema a acreditar que está interagindo com uma fonte legítima. A falsificação pode ser usada para roubar dados confidenciais, obter acesso não autorizado ou interromper a comunicação.
