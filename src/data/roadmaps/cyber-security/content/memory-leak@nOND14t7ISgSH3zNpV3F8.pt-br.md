# Vazamento de memória

Um vazamento de memória ocorre quando um programa de computador consome memória, mas não consegue liberá-la de volta ao sistema operacional depois que ela não é mais necessária. Com o tempo, isso pode levar à redução do desempenho do sistema, ao aumento do uso de memória e, em casos graves, o programa ou sistema pode travar devido ao esgotamento da memória disponível.
