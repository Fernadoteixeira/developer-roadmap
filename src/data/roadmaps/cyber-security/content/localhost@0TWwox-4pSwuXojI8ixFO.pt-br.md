# localhost

**Localhost** refere-se ao nome de host padrão usado para acessar o computador local no qual um serviço ou aplicativo de rede está em execução. Ele resolve para o endereço IP de loopback `127.0.0.1` para IPv4 ou `::1` para IPv6. Ao se conectar a `localhost`, você está se comunicando efetivamente com sua própria máquina, permitindo testar e depurar serviços de rede ou aplicativos localmente sem acessar redes externas.
