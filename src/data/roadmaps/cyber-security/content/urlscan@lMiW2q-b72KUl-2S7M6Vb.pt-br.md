# urlscan.io

urlscan.io é um serviço gratuito para escanear e analisar sites. Quando um URL é enviado para urlscan.io, um processo automatizado navegará até o URL como um usuário normal e registrará a atividade que a navegação desta página cria. Isto inclui os domínios e IPs contactados, os recursos (JavaScript, CSS, etc) solicitados a esses domínios, bem como informações adicionais sobre a própria página. urlscan.io fará uma captura de tela da página, registrará o conteúdo do DOM, variáveis ​​globais JavaScript, cookies criados pela página e uma infinidade de outras observações. Se o site tiver como alvo os usuários de uma das mais de 900 marcas rastreadas pelo urlscan.io, ele será destacado como potencialmente malicioso nos resultados da verificação.
