# Roteador

Um roteador é um dispositivo de rede que direciona pacotes de dados entre diferentes redes, garantindo que eles cheguem ao seu destino. Opera na camada de rede (Camada 3) do modelo OSI e encaminha dados com base nos endereços IP de origem e destino. Os roteadores são essenciais para conectar dispositivos à Internet ou interligar várias redes. Eles mantêm uma tabela de roteamento para decidir o melhor caminho para os dados e podem atualizar rotas dinamicamente usando protocolos como RIP, OSPF ou BGP. Os roteadores também lidam com a tradução de endereços de rede (NAT), permitindo que vários dispositivos compartilhem um único endereço IP público. Muitos roteadores modernos oferecem Wi-Fi para conectividade sem fio e incluem segurança básica de firewall para proteger a rede contra ameaças.
