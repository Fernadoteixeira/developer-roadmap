# Verdadeiro Negativo / Verdadeiro Positivo

Um Verdadeiro Positivo ocorre quando um sistema de segurança identifica corretamente uma ameaça genuína ou atividade maliciosa. É um alerta preciso que detecta corretamente um incidente de segurança real. Por exemplo, um antivírus sinaliza corretamente um arquivo como malware. Um Verdadeiro Negativo ocorre quando um sistema de segurança identifica corretamente que não há ameaça, quando na verdade nenhuma ameaça existe. É a determinação precisa do sistema de que atividades normais e benignas não são um risco à segurança. Por exemplo, um firewall permitindo corretamente o tráfego de rede legítimo.

Tanto os Verdadeiros Positivos quanto os Verdadeiros Negativos representam avaliações corretas dos sistemas de segurança, contribuindo para a detecção eficaz de ameaças e minimizando alarmes falsos. Equilibrá-los com a minimização de falsos positivos e falsos negativos é crucial para o desempenho ideal do sistema de segurança.
