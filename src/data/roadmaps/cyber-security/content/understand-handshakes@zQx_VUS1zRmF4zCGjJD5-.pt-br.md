# Entenda apertos de mão

Em redes e segurança cibernética, um aperto de mão é um processo de estabelecimento de uma conexão segura entre duas partes antes do início da troca de dados. Normalmente envolve uma série de mensagens predefinidas trocadas para verificar identidades, concordar com parâmetros de comunicação e, às vezes, estabelecer chaves de criptografia. O exemplo mais comum é o handshake triplo TCP usado para iniciar uma conexão. Em protocolos criptográficos como TLS/SSL, os handshakes são mais complexos, envolvendo verificação de certificados e troca de chaves. Os handshakes são cruciais para garantir comunicações seguras e autenticadas, impedir acessos não autorizados e definir os parâmetros para uma transferência eficiente de dados em vários protocolos de rede e sistemas de segurança.
