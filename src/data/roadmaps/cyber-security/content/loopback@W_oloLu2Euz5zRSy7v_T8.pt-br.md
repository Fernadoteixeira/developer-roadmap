# loopback

**Loopback** refere-se a uma interface de rede especial usada para enviar tráfego de volta ao mesmo dispositivo para fins de teste e diagnóstico. O endereço de loopback para IPv4 é `127.0.0.1`, enquanto para IPv6 é `::1`. Quando um dispositivo envia uma solicitação ao endereço de loopback, os dados da rede não saem da máquina local; em vez disso, ele é processado internamente, permitindo que os desenvolvedores testem aplicativos ou serviços de rede sem a necessidade de acesso externo à rede. Loopback é comumente usado para simular tráfego de rede, verificar serviços locais ou depurar problemas localmente.
