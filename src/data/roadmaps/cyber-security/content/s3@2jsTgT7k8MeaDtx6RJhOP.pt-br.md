# S3

Amazon Simple Storage Service (S3) é um serviço de armazenamento em nuvem escalonável e baseado em objetos fornecido pela AWS. Ele permite aos usuários armazenar e recuperar grandes quantidades de dados, como arquivos, backups ou conteúdo de mídia, com alta durabilidade e disponibilidade. O S3 foi projetado para oferecer flexibilidade, permitindo que os usuários acessem dados de qualquer lugar via Internet, ao mesmo tempo que oferece recursos de segurança como criptografia e controles de acesso. É amplamente utilizado para armazenamento de dados, distribuição de conteúdo, recuperação de desastres e análise de big data, fornecendo armazenamento escalonável e econômico para uma variedade de aplicações.
