# gateway padrão

Um gateway padrão é um nó de rede, normalmente um roteador ou firewall, que serve como ponto de acesso ou intermediário entre uma rede local e redes externas, como a Internet. Quando um dispositivo em uma rede local precisa se comunicar com um dispositivo fora de sua própria sub-rede (como acessar um site ou enviar um e-mail), ele envia os dados para o gateway padrão, que então os encaminha para o destino externo apropriado. O gateway padrão atua como um diretor de tráfego, garantindo que os pacotes de dados sejam encaminhados corretamente entre a rede interna e as redes externas, tornando-o um componente crucial para permitir a comunicação além dos limites da rede local.
