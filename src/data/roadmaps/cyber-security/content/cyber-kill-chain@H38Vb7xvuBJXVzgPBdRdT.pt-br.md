# Cadeia de morte cibernética

A **Cyber ​​Kill Chain** é um modelo desenvolvido pela Lockheed Martin, uma importante empresa aeroespacial, de apoio militar e de segurança, para compreender e prevenir invasões cibernéticas em diversas redes e sistemas. Serve como uma estrutura para detalhar os estágios de um ataque cibernético, tornando mais fácil para os profissionais de segurança identificar, mitigar e prevenir ameaças.
