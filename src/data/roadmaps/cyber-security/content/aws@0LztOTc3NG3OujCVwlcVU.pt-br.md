# AWS

Amazon Web Services (AWS) é uma plataforma líder de computação em nuvem fornecida pela Amazon. Lançada em 2006, a AWS oferece uma ampla gama de serviços de TI sob demanda, como capacidade de computação, armazenamento, bancos de dados, redes e segurança, que permitem às organizações desenvolver, implantar e dimensionar aplicativos e infraestrutura de forma rápida e econômica.
