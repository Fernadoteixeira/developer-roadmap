# Ataque Drive-by

Drive-by Attack é um tipo de ataque cibernético em que código malicioso é automaticamente baixado e executado no sistema de um usuário simplesmente visitando um site comprometido ou malicioso. O usuário não precisa clicar em nada nem interagir com a página; apenas carregar o site é suficiente para desencadear o ataque.
