# nslookup

**nslookup** é um utilitário de rede usado para consultar servidores DNS (Domain Name System) em busca de informações sobre nomes de domínio e endereços IP. Ele permite que os usuários obtenham detalhes como mapeamentos de endereços IP para um determinado nome de domínio, pesquisas reversas para encontrar nomes de domínio associados a um endereço IP e tipos de registro DNS como registros A, MX e CNAME. O nslookup ajuda a solucionar problemas relacionados ao DNS, verificar configurações de DNS e analisar registros DNS. Ele pode ser executado a partir da linha de comando em vários sistemas operacionais, incluindo Windows, macOS e Linux.
