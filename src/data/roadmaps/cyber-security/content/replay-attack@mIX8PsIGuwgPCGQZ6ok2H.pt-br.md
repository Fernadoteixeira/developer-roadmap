# Ataque de repetição

Um Replay Attack é um tipo de ataque de rede em que um invasor intercepta e retransmite dados de comunicação legítimos, muitas vezes com o objetivo de obter acesso não autorizado a um sistema ou realizar ações não autorizadas. Neste ataque, o invasor captura uma transmissão de dados válida e a “reproduz” mais tarde, sem a necessidade de descriptografar ou alterar os dados, para induzir o destinatário a pensar que se trata de uma solicitação legítima.
