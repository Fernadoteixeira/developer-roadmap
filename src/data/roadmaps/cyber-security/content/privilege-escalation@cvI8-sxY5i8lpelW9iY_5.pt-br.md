# Escalação de privilégios

O escalonamento de privilégios é uma técnica em que um invasor aumenta seu nível de acesso dentro de um sistema, passando de permissões inferiores para permissões superiores, como de usuário padrão para administrador. Isto pode ser conseguido explorando vulnerabilidades do sistema, configurações incorretas ou falhas de segurança. É fundamental implementar fortes controles de acesso, aderir ao princípio do menor privilégio e atualizar e corrigir regularmente os sistemas para se defender contra tais ataques.
