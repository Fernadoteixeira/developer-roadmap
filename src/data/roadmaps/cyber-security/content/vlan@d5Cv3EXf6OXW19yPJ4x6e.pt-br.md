# VLAN

Uma rede local virtual (VLAN) é uma segmentação lógica de uma rede física, permitindo a existência de várias redes isoladas na mesma infraestrutura física. As VLANs agrupam dispositivos com base em função, departamento ou aplicativo, independentemente de sua localização física. Eles melhoram o desempenho da rede reduzindo o tráfego de transmissão, melhoram a segurança isolando sistemas sensíveis e fornecem flexibilidade no projeto e no gerenciamento da rede. As VLANs são configuradas em switches de rede usando o padrão IEEE 802.1Q, que adiciona tags aos quadros Ethernet para identificar a associação à VLAN. Esta tecnologia é crucial para uma administração de rede eficiente em grandes empresas, data centers e ambientes de rede complexos.
