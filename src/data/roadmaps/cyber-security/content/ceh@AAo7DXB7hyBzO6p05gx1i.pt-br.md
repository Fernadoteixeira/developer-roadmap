# CEH

**Certified Ethical Hacker (CEH)** é uma certificação avançada focada em equipar profissionais de segurança cibernética com o conhecimento e as habilidades necessárias para se defenderem contra o cenário de ameaças cibernéticas em constante evolução. Esta certificação é facilitada pelo EC-Council, uma organização reconhecida internacionalmente para certificações de segurança da informação.
