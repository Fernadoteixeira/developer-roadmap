# Linux

Linux é um kernel de sistema operacional de código aberto semelhante ao Unix, lançado pela primeira vez por Linus Torvalds em 1991. Ele forma o núcleo de vários sistemas operacionais conhecidos como distribuições Linux. O Linux é conhecido por sua estabilidade, segurança e flexibilidade, o que o torna popular para servidores, sistemas embarcados e, cada vez mais, para uso em desktops. Ele oferece suporte a uma ampla variedade de hardware e oferece interfaces de linha de comando poderosas junto com interfaces gráficas de usuário. O Linux segue os princípios do Unix, enfatizando a modularidade e a filosofia de “fazer uma coisa e fazê-la bem”. Sua natureza de código aberto permite desenvolvimento e personalização orientados pela comunidade. Linux é amplamente utilizado em computação em nuvem, supercomputadores e dispositivos Android e é um componente fundamental da pilha de servidores web LAMP (Linux, Apache, MySQL, PHP).
