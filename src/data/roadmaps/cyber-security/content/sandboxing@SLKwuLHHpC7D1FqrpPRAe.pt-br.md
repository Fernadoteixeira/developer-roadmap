# Sandbox

Sandboxing é uma técnica de segurança em que um programa ou código é isolado em um ambiente controlado, ou “sandbox”, para evitar que afete outras partes do sistema. Esse isolamento permite que códigos suspeitos ou não confiáveis, como software, scripts ou arquivos, sejam executados e analisados ​​com segurança, sem risco de danos ao sistema host. Sandboxing é comumente usado para detectar malware ou testar aplicativos potencialmente prejudiciais em segurança cibernética.
