# autópsia

Autopsy é uma plataforma forense digital versátil e poderosa de código aberto usada principalmente para resposta a incidentes, investigações de segurança cibernética e recuperação de dados. Como investigador, você pode utilizar o Autopsy para analisar de forma rápida e eficiente um sistema comprometido, extrair artefatos cruciais e gerar relatórios abrangentes. Integrado ao The Sleuth Kit e outros plug-ins, o Autopsy permite que os examinadores automatizem tarefas e se aprofundem na estrutura de um sistema para descobrir a causa raiz de um incidente.
