# IP

IP, ou Protocolo de Internet, é um conceito fundamental em segurança cibernética que se refere à forma como os dados são transferidos entre redes, especificamente a Internet. É um componente central da arquitetura da Internet e serve como o principal alicerce para a comunicação entre dispositivos conectados à rede. Um endereço IP é um identificador exclusivo atribuído a cada dispositivo conectado a uma rede, como um computador ou smartphone. Compreende uma série de números separados por pontos (por exemplo, 192.168.1.1). Os endereços IP podem ser IPv4 (32 bits) ou o formato IPv6 (128 bits) mais recente, que fornece mais endereços disponíveis. Eles permitem que dispositivos enviem e recebam pacotes de dados de e para outros dispositivos na Internet.
