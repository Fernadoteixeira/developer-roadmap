# CISM

O Certified Information Security Manager (CISM) é uma certificação avançada de segurança cibernética oferecida pela ISACA que se concentra no gerenciamento de segurança da informação. Ele foi projetado para profissionais que possuem um forte conhecimento de segurança da informação e são responsáveis ​​por supervisionar, projetar e gerenciar os programas de segurança da informação de uma organização.
