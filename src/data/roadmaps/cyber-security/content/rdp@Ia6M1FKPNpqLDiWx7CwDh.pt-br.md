# RDP

**Remote Desktop Protocol (RDP)** é um protocolo desenvolvido pela Microsoft que permite aos usuários acessar e controlar remotamente um computador em uma rede. Ele permite que os usuários interajam com um ambiente de área de trabalho remota como se estivessem sentados na frente do computador, fornecendo acesso a aplicativos, arquivos e recursos de rede. O RDP é comumente usado para administração remota, suporte técnico e trabalho remoto. Ele opera na porta TCP 3389 e suporta criptografia para transmissão segura de dados, embora medidas de segurança adequadas, como senhas fortes e autenticação multifator, sejam essenciais para evitar acesso não autorizado.
