# RAIO

**RADIUS (Remote Authentication Dial-In User Service)** é um protocolo de rede que fornece gerenciamento centralizado de autenticação, autorização e contabilidade (AAA) para usuários que se conectam e usam um serviço de rede. É comumente usado para gerenciar o acesso a recursos de rede, como VPNs, Wi-Fi e serviços dial-up. Os servidores RADIUS validam as credenciais do usuário, aplicam políticas de acesso e registram as atividades do usuário. Ele opera nas portas UDP 1812 (autenticação) e 1813 (contabilidade) e suporta criptografia para transmitir com segurança credenciais e dados do usuário.
