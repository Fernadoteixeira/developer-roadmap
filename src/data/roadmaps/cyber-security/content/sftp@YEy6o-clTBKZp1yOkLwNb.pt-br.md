# SFTP

SFTP (SSH File Transfer Protocol) é um protocolo seguro de transferência de arquivos que fornece acesso, transferência e gerenciamento de arquivos em um fluxo de dados confiável. Ele é executado no protocolo SSH, normalmente na porta 22, garantindo transferências de arquivos criptografados. O SFTP oferece segurança mais forte do que o FTP tradicional, criptografando comandos e dados em trânsito, evitando interceptações não autorizadas. Ele oferece suporte a recursos como retomada de transferências interrompidas, listagens de diretórios e operações remotas do sistema de arquivos. O SFTP é amplamente utilizado para transferências seguras de arquivos em vários ambientes, desde hospedagem na web até gerenciamento de dados corporativos, oferecendo uma alternativa mais segura ao FTP, mantendo funcionalidades semelhantes. Sua integração com SSH o torna a escolha preferida para transferências seguras e autenticadas de arquivos em muitas configurações de rede.
