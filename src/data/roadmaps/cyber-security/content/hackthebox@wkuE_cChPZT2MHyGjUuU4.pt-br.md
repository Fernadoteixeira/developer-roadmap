# HackTheBox

Hack The Box (HTB) é uma plataforma online popular projetada para entusiastas de segurança, testadores de penetração e hackers éticos para desenvolver e aprimorar suas habilidades, envolvendo-se em desafios de segurança cibernética do mundo real. A plataforma oferece uma ampla variedade de máquinas virtuais (VMs), conhecidas como “caixas”, cada uma com um conjunto exclusivo de vulnerabilidades de segurança para explorar.
