# LOLBAS

**LOLBAS** (Living Off the Land Binaries and Scripts) refere-se a uma coleção de binários e scripts de sistema legítimos que podem ser usados ​​de forma abusiva por invasores para executar ações maliciosas enquanto evitam a detecção. Essas ferramentas, que muitas vezes fazem parte do sistema operacional ou do software instalado, podem ser aproveitadas para diversos fins, como executar comandos, acessar dados ou modificar configurações do sistema, permitindo assim que invasores realizem suas atividades sem implantar malware personalizado. O uso de técnicas LOLBAS torna mais difícil para as soluções de segurança tradicionais detectar e prevenir atividades maliciosas, uma vez que os binários e scripts usados ​​são normalmente confiáveis ​​e considerados legítimos.
