# Entenda o modelo OSI

O modelo OSI (Open Systems Interconnection) é uma estrutura conceitual que descreve como ocorre a comunicação de dados entre dispositivos em uma rede. É composto por sete camadas, cada uma com funções específicas:

1. Físico: Lida com meios físicos de transmissão
2. Data Link: Lida com transferência sem erros entre nós adjacentes
3. Rede: gerencia endereçamento e roteamento
4. Transporte: Garante entrega de dados ponta a ponta e controle de fluxo
5. Sessão: estabelece, gerencia e encerra conexões
6. Apresentação: Formata e criptografa dados para a camada de aplicação
7. Aplicação: Fornece serviços de rede para aplicativos de usuário final
