# netstat

**netstat** (estatísticas de rede) é uma ferramenta de linha de comando usada para exibir conexões de rede, tabelas de roteamento e estatísticas de interface de rede. Ele fornece informações sobre conexões TCP e UDP ativas, portas de escuta e o status das interfaces de rede. Ao usar o **netstat**, os usuários podem monitorar a atividade da rede, diagnosticar problemas de conectividade e identificar portas abertas e serviços em execução em um sistema. A ferramenta está disponível em vários sistemas operacionais, incluindo Windows, macOS e Linux, e é frequentemente empregada para solução de problemas de rede e avaliações de segurança.
