# VirusTotal

O principal recurso do VirusTotal é a verificação múltipla usando mais de 70 scanners antivírus para gerar um relatório cumulativo sobre se um arquivo é malicioso. Ele também armazena hashes de arquivos, eliminando a necessidade de verificar novamente os arquivos carregados anteriormente. Os pesquisadores podem comentar na comunidade, compartilhando suas análises e insights sobre malware para que outros possam se beneficiar. Os dados agregados do VirusTotal vêm de vários mecanismos antivírus, scanners de sites, ferramentas de análise de arquivos e URL e contribuições de usuários. Essas ferramentas atendem a diversos propósitos, incluindo mecanismos heurísticos, assinaturas reconhecidamente inválidas, extração de metadados e identificação de sinais maliciosos. Além disso, o VirusTotal oferece serviços de pesquisa por hash de arquivo, endereço IP e URL, que também são verificados. Para recursos mais abrangentes, o VirusTotal oferece serviços Premium, como Inteligência e Caça.
