# Kerberos

Kerberos é um protocolo de autenticação de rede projetado para fornecer autenticação forte para aplicativos cliente/servidor. Foi desenvolvido pelo MIT na década de 1980 e recebeu o nome do cão de três cabeças da mitologia grega que guardava os portões do Hades, simbolizando o objetivo do protocolo de fornecer autenticação segura em um ambiente de rede potencialmente hostil.
