# Negação de serviço (DoS) vs Negação de serviço distribuída (DDoS)

A negação de serviço (DoS) e a negação de serviço distribuída (DDoS) são tipos de ataques cibernéticos que visam interromper o funcionamento normal de um serviço direcionado, normalmente um site ou rede. Um ataque DoS envolve uma única fonte sobrecarregando um sistema com uma enxurrada de solicitações ou dados maliciosos, esgotando seus recursos e tornando-o indisponível para usuários legítimos. Em contraste, um ataque DDoS amplifica esta perturbação ao utilizar vários dispositivos comprometidos, muitas vezes formando uma botnet, para lançar um ataque coordenado a partir de inúmeras fontes simultaneamente. Esta natureza distribuída torna os ataques DDoS mais difíceis de mitigar, uma vez que o tráfego vem de muitos locais diferentes, dificultando a identificação e o bloqueio do tráfego malicioso. Ambos os tipos de ataques podem causar tempo de inatividade significativo, perdas financeiras e danos à reputação da organização visada.
