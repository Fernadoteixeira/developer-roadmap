# HTTP/HTTPS

HTTP (Hypertext Transfer Protocol) e HTTPS (HTTP Secure) são protocolos fundamentais para comunicação na web. HTTP é a base para a troca de dados na World Wide Web, permitindo que os navegadores solicitem recursos de servidores web. No entanto, o HTTP transmite dados em texto simples, tornando-o vulnerável a espionagem e ataques man-in-the-middle. O HTTPS aborda essas questões de segurança adicionando uma camada de criptografia usando SSL/TLS (Secure Sockets Layer/Transport Layer Security). Essa criptografia protege a confidencialidade e a integridade dos dados em trânsito, protegendo informações confidenciais, como credenciais de login e transações financeiras. HTTPS também fornece autenticação, garantindo que os usuários estejam se comunicando com o site pretendido. Nos últimos anos, tem havido um impulso significativo para a adoção de HTTPS em toda a web, com os principais navegadores marcando sites HTTP como “não seguros”. Essa mudança melhorou bastante a segurança geral da web, embora seja importante observar que o HTTPS protege a conexão, não necessariamente o conteúdo do site em si.
