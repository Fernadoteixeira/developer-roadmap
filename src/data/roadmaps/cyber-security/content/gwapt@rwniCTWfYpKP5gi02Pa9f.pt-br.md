# GWAPT

A certificação GIAC Web Application Penetration Tester (GWAPT) valida a capacidade de um indivíduo de realizar avaliações detalhadas de segurança de aplicativos da Web e explorar vulnerabilidades. O GWAPT se concentra no uso de metodologias de hacking ético para conduzir testes de penetração de aplicativos da web com o objetivo de identificar, avaliar e mitigar riscos de segurança.
