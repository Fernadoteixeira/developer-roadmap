# LDAP

LDAP (Lightweight Directory Access Protocol) é um protocolo de aplicação padronizado para acessar e manter serviços de informações de diretório distribuídos em uma rede IP. É usado principalmente para consultar e modificar serviços de diretório, como autenticação de usuário e pesquisa de informações. O LDAP organiza os dados em uma estrutura de árvore hierárquica e é comumente usado em ambientes corporativos para gerenciamento centralizado de usuários, autenticação e autorização. Ele oferece suporte a recursos como logon único e pode ser integrado a vários aplicativos e serviços. O LDAP é amplamente utilizado em conjunto com o Active Directory e outros serviços de diretório para fornecer um repositório centralizado para contas de usuários, grupos e outros dados organizacionais, facilitando o gerenciamento eficiente de usuários e recursos em ambientes de rede.
