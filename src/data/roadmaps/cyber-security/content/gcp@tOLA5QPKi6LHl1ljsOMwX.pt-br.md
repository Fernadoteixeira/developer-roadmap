# GCP

Google Cloud Platform (GCP) é uma coleção de serviços de computação em nuvem oferecidos pelo Google, que fornece infraestrutura e serviços de plataforma para empresas ou indivíduos. Ele permite que os usuários criem seus próprios aplicativos ou serviços com base nos recursos fornecidos ou utilizem serviços prontos para uso fornecidos pelo Google. O GCP abrange uma ampla variedade de serviços, incluindo (mas não limitado a) computação, armazenamento, bancos de dados, redes e muito mais.
