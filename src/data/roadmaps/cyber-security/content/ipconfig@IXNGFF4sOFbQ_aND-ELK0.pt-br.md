# ipconfig

`ipconfig` é um utilitário de linha de comando amplamente utilizado para sistemas operacionais Windows que fornece informações valiosas sobre a configuração de rede de um computador. Pode ser extremamente útil para tarefas de resposta e descoberta de incidentes ao investigar problemas relacionados à rede, extrair detalhes cruciais da rede ou ao tentar determinar o endereço IP de uma máquina.
