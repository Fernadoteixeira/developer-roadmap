# tracert

Tracert (traceroute em sistemas baseados em Unix) é uma ferramenta de diagnóstico de rede usada para rastrear o caminho que os pacotes de dados percorrem de um computador de origem até um host de destino. Ele mostra o número de saltos (roteadores intermediários) percorridos, os endereços IP desses roteadores e o tempo de ida e volta para cada salto. O Tracert funciona enviando pacotes com valores crescentes de Time-To-Live (TTL), fazendo com que cada roteador ao longo do caminho responda. Essa ferramenta é valiosa para identificar gargalos de rede, identificar onde ocorre a perda de pacotes e compreender o caminho de roteamento do tráfego de rede. É comumente usado para solucionar problemas de conectividade de rede, analisar o desempenho da rede e mapear a topologia da rede.
