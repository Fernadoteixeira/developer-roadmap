# WADCOMS

WADcoms (Web Application Dangerous Commands) é um banco de dados abrangente de comandos e padrões perigosos de aplicativos da web que podem ser explorados para comprometer a segurança da web. Ele oferece um catálogo de comandos potencialmente prejudiciais e seus contextos, ajudando os profissionais de segurança a identificar e mitigar riscos associados a aplicações web, entendendo como esses comandos podem ser usados ​​indevidamente para ataques como injeção de SQL, cross-site scripting (XSS) e execução remota de código (RCE).
