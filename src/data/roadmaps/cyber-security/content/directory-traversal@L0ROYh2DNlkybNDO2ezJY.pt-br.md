# Travessia de diretório

Directory Traversal, também conhecido como Path Traversal, é uma vulnerabilidade que permite que invasores leiam arquivos em um sistema sem a devida autorização. Esses ataques normalmente exploram caminhos não seguros usando sequências "../" (ponto-ponto-barra) e suas variações, ou caminhos de arquivo absolutos. O ataque também é conhecido como "barra ponto-ponto", "subida de diretório" ou "retrocesso".

Embora o Directory Traversal às vezes seja combinado com outras vulnerabilidades, como Inclusão de Arquivo Local (LFI) ou Inclusão de Arquivo Remoto (RFI), a principal diferença é que o Directory Traversal não executa código, enquanto o LFI e o RFI geralmente o fazem.
