# HOMEM

Uma **Metropolitan Area Network (MAN)** é um tipo de rede que abrange uma cidade ou um grande campus, conectando várias redes locais (LANs) dentro dessa área geográfica. Os MANs são projetados para fornecer transferência de dados e serviços de comunicação em alta velocidade para organizações, instituições ou empresas em uma cidade. Eles oferecem suporte a uma variedade de aplicações, incluindo acesso à Internet, conectividade à intranet e compartilhamento de dados entre vários locais. Normalmente, as MANs são mais rápidas e cobrem uma área mais ampla do que as LANs, mas têm escopo menor em comparação com as redes de longa distância (WANs).
