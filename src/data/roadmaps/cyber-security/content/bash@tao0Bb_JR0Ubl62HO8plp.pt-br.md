# Bash

Bash (Bourne Again Shell) é um shell Unix e uma linguagem de script amplamente usada que atua como uma interface de linha de comando para executar comandos e organizar arquivos em seu computador. Permite aos usuários interagir com o sistema operacional do sistema digitando comandos de texto, servindo como alternativa à interface gráfica do usuário (GUI). Bash, criado como uma versão gratuita e aprimorada do Bourne Shell original (`sh`), é o shell padrão em muitos sistemas baseados em Unix, incluindo Linux, macOS e Windows Subsystem for Linux (WSL).
