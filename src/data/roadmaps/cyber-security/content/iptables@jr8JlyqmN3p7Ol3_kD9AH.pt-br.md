# iptables

IPTables é um utilitário de linha de comando para configurar e gerenciar regras de filtragem de pacotes no sistema operacional Linux. Ele permite que o administrador do sistema defina e gerencie as regras de firewall que controlam o tráfego de entrada e saída da rede. IPTables é uma ferramenta essencial para proteger sistemas Linux e garantir o fluxo adequado de tráfego de rede.
