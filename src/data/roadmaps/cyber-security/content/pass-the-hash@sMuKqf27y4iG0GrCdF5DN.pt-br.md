# Passe o Hash

Pass the Hash (PtH) é uma técnica de hacking que permite que um invasor se autentique em um servidor ou serviço remoto usando o valor hash da senha de um usuário, sem precisar saber a senha real em texto simples. Este método explora pontos fracos na forma como alguns protocolos de autenticação lidam com credenciais com hash, especialmente em sistemas baseados em Windows.
