# CISSP

O Certified Information Systems Security Professional (CISSP) é uma certificação reconhecida globalmente oferecida pelo International Information System Security Certification Consortium (ISC)². Ele foi projetado para profissionais de segurança experientes validarem seu conhecimento e experiência na área de segurança da informação.

Saiba mais com os seguintes recursos:

- [@official@Certificação CISSP](https://www.isc2.org/certifications/cissp)
