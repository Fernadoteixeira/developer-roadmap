# GTFOBINS

GTFOBins (GTFOBINS) é uma lista selecionada de binários Unix que podem ser explorados por invasores para contornar restrições de segurança locais em um sistema mal configurado. Ele fornece um índice detalhado de comandos e scripts, demonstrando como certos binários, quando usados ​​indevidamente, podem permitir escalonamento de privilégios, manipulação de arquivos e outras atividades não autorizadas, servindo assim como um recurso para profissionais de segurança entenderem vulnerabilidades potenciais e para invasores identificarem e explorarem pontos fracos.
