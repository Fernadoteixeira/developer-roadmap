# NAT

**Network Address Translation (NAT)** é um método usado para modificar informações de endereço IP em cabeçalhos de pacotes enquanto eles estão em trânsito em uma rede. O NAT permite que vários dispositivos em uma rede privada compartilhem um único endereço IP público para acessar recursos externos, ajudando a conservar o número limitado de endereços IP públicos disponíveis. Também aumenta a segurança, ocultando endereços IP internos da Internet pública. Os tipos comuns de NAT incluem **NAT estático** (mapeamento um para um), **NAT dinâmico** (mapeamento muitos para muitos) e **Conversão de endereço de porta (PAT)** ou **Sobrecarga de NAT** (mapeamento muitos para um, comumente usado em roteadores domésticos).
