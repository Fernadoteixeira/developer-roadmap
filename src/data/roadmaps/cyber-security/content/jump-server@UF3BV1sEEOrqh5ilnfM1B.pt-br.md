# Servidor de Salto

Um **servidor de salto**, também conhecido como **bastion host** ou **host de salto**, é um componente de segurança crítico em muitas arquiteturas de rede. É um servidor dedicado, bloqueado e seguro que fica dentro de uma rede protegida e fornece um ponto de acesso controlado para usuários e administradores acessarem componentes específicos do sistema. Este servidor intermediário atua como uma ponte entre redes não confiáveis ​​e os sistemas internos privilegiados, reduzindo assim a superfície de ataque e protegendo o ambiente.
