# SSL/TLS

Secure Sockets Layer (SSL) e Transport Layer Security (TLS) são protocolos criptográficos usados ​​para fornecer segurança nas comunicações pela Internet. Esses protocolos criptografam os dados transmitidos pela web, de forma que qualquer pessoa que tentar interceptar pacotes não conseguirá interpretar os dados. Uma diferença que é importante saber é que o SSL agora está obsoleto devido a falhas de segurança, e a maioria dos navegadores modernos não o suporta mais. Mas o TLS ainda é seguro e amplamente suportado, portanto, use preferencialmente o TLS.
