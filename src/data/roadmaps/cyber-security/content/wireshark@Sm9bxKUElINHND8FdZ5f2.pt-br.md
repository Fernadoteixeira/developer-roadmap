# Wireshark

Wireshark é um poderoso analisador de protocolo de rede de código aberto usado para captura e análise de pacotes em tempo real. Ele permite que os usuários examinem o tráfego de rede em um nível microscópico, capturando e navegando interativamente no tráfego executado em uma rede de computadores. O Wireshark pode decodificar uma ampla variedade de protocolos de rede, tornando-o uma ferramenta essencial para solução de problemas de rede, análise de segurança, desenvolvimento de software e protocolo e educação. Ele fornece uma interface gráfica amigável e oferece recursos como inspeção profunda de centenas de protocolos, captura ao vivo e análise offline, além da capacidade de ler/gravar muitos formatos de arquivo de captura diferentes. O Wireshark é amplamente utilizado por profissionais de TI, especialistas em segurança e desenvolvedores para diagnosticar problemas de rede e compreender a comunicação em rede.
