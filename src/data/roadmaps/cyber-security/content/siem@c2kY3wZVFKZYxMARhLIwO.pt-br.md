# SIEM

SIEM, abreviação de Security Information and Event Manager, é um termo usado para descrever ferramentas que aumentam muito a visibilidade de uma rede ou sistema. Ele faz isso monitorando, filtrando, coletando, normalizando e correlacionando grandes quantidades de dados, como logs, e os apresenta de maneira organizada por meio de uma interface/painel. As organizações aproveitam os SIEMs para monitorar e, assim, identificar, proteger e responder a ameaças potenciais em seu ambiente. Para obter experiência prática, considere configurar um SIEM em seu próprio ambiente. Existem algumas ferramentas comerciais que você pode experimentar gratuitamente e também existem alternativas de código aberto, como Wazuh ou LevelBlue OSSIM (AlienVault).
