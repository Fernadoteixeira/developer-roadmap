# Componentes de hardware de computador

Componentes de hardware de computador são as partes físicas de um sistema de computador que trabalham juntas para executar tarefas de computação. Os principais componentes incluem a **unidade central de processamento (CPU)**, que é o “cérebro” do computador responsável pela execução de instruções e processamento de dados. A **placa-mãe** é a placa de circuito principal que conecta e permite a comunicação entre a CPU, a memória e outros hardwares. **Memória de acesso aleatório (RAM)** serve como memória de curto prazo do computador, armazenando dados que estão sendo usados ​​ativamente pela CPU para acesso rápido.

O **dispositivo de armazenamento**, como uma unidade de disco rígido (HDD) ou unidade de estado sólido (SSD), é onde os dados são armazenados permanentemente, incluindo o sistema operacional, aplicativos e arquivos. A **unidade de fonte de alimentação (PSU)** fornece a energia elétrica necessária para operar os componentes. **Unidades de processamento gráfico (GPU)**, dedicadas à renderização de imagens e vídeos, são importantes para tarefas como jogos, edição de vídeo e aprendizado de máquina. Além disso, **dispositivos de entrada** como teclados e mouses e **dispositivos de saída** como monitores e impressoras permitem que os usuários interajam com o sistema. Juntos, esses componentes constituem o hardware essencial de um computador, permitindo-lhe executar diversas funções computacionais.
