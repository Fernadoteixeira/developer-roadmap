# Ir

Go, também conhecido como Golang, é uma linguagem de programação de código aberto criada pelo Google. Lançado em 2009, foi projetado para superar problemas presentes em outras linguagens e oferecer uma experiência de desenvolvimento mais segura, robusta e eficiente.
