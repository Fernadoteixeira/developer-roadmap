# Salga

Salting é um conceito crucial no domínio da criptografia. É uma técnica empregada para aumentar a segurança de senhas ou dados confidenciais equivalentes, adicionando uma camada extra de proteção para protegê-los contra tentativas de hacking, como ataques de força bruta ou ataques de dicionário.
