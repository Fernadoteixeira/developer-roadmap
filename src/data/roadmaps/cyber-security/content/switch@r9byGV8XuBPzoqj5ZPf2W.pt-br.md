# Trocar

Um switch é um dispositivo de rede que opera na camada de enlace de dados (Camada 2) do modelo OSI, conectando vários dispositivos dentro de uma rede local (LAN). Ele usa endereços MAC para encaminhar pacotes de dados entre dispositivos, criando domínios de colisão separados para cada porta. Os switches melhoram a eficiência da rede enviando pacotes apenas para os destinos pretendidos, reduzindo o tráfego desnecessário. Eles suportam comunicação full-duplex, permitindo a transmissão simultânea de dados em ambas as direções. Os switches modernos geralmente incluem recursos avançados como VLANs, espelhamento de portas e gerenciamento de qualidade de serviço (QoS). Os switches são fundamentais para a criação de redes segmentadas e eficientes e são componentes cruciais em infraestruturas de rede de pequenos escritórios e grandes empresas.
