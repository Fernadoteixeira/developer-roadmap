# DMZ

Uma **DMZ**, também conhecida como **Zona Desmilitarizada**, é uma parte específica de uma rede que funciona como um buffer ou separação entre a rede interna confiável de uma organização e as redes externas não confiáveis, como a Internet. O objetivo principal de uma DMZ é isolar sistemas e dados críticos do ambiente externo potencialmente hostil e fornecer uma camada extra de segurança.
