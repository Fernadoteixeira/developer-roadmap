# enrolar

cURL é uma ferramenta versátil de linha de comando usada principalmente para transferência de dados usando vários protocolos de rede. É amplamente utilizado em segurança cibernética e desenvolvimento com a finalidade de testar e interagir com serviços da web, APIs e examinar a segurança de aplicativos da web. Curl oferece suporte a vários protocolos, como HTTP, HTTPS, FTP, SCP, SFTP e muitos mais.
