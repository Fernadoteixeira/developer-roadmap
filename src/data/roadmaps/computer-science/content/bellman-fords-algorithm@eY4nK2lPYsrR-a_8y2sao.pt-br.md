# Algoritmo de Bellman Ford

O algoritmo de Bellman Ford é um algoritmo de gráfico que encontra o caminho mais curto de um vértice de origem para todos os outros vértices em um gráfico. É um algoritmo de programação dinâmica que usa uma abordagem bottom-up para encontrar o caminho mais curto. É semelhante ao algoritmo de Dijkstra, mas pode lidar com pesos negativos. Também é semelhante ao algoritmo de Floyd-Warshall, mas pode lidar com pesos negativos e é mais rápido que o algoritmo de Floyd-Warshall.
