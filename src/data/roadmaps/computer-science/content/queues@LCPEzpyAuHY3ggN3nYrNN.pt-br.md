# Caudas

As filas de mensagens são uma forma comum de desacoplar sistemas. Eles são usados ​​para dissociar o produtor de uma mensagem do consumidor de uma mensagem. Isso permite que o produtor envie uma mensagem e não precise esperar que o consumidor a processe. Também permite que o consumidor processe a mensagem em seu próprio ritmo.
