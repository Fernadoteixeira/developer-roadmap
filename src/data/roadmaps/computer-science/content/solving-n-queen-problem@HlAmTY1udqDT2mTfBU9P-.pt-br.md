# Resolvendo o Problema da Rainha

N Queen Problem é um problema famoso em Ciência da Computação. É um problema de colocar n rainhas em um tabuleiro de xadrez nxn de modo que não haja duas rainhas atacando uma à outra. O problema é encontrar todas as soluções possíveis para o problema.
