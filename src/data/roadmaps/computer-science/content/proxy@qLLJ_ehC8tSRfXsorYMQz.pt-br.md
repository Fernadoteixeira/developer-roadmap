# Proxy

Um servidor proxy é uma peça intermediária de hardware/software situada entre o cliente e o servidor back-end. Ele recebe solicitações de clientes e as retransmite aos servidores de origem. Normalmente, os proxies são usados ​​para filtrar solicitações, registrar solicitações ou, às vezes, transformar solicitações (adicionando/removendo cabeçalhos, criptografando/descriptografando ou compactando).
