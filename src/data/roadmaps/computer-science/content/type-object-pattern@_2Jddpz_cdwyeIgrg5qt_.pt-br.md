# Padrão Type Object

O padrão Type Object é um padrão de projeto estrutural/criacional que permite definir novos "tipos" de objetos dinamicamente em tempo de execução sem criar novas classes no código-fonte. Ele separa a classe genérica das instâncias que representam tipos específicos de comportamento e atributos.
