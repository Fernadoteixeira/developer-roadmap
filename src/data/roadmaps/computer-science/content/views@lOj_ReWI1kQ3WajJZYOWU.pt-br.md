# Views em Banco de Dados

Views (visões) em SQL são tabelas virtuais baseadas no conjunto de resultados de uma consulta SQL. Elas possuem linhas e colunas como uma tabela real do banco de dados e permitem simplificar consultas complexas, restringir o acesso a dados e apresentar dados agregados.
