# Algoritmo de Rabin-Karp

O algoritmo Rabin-Karp é um algoritmo de busca de strings que usa hashing para encontrar qualquer um de um conjunto de strings padrão em um texto. Para strings de comprimento médio `n`, ele executa em tempo `O(n+m)` com espaço `O(m)`, onde `m` é o comprimento do padrão. É frequentemente usado em bioinformática para procurar padrões de DNA.
