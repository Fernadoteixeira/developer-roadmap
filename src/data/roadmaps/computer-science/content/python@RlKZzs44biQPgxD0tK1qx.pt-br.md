# Píton

Python é uma linguagem de programação bem conhecida, que é ao mesmo tempo uma linguagem fortemente tipada e dinamicamente tipada. Por ser uma linguagem interpretada, o código é executado assim que é escrito e a sintaxe Python permite escrever código de forma programática funcional, processual ou orientada a objetos.
