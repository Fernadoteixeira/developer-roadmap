# Pilha

Pilha é uma coleção linear de itens onde os itens são inseridos e removidos em uma ordem específica. A pilha também é chamada de estrutura de dados LIFO porque segue o princípio "Último a entrar, primeiro a sair", ou seja, o item inserido por último é aquele que é retirado primeiro.
