# Padrões Arquitetônicos

Os padrões arquitetônicos são padrões de design de alto nível que se concentram na estrutura geral do sistema. Eles são semelhantes aos padrões de projeto, mas estão mais preocupados com a estrutura do sistema. Eles são usados ​​para resolver problemas comuns a muitos sistemas de software.
