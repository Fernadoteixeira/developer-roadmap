# Teorema PACELC

O Teorema PACELC é uma extensão do Teorema CAP. Uma das questões que o Teorema CAP não conseguiu responder foi “o que acontece quando não há partição, que combinação lógica um sistema distribuído tem?”. Então, para responder a isso, além de Consistência, Disponibilidade e Tolerância de Partição, também inclui Latência como uma das propriedades desejadas de um Sistema Distribuído. A sigla PACELC significa Particionado, Disponibilidade, Consistência, Else Latência, Consistência.
