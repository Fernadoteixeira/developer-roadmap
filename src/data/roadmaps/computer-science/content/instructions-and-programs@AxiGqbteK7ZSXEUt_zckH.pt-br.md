# Instruções e Programas

As instruções são os comandos mais básicos que uma CPU pode entender, direcionando-a para executar ações específicas, como adicionar números ou mover dados. Um programa, por outro lado, é uma coleção dessas instruções, organizadas em sequência para realizar uma tarefa específica. Pense nas instruções como palavras individuais e no programa como uma frase ou história completa; a CPU executa essas instruções uma por uma, seguindo a lógica do programa, para atingir o resultado desejado.
