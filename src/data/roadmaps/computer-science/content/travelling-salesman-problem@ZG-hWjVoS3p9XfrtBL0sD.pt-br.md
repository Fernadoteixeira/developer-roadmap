# Problema do Cixeiro Viajante

O Problema do Caxeiro Viajante (TSP - Travelling Salesman Problem) é um problema clássico da ciência da computação e otimização combinatória. É um problema NP-difícil que busca encontrar a rota mais curta possível que visite uma lista de cidades e retorne à cidade de origem.
