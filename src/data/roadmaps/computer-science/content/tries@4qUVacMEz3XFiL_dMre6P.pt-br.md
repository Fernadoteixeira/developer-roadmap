# Tries (Árvores de Prefixos)

Tries (ou árvores prefixadas) são uma estrutura de dados de árvore ordenada usada para armazenar e buscar cadeias de caracteres (strings). Cada nó representa um caractere, permitindo busca rápida de prefixos comuns e autocompletar eficiente.
