# C++

C++ é uma poderosa linguagem de programação de uso geral. Ele pode ser usado para desenvolver sistemas operacionais, navegadores, jogos e assim por diante. C++ oferece suporte a diferentes formas de programação, como processual, orientada a objetos, funcional e assim por diante. Isso torna o C++ poderoso e flexível.
