# Pesquisa de substring

A pesquisa de substring é o problema de encontrar uma substring em uma string. Este é um problema muito comum na ciência da computação e existem muitos algoritmos para resolvê-lo.

Visite os seguintes recursos para saber mais:

- [@article@Qual é o algoritmo de pesquisa de substring mais rápido?](https://stackoverflow.com/questions/3183582/what-is-the-fastest-substring-search-algorithm)
- [@article@Substring Search - Exercícios](https://algs4.cs.princeton.edu/53substring/)
