# A\* Algoritmo

A\* é um algoritmo de passagem de gráfico usado para encontrar o caminho mais curto entre dois nós em um gráfico. É uma versão modificada do algoritmo de Dijkstra que utiliza heurística para encontrar o caminho mais curto. É usado em pathfinding e travessia de gráfico.
