# Pesquisa de força bruta

A pesquisa de força bruta é um algoritmo simples que verifica um padrão em uma string comparando cada caractere da string com o primeiro caractere do padrão. Se o primeiro caractere corresponder, ele compara o próximo caractere da string com o próximo caractere do padrão e assim por diante. Se todos os caracteres do padrão corresponderem, o padrão será encontrado. Se o primeiro caractere não corresponder, o algoritmo compara o segundo caractere da string com o primeiro caractere do padrão e assim por diante.
