# Transações

Resumindo, uma transação de banco de dados é uma sequência de múltiplas operações executadas em um banco de dados, e todas serviram como uma única unidade lógica de trabalho – ocorrendo totalmente ou não. Em outras palavras, nunca há um caso em que apenas metade das operações seja executada e os resultados salvos.
