# Padrão de objeto nulo

O padrão de objeto nulo é um padrão de design usado para representar um valor nulo com um objeto. É uma forma de evitar exceções de referência nula, fornecendo um objeto padrão que não faz nada. É uma forma de fornecer um comportamento padrão caso os dados não estejam disponíveis.
