# listas vinculadas

Os arrays armazenam elementos em locais de memória contíguos, resultando em endereços facilmente calculáveis ​​para os elementos armazenados e isso permite acesso mais rápido a um elemento em um índice específico. As listas vinculadas são menos rígidas em sua estrutura de armazenamento e os elementos geralmente não são armazenados em locais contíguos, portanto, precisam ser armazenados com tags adicionais que dão uma referência ao próximo elemento. Esta diferença no esquema de armazenamento de dados decide qual estrutura de dados seria mais adequada para uma determinada situação.
