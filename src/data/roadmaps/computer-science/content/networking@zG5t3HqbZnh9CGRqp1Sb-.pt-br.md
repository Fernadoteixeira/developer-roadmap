# Rede

Rede é o processo de conectar dois ou mais dispositivos de computação com a finalidade de compartilhar dados. Numa rede de dados, os dados partilhados podem ser tão simples como uma impressora ou tão complexos como uma transação financeira global.

Se você tem experiência em redes ou deseja ser engenheiro de confiabilidade ou engenheiro de operações, espere perguntas sobre estes tópicos. Caso contrário, é bom saber.
