# Pesquisa longa

Long polling é uma técnica usada para implementar a funcionalidade push do servidor por HTTP. É um método de abrir uma solicitação no servidor e mantê-la aberta até que ocorra um evento, momento em que o servidor responde. Isso contrasta com uma solicitação HTTP normal, em que o servidor responde imediatamente com quaisquer dados disponíveis no momento.
