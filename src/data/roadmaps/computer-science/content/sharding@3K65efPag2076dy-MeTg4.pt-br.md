# Fragmentação

A fragmentação de banco de dados é um método de distribuição de dados em várias máquinas. É uma técnica de escalonamento horizontal, em oposição ao escalonamento vertical, que é o escalonamento adicionando mais potência a uma única máquina. A fragmentação é uma maneira comum de dimensionar um banco de dados.
