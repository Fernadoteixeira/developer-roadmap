# Normalização vs Desnormalização

A normalização do banco de dados é um processo usado para organizar um banco de dados em tabelas e colunas. A ideia é que uma tabela seja sobre um tema específico e que apenas as colunas que apoiam esse tema sejam incluídas. Isso limita o número de dados duplicados contidos no seu banco de dados. Isso torna o banco de dados mais flexível, eliminando problemas decorrentes de modificações no banco de dados.

A desnormalização é o oposto da normalização. É o processo de adicionar dados redundantes a um banco de dados para melhorar o desempenho de leitura. Isso é feito adicionando dados duplicados em várias tabelas para evitar junções dispendiosas. Isso é feito às custas do aumento do armazenamento e da diminuição do desempenho de gravação.
