# Polinômio

Algoritmos polinomiais são algoritmos que possuem um tempo de execução que é uma função polinomial do tamanho da entrada. Isso significa que o tempo de execução é uma função no formato `n^k` onde `k` é uma constante. Por exemplo, o tempo de execução do algoritmo a seguir é `n^2`:

```python
def polynomial_algorithm(n):
    for i in range(n):
        for j in range(n):
            print(i, j)
```
