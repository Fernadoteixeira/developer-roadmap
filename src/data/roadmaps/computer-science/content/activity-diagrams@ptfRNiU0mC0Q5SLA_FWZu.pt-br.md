# Diagramas de Atividades

Os diagramas de atividades são usados ​​para modelar o fluxo de controle em um sistema. Eles são usados ​​em conjunto com diagramas de casos de uso para modelar o comportamento do sistema para cada caso de uso. Eles também são usados ​​para modelar o comportamento de uma única classe.
