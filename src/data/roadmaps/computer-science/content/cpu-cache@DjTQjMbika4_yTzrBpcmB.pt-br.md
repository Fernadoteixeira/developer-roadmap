# Cache da CPU

Um cache de CPU é um cache de hardware usado pela unidade central de processamento de um computador para reduzir o custo médio de acesso aos dados da memória principal. Um cache é uma memória menor e mais rápida, localizada mais próxima do núcleo do processador, que armazena cópias dos dados de locais de memória principais usados ​​com frequência.
