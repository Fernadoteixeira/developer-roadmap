# Escolha um idioma

Você precisa escolher uma linguagem de programação para aprender os conceitos de Ciência da Computação. Minha recomendação pessoal seria escolher C++ ou C e a razão para isso é:

- Eles permitem que você lide com ponteiros e alocação/desalocação de memória, para que você sinta as estruturas de dados e algoritmos em seus ossos. Em linguagens de nível superior como Python ou Java, eles ficam ocultos para você. No trabalho diário, isso é ótimo, mas quando você aprende como essas estruturas de dados de baixo nível são construídas, é ótimo se sentir próximo do metal.
- Você poderá encontrar muitos recursos para os tópicos listados neste roteiro usando C ou C++. Você pode encontrar muitos recursos para Python e Java, mas eles não são tão abundantes quanto C++ e C.
