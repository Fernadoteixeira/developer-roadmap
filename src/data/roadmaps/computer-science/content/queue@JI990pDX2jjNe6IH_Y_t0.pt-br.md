# Fila

Fila é uma coleção linear de itens onde os itens são inseridos e removidos em uma ordem específica. A fila também é chamada de Estrutura de Dados FIFO porque segue o princípio “Primeiro a entrar, primeiro a sair”, ou seja, o item que é inserido no primeiro é o que é retirado primeiro.
