# Árvores KD

Árvores KD são uma estrutura de dados que permite uma pesquisa rápida do vizinho mais próximo em espaços de alta dimensão. Eles são uma generalização de árvores de busca binária e são usados ​​em uma variedade de aplicações, incluindo visão computacional e geometria computacional.
