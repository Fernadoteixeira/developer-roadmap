# Teorema CAP

CAP é um acrônimo para Consistência, Disponibilidade e Tolerância de Partição. De acordo com o teorema CAP, qualquer sistema distribuído só pode garantir duas das três propriedades a qualquer momento. Você não pode garantir todas as três propriedades de uma só vez.
