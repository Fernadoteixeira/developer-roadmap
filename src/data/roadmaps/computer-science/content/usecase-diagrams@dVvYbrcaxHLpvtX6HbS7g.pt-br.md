# Diagramas de Casos de Uso

Os diagramas de casos de uso são um tipo de diagrama UML utilzado para modelar as interações entre os **atores** e os **casos de uso** de um sistema.

Um ator é uma pessoa ou um sistema externo que interage com o sistema. Os atores geralmente são representados por figuras de palito ou retângulos com o nome do ator.

Um caso de uso representa uma funcionalidade ou tarefa que o sistema realiza. Os casos de uso são representados por elipses contendo o nome do caso de uso em seu interior.

O diagrama de casos de uso exibe a fronteira do sistema, os atores envolvidos e as relações de uso.
