# Pular listas

Listas de pulos são uma estrutura de dados que permite executar operações em uma lista classificada em tempo O (log n). As listas de pulos são uma estrutura de dados probabilística, o que significa que a probabilidade de uma determinada operação levar um determinado período de tempo é um determinado valor. No caso de listas de pulos, a probabilidade de uma operação levar tempo O(log n) é 1.
