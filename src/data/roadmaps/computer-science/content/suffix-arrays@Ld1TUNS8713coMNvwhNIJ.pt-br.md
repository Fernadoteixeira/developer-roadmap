# Matrizes de sufixo

Matrizes de sufixos são uma estrutura de dados que nos permite encontrar rapidamente todos os sufixos de uma string em ordem lexicográfica. Isso é útil para muitos problemas, como encontrar a substring comum mais longa entre duas strings ou encontrar o número de substrings distintas de uma string.
