# Árvores de pesquisa balanceadas

Árvores de pesquisa balanceadas são um tipo de estrutura de dados que permite inserção, exclusão e pesquisa rápida de dados. Eles são um tipo de árvore de pesquisa binária com autoequilíbrio, o que significa que são uma árvore binária que mantém a propriedade da árvore de pesquisa binária ao mesmo tempo que mantém a árvore equilibrada. Isso significa que a árvore está sempre aproximadamente balanceada, o que permite rápida inserção, exclusão e consulta de dados.
