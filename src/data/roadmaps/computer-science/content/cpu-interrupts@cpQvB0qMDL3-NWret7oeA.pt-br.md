# interrupções de CPU

As interrupções da CPU são uma forma de a CPU se comunicar com o resto do computador. Eles são uma forma de a CPU informar ao resto do computador que precisa fazer alguma coisa. Por exemplo, se a CPU estiver executando um programa e precisar ler o teclado, ela enviará uma interrupção ao teclado para solicitar que envie os dados para a CPU. A CPU irá então esperar que o teclado envie os dados e então continuará executando o programa.
