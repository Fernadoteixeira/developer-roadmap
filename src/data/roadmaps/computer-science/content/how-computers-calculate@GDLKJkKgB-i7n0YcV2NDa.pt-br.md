# Como os computadores calculam?

Os computadores calculam usando o sistema binário, onde todos os dados são representados como 0s e 1s. Esses estados binários correspondem às posições ON/OFF dos transistores, que são os blocos de construção das portas lógicas (AND, OR, NOT). Números, caracteres e instruções são divididos em sequências binárias (bits) e agrupados em bytes (8 bits). Operações aritméticas como adição são realizadas através de portas lógicas, que combinam valores binários. A CPU executa esses cálculos seguindo um ciclo de busca-decodificação-execução. Cálculos complexos, como manipulação de decimais, usam representação de ponto flutuante. Programas escritos em linguagens de alto nível são compilados em código de máquina para execução pela CPU.
