# Constante

Algoritmos de tempo constante são os algoritmos mais simples e eficientes. São algoritmos que sempre levam o mesmo tempo para serem executados, independentemente do tamanho da entrada. Este é o melhor cenário para um algoritmo e é o objetivo de todos os algoritmos.
