# Rede de distribuição de conteúdo (CDN)

Uma CDN é uma rede de servidores distribuídos geograficamente. Os servidores estão conectados entre si e à Internet. Os servidores são usados ​​para entregar conteúdo aos usuários. O conteúdo é entregue ao usuário a partir do servidor mais próximo do usuário. Isso é feito para reduzir a latência e melhorar o desempenho da entrega de conteúdo.
