# Algoritmo de Dijkstra

O algoritmo de Dijkstra é um algoritmo de passagem de gráfico que encontra o caminho mais curto entre dois nós em um gráfico. É um algoritmo de gráfico ponderado, o que significa que cada aresta do gráfico possui um peso associado a ela. O algoritmo funciona encontrando o caminho mais curto do nó inicial até todos os outros nós do gráfico. Ele faz isso acompanhando a distância do nó inicial até cada nó e, em seguida, escolhendo o nó com a distância mais curta do nó inicial para visitar em seguida. Em seguida, ele atualiza a distância de cada nó ao nó inicial e repete o processo até que todos os nós tenham sido visitados.
