# Algoritmo de Boyer Moore

O algoritmo Boyer Moore é um algoritmo de pesquisa de string usado para encontrar o índice de uma substring em uma string. É um algoritmo muito eficiente usado em muitas aplicações. É usado em editores de texto, compiladores e muitas outras aplicações.
