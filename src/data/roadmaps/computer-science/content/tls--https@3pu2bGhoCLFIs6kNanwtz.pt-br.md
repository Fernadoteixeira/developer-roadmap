# TLS/HTTPS

TLS (Transport Layer Security) é um protocolo criptográfico que fornece privacidade e integridade de dados entre dois aplicativos em comunicação. É amplamente utilizado para proteger HTTP, embora possa ser usado com qualquer protocolo. O TLS é frequentemente usado em combinação com HTTPS, que é HTTP sobre TLS.
