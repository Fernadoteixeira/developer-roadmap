# Codificações de caracteres

As codificações de caracteres são uma forma de representar caracteres como números. Eles são usados ​​para armazenar e transmitir texto. A codificação de caracteres mais comum é ASCII, que é uma codificação de 7 bits. Isso significa que cada caractere é representado por um número entre 0 e 127. O conjunto de caracteres ASCII contém 128 caracteres, incluindo letras, números, pontuação e caracteres de controle. O conjunto de caracteres ASCII é um subconjunto do conjunto de caracteres Unicode, que é uma codificação de 16 bits. Unicode é um superconjunto de ASCII, portanto os caracteres ASCII podem ser representados por Unicode. Unicode é a codificação de caracteres mais comum usada na web.
