# DML (linguagem de manipulação de dados)

Os comandos SQL que manipulam dados no banco de dados pertencem ao DML, ou Linguagem de Manipulação de Dados, e isso inclui a maioria das instruções SQL. DCL é o componente da instrução SQL que controla o acesso aos dados e ao banco de dados. Basicamente, as instruções DCL são agrupadas com instruções DML.
