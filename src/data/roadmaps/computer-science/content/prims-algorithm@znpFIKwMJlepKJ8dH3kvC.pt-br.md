# Algoritmo de Prim

O algoritmo de Prim é um algoritmo ganancioso que encontra uma árvore geradora mínima para um gráfico não direcionado ponderado. Uma árvore geradora mínima é um subconjunto das arestas de um gráfico não direcionado conectado e ponderado por arestas que conecta todos os vértices entre si, sem quaisquer ciclos e com o peso total de aresta mínimo possível. Uma árvore geradora mínima para um gráfico não direcionado ponderado também é chamada de árvore geradora de peso mínimo ou árvore geradora de custo mínimo.
