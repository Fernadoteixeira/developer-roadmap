# Classificação de pilha

Heap sort é um algoritmo de classificação baseado em comparação. É semelhante à classificação por seleção, onde primeiro encontramos o elemento máximo e colocamos o elemento máximo no final. Repetimos o mesmo processo para o elemento restante.
