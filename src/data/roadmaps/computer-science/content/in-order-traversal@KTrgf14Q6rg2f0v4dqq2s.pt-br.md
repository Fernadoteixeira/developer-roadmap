# Travessia em ordem

A travessia em ordem é um algoritmo de travessia de árvore que visita a subárvore esquerda, a raiz e, em seguida, a subárvore direita. Esta é a maneira mais comum de percorrer uma árvore de pesquisa binária. Também é usado para criar uma lista ordenada de nós em uma árvore de pesquisa binária.
