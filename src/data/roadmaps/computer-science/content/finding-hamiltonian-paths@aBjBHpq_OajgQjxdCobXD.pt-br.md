# Encontrando caminhos hamiltonianos

Caminhos hamiltonianos são caminhos que visitam cada nó de um grafo exatamente uma vez. Eles receberam o nome do famoso matemático Hamilton. Os caminhos hamiltonianos são um caso especial de ciclos hamiltonianos, que são ciclos que visitam cada nó em um gráfico exatamente uma vez.
