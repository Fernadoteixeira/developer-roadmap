# Procedimentos Armazenados

Procedimentos armazenados são criados para realizar uma ou mais operações DML no banco de dados. Nada mais é do que o grupo de instruções SQL que aceita alguma entrada na forma de parâmetros e executa alguma tarefa, podendo ou não retornar um valor.
