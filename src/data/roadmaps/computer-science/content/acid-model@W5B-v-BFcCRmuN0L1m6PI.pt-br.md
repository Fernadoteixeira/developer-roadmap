# ÁCIDO

ACID são as quatro propriedades de qualquer sistema de banco de dados que ajudam a garantir que somos capazes de realizar as transações de maneira confiável. É uma sigla que se refere à presença de quatro propriedades: atomicidade, consistência, isolamento e durabilidade.
