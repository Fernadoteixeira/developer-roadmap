# Gráfico

Gráficos em estruturas de dados são estruturas de dados não lineares compostas por um número finito de nós ou vértices e as arestas que os conectam. Gráficos em estruturas de dados são usados ​​para resolver problemas do mundo real nos quais representam a área do problema como uma rede, como redes telefônicas, redes de circuitos e redes sociais.
