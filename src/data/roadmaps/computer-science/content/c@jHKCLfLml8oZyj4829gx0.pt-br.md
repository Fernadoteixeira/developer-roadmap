# C\#

C# (pronuncia-se "C sustenido") é uma linguagem de programação de uso geral desenvolvida pela Microsoft. Ele é usado para realizar diversas tarefas e pode ser usado para criar aplicativos web, jogos, aplicativos móveis, etc.
