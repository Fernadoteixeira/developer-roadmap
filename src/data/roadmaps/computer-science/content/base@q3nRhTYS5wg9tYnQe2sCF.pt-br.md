# Modelo BASE

O aumento da popularidade dos bancos de dados NoSQL proporcionou flexibilidade e fluidez com facilidade para manipular dados e, como resultado, um novo modelo de banco de dados foi projetado, refletindo essas propriedades. A sigla BASE é um pouco mais confusa do que ACID, mas, no entanto, as palavras por trás dela sugerem maneiras pelas quais o modelo BASE é diferente e a sigla BASE significa: -

- **B**asicamente **A**disponível
- \*\* Estado suave
- **E**consistência eventual
