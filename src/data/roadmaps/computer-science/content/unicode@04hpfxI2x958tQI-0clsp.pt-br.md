# Unicode

Unicode é um padrão universal para codificação de caracteres. É um superconjunto do ASCII, o que significa que o ASCII é um subconjunto do Unicode. O Unicode permite codificar mais de 140.000 caracteres cobrindo diversos idiomas e símbolos mundiais, superando amplamente os 128 caracteres do ASCII original.
