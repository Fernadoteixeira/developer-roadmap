# gRPC

gRPC é um protocolo de serialização independente de plataforma usado para comunicação entre serviços. Projetado pelo Google em 2015, é uma alternativa moderna às APIs REST. É um protocolo binário que usa HTTP/2 como camada de transporte. É uma estrutura RPC de alto desempenho, código aberto e uso geral que coloca o mobile e o HTTP/2 em primeiro lugar.

Seu principal caso de uso é a comunicação entre dois idiomas diferentes dentro do mesmo aplicativo. Você pode usar Python para se comunicar com Go ou Java para se comunicar com C#.
