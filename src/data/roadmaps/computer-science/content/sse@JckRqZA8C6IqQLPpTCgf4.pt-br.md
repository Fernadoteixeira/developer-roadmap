# eventos enviados pelo servidor

Server-Sent Events é uma tecnologia push de servidor que permite que um cliente receba atualizações automáticas de um servidor por meio de uma conexão HTTP e descreve como os servidores podem iniciar a transmissão de dados para clientes depois que uma conexão inicial do cliente for estabelecida.
