# Bloqueio

Os bloqueios são usados ​​para evitar que os dados sejam modificados por vários processos ao mesmo tempo. Isso é importante porque se dois processos modificarem os mesmos dados ao mesmo tempo, os dados poderão ser corrompidos. Bloqueios são usados ​​para evitar que isso aconteça.
