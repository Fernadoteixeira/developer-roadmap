# Matriz de Adjacência

Uma matriz de adjacência é uma matriz quadrada usada para representar um gráfico finito. É usado para representar as conexões entre vértices em um gráfico. A matriz é preenchida com 0s e 1s, onde 1 representa uma conexão entre dois vértices e 0 representa nenhuma conexão.
