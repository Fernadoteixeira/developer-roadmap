# Classes de Complexidade

Na informática existem alguns problemas cujas soluções ainda não foram encontradas, os problemas são divididos em classes conhecidas como Classes de Complexidade. Na teoria da complexidade, uma Classe de Complexidade é um conjunto de problemas com complexidade relacionada. Essas aulas ajudam os cientistas a agrupar problemas com base em quanto tempo e espaço são necessários para resolvê-los e verificar as soluções. É o ramo da teoria da computação que trata dos recursos necessários para resolver um problema.
