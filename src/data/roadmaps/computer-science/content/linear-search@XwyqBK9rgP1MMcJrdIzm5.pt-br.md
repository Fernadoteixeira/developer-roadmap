# Pesquisa Linear

A pesquisa linear é um algoritmo muito simples usado para pesquisar um valor em uma matriz. Ele verifica sequencialmente cada elemento do array até que uma correspondência seja encontrada ou até que todos os elementos tenham sido pesquisados.
