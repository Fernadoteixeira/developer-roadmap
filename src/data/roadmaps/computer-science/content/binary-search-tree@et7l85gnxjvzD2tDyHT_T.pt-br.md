# Árvore de pesquisa binária

Uma árvore de pesquisa binária, também chamada de árvore binária ordenada ou classificada, é uma estrutura de dados de árvore binária enraizada com a chave de cada nó interno sendo maior que todas as chaves na subárvore esquerda do respectivo nó e menor que aquelas em sua subárvore direita.
