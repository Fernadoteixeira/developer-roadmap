# Estruturas de dados

Como o próprio nome indica, uma **Estrutura de Dados** é uma forma de organizar os dados na **memória** para que possam ser usados ​​de forma eficiente. Algumas estruturas de dados comuns são array, lista vinculada, pilha, hashtable, fila, árvore, heap e gráfico.
