# Algoritmo de Kruskal

O algoritmo de Kruskal é um algoritmo ganancioso que encontra uma árvore geradora mínima para um grafo ponderado conectado. É um algoritmo de árvore geradora mínima que toma um gráfico como entrada e encontra o subconjunto das arestas desse gráfico que formam uma árvore que inclui todos os vértices, onde o peso total de todas as arestas da árvore é minimizado. Se o grafo não estiver conectado, ele encontrará uma floresta de abrangência mínima (uma árvore de abrangência mínima para cada componente conectado).
