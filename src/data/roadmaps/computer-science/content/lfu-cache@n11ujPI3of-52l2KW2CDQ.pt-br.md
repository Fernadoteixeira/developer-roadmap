# Cache LFU

LFU Cache é uma estrutura de dados que armazena pares de valores-chave. Possui tamanho fixo e quando está cheio remove o par de valores-chave menos utilizado. É uma variação do cache LRU e é usado em muitos aplicativos, como cache de páginas da web, cache de consultas de banco de dados e cache de imagens.
