# httphttps

HTTP é o protocolo de comunicação da camada de aplicativo baseado em `TCP/IP` que padroniza como o cliente e o servidor se comunicam entre si. Define como o conteúdo é solicitado e transmitido pela Internet.

HTTPS (Hypertext Transfer Protocol Secure) é a versão segura do HTTP, que é o principal protocolo usado para enviar dados entre um navegador da web e um site.

`HTTPS = HTTP + SSL/TLS`
