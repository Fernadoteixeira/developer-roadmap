# Contêineres

Contêineres são uma construção na qual cgroups, namespaces e chroot são usados ​​para encapsular e isolar totalmente um processo. Esse processo encapsulado, denominado imagem de contêiner, compartilha o kernel do host com outros contêineres, permitindo que os contêineres sejam significativamente menores e mais rápidos que as máquinas virtuais. Essas imagens são projetadas para portabilidade, permitindo testes locais completos de uma imagem estática e fácil implantação em uma plataforma de gerenciamento de contêineres.
