# github

O GitHub se tornou um hub central para projetos de código aberto e é amplamente utilizado por desenvolvedores, empresas e organizações para repositórios públicos e privados. Foi adquirida pela Microsoft em 2018, mas continua a operar como uma entidade relativamente independente. A popularidade do GitHub o tornou uma ferramenta essencial nos fluxos de trabalho modernos de desenvolvimento de software e uma plataforma chave para apresentar projetos de codificação e contribuir para software de código aberto.
