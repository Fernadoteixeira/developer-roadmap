# Togaf

A estrutura de conteúdo TOGAF fornece um modelo detalhado de produtos de trabalho arquitetônicos, incluindo entregas, artefatos dentro de entregas e os blocos de construção arquitetônicos que os artefatos representam.

Visite os seguintes recursos para saber mais:

- [@official@Togaf](https://www.opengroup.org/togaf)
- [@article@Wikipedia](https://en.wikipedia.org/wiki/The_Open_Group_Architecture_Framework)
