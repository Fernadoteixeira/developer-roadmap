# Infraestrutura como código

Às vezes chamada de IaC, esta seção refere-se às técnicas e ferramentas usadas para definir a infraestrutura, normalmente em uma linguagem de marcação como YAML ou JSON. A infraestrutura como código permite que os engenheiros de DevOps usem os mesmos fluxos de trabalho usados ​​pelos desenvolvedores de software para criar versões, reverter e gerenciar alterações.

O termo Infraestrutura como Código abrange tudo, desde inicialização até configuração e orquestração, e é considerado uma prática recomendada no setor gerenciar toda a infraestrutura como código. Essa técnica precipitou a explosão na complexidade do sistema observada nas organizações modernas de DevOps.
