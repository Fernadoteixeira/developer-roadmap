# Sistemas Distribuídos

Sistemas distribuídos são um tipo de arquitetura computacional onde componentes localizados em computadores em rede se comunicam e coordenam suas ações através da passagem de mensagens. Esses sistemas são projetados para trabalhar em conjunto para atingir um objetivo comum, muitas vezes fornecendo serviços ou processando dados de forma colaborativa.
