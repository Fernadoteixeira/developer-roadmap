# Programação Reativa

A programação reativa descreve um paradigma de design que depende da lógica de programação assíncrona para lidar com atualizações em tempo real para conteúdo que de outra forma seria estático. Ele fornece um meio eficiente – o uso de fluxos de dados automatizados – para lidar com atualizações de dados no conteúdo sempre que um usuário faz uma consulta.
