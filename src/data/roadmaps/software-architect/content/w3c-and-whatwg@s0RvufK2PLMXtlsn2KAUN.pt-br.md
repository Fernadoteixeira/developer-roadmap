# Padrões W3c e WHATWG

Os padrões do World Wide Web Consortium (W3C) definem as melhores práticas para desenvolvimento web para permitir que os desenvolvedores criem experiências interativas ricas que estão disponíveis em qualquer dispositivo. Esses padrões variam desde tecnologias web recomendadas, como HTML, CSS, XML, até princípios geralmente aceitos de arquitetura, semântica e serviços web.

O Grupo de Trabalho de Tecnologia de Aplicativos de Hipertexto da Web (WHATWG) é outro conjunto de padrões da web que surgiu depois que o W3C anunciou que se concentraria em XHTML em vez de HTML.

Visite os seguintes recursos para saber mais:

- [@official@Padrões W3C](https://www.w3.org/standards/)
- [@official@WHATWG Padrões](https://spec.whatwg.org/)
