# Sem servidor

Arquitetura sem servidor (também conhecida como computação sem servidor ou função como serviço, FaaS) é um padrão de design de software onde os aplicativos são hospedados por um serviço de terceiros, eliminando a necessidade de gerenciamento de software e hardware de servidor pelo desenvolvedor. Os aplicativos são divididos em funções individuais que podem ser invocadas e dimensionadas individualmente.
