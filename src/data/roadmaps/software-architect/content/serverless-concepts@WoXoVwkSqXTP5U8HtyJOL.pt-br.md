# Conceitos sem servidor

Serverless é um modelo de desenvolvimento nativo da nuvem que permite aos desenvolvedores criar e executar aplicativos sem precisar gerenciar servidores. Ainda existem servidores sem servidor, mas eles são abstraídos do desenvolvimento de aplicativos. Um provedor de nuvem cuida do trabalho rotineiro de provisionamento, manutenção e dimensionamento da infraestrutura do servidor. Os desenvolvedores podem simplesmente empacotar seu código em contêineres para implantação.
