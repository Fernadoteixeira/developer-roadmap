# PKI

Uma infraestrutura de chave pública (PKI) é um conjunto de funções, políticas, hardware, software e procedimentos para criar, gerenciar, distribuir, usar, armazenar e revogar certificados digitais e criptografia de chave pública. O objetivo de uma PKI é facilitar a transferência eletrônica segura de informações para uma série de atividades de rede, como comércio eletrônico, serviços bancários pela Internet e e-mail confidencial. É necessário para atividades onde senhas simples são um método de autenticação inadequado, sendo necessária a comprovação mais rigorosa para confirmar a identidade das partes envolvidas na comunicação e validar as informações que estão sendo transferidas.
