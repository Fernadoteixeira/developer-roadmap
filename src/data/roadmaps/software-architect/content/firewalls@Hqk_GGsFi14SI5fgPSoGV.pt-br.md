# Firewalls

Um Firewall é um dispositivo de segurança de rede que monitora e filtra o tráfego de entrada e saída da rede com base nas políticas de segurança previamente estabelecidas de uma organização. Os firewalls geralmente ficam entre uma rede confiável e uma rede não confiável; muitas vezes a rede não confiável é a Internet. Por exemplo, as redes de escritórios costumam usar um firewall para proteger a rede contra ameaças online.
