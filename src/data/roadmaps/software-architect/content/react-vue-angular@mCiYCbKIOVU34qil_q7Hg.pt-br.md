# Reagir

React é a biblioteca JavaScript front-end mais popular para construção de interfaces de usuário. O React também pode renderizar no servidor usando Node e potencializar aplicativos móveis usando React Native.

Vue.js é uma estrutura JavaScript progressiva projetada para construir interfaces de usuário e aplicativos de página única.

Angular é uma estrutura de aplicativo da web front-end de código aberto baseada em TypeScript, liderada pela equipe Angular do Google.
