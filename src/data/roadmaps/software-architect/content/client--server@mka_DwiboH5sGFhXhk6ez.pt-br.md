# Arquitetura Cliente-Servidor

A arquitetura cliente-servidor é um modelo de computação que separa tarefas ou cargas de trabalho entre provedores de serviços (servidores) e solicitantes de serviços (clientes). Essa arquitetura é amplamente utilizada em aplicações de rede, incluindo aplicações web, onde os clientes interagem com servidores para acessar recursos, serviços e dados.
