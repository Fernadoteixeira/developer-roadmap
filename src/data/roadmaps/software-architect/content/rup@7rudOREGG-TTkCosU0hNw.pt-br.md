# RUP

O RUP (**Rational Unified Process**) não é uma certificação amplamente reconhecida como PMP ou Scrum, mas sim uma estrutura de desenvolvimento de software criada pela Rational Software (agora IBM). Segue uma abordagem iterativa e incremental para o desenvolvimento de projetos, baseada nas melhores práticas para entregar software de alta qualidade no prazo e dentro do orçamento.
