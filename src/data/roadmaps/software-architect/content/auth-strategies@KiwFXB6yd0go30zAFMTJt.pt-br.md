# Estratégias de autenticação

As estratégias de autenticação são essenciais para garantir o acesso seguro a aplicações e sistemas. Eles definem como os usuários são verificados antes de receberem acesso aos recursos. Aqui estão algumas estratégias de autenticação comuns:

Autenticação baseada em senha

Autenticação multifator (MFA)

OAuth e OpenID Connect

Autenticação baseada em token:

Autenticação Biométrica

Autenticação baseada em certificado
