# EMC e DMS

EMC (Enterprise Metadata Catalog) e DMS (Document Management System) são dois conceitos distintos no domínio do gerenciamento de dados e sistemas de informação. Abaixo está uma visão geral de cada um:

Um Enterprise Metadata Catalog (EMC) é um repositório centralizado que armazena metadados sobre ativos de dados dentro de uma organização. Esses metadados fornecem contexto, significado e estrutura aos dados, permitindo melhor gerenciamento e utilização dos dados.

Um Sistema de Gerenciamento de Documentos (DMS) é uma solução de software que ajuda as organizações a capturar, armazenar, gerenciar e rastrear documentos eletrônicos e imagens de informações em papel. As soluções DMS são essenciais para organizar e proteger documentos em formato digital.
