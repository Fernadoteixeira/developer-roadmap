# Malha de serviço

Um Service Mesh é uma camada de infraestrutura dedicada para lidar com a comunicação entre serviços. É responsável pela entrega confiável de solicitações por meio da complexa topologia de serviços que compõem um aplicativo moderno e nativo da nuvem. Em termos leigos, é uma ferramenta que ajuda a controlar como os diferentes serviços se comunicam entre si.
