# Modelo TCP/IP

O `TCP/IP model` define como os dispositivos devem transmitir dados entre eles e permite a comunicação em redes e grandes distâncias. O modelo representa como os dados são trocados e organizados em redes. Ele é dividido em quatro camadas, que definem os padrões para troca de dados e representam como os dados são tratados e empacotados quando entregues entre aplicativos, dispositivos e servidores.

- **Camada de acesso à rede**: A camada de acesso à rede é um grupo de aplicações que requerem comunicações de rede. Esta camada é responsável por gerar os dados e solicitar conexões.

- **Camada de Internet**: A camada de Internet é responsável por enviar pacotes de uma rede e controlar seu movimento através de uma rede para garantir que cheguem ao seu destino.

- **Camada de transporte**: A camada de transporte é responsável por fornecer uma conexão de dados sólida e confiável entre o aplicativo ou dispositivo original e o destino pretendido.

- **Camada de Aplicação**: A camada de aplicação refere-se a programas que precisam de TCP/IP para ajudá-los a se comunicarem entre si.
