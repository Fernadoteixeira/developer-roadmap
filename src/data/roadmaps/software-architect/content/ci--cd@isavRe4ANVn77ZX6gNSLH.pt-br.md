# CI/CD

CI/CD é um método para entregar aplicativos com frequência aos clientes, introduzindo automação nos estágios de desenvolvimento de aplicativos. Os principais conceitos atribuídos ao CI/CD são integração contínua, entrega contínua e implantação contínua. CI/CD é uma solução para os problemas que a integração de novos códigos pode causar para as equipes de desenvolvimento e operações (também conhecido como "inferno da integração").
