# Bancos de dados SQL

SQL significa Linguagem de Consulta Estruturada. É usado para bancos de dados relacionais. Um banco de dados SQL é uma coleção de tabelas que armazena um conjunto específico de dados estruturados. Exemplos de bancos de dados SQL incluem MariaDB, MySQL e PostgreSQL.
