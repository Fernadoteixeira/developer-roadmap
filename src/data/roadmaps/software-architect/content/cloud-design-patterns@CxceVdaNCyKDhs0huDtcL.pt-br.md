# Padrões de design de nuvem

Esses padrões de design são úteis para criar aplicativos confiáveis, escaláveis ​​e seguros na nuvem. Os padrões de design de nuvem em que cada padrão descreve o problema que o padrão aborda, considerações para aplicar o padrão e um exemplo baseado no Microsoft Azure. A maioria dos padrões inclui exemplos de código ou trechos que mostram como implementar o padrão no Azure. No entanto, a maioria dos padrões são relevantes para qualquer sistema distribuído, seja hospedado no Azure ou em outras plataformas de nuvem.
