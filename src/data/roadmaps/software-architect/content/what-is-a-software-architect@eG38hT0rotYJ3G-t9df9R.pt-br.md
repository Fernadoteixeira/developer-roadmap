# O que é arquiteto de software?

Um desenvolvedor especialista que projeta soluções de software desde o início, tomando decisões de alto nível sobre cada etapa do processo, incluindo padrões técnicos, ferramentas, princípios de design, plataformas a serem utilizadas, etc., liderando uma equipe de engenheiros para criar o produto final.
