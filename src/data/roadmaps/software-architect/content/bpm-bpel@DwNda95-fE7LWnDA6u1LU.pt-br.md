# BPMBPEL

## BPM: Gestão de Processos de Negócios

As médias ou grandes empresas necessitam de processos robustos para agilizar as suas necessidades de negócio, reduzindo os custos incorridos por processo e diminuindo o tempo de resposta de cada actividade.
Para conseguir isso, existem várias ferramentas de BPM como PEGA, IBM BPM, Appian, etc. Basicamente, essas ferramentas automatizam os processos por meio de uma modelagem e implementação robusta de processos.

## BPMN: notações de gerenciamento de processos de negócios

É um padrão para representar graficamente processos de negócios. Na modelagem do processo, as notações utilizadas são obedecidas ao BPMN (existem outras como EPC, etc.). Portanto, BPMN é uma notação padrão que os consultores de BPM seguem para modelar o processo de negócios. O BPMN possui versões e agora o BPMN 2.0 é o padrão.

## BPEL: Linguagem de Execução de Processos de Negócios

Os programadores utilizam o BPEL para definir como um processo de negócio que envolve serviços web será executado. As mensagens BPEL são normalmente usadas para invocar serviços remotos, orquestrar a execução de processos e gerenciar eventos e exceções. BPEL é frequentemente associado à notação de gerenciamento de processos de negócios. Em muitas organizações, os analistas usam BPMN para visualizar processos de negócios e os desenvolvedores transformam as visualizações em BPEL para execução.
