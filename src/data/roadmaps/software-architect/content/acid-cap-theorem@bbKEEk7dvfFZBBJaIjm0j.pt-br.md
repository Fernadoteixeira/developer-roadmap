# Teorema ÁCIDO e CAP

ACID (Atomicidade, Consistência, Isolamento, Durabilidade) e CAP (Consistência, Disponibilidade, Tolerância de Partição) são conceitos essenciais em sistemas distribuídos. Eles são frequentemente usados ​​para explicar os compromissos entre consistência e disponibilidade.

CAP é um acrônimo para Consistência, Disponibilidade e Tolerância de Partição. De acordo com o teorema CAP, qualquer sistema distribuído só pode garantir duas das três propriedades a qualquer momento. Você não pode garantir todas as três propriedades de uma só vez.

ACID é um acrônimo que significa Atomicidade, Consistência, Isolamento, Durabilidade. ACID é um conjunto de propriedades de transações de banco de dados destinadas a garantir a validade mesmo em caso de erros, falhas de energia, etc.
