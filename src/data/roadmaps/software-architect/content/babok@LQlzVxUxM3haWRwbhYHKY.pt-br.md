# Babok

O guia para o Corpo de Conhecimento de Análise de Negócios (Guia BABOK) é um livro do Instituto Internacional de Análise de Negócios (IIBA) que fornece aos analistas de negócios (BAs) estratégias para usar dados para melhorar os processos de fluxo de trabalho, tecnologia, produtos e serviços de uma organização.
