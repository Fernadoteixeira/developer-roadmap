# Orientado a serviços

A arquitetura orientada a serviços (SOA) é uma abordagem empresarial para o desenvolvimento de software de componentes de aplicativos que aproveita componentes ou serviços de software reutilizáveis.

SOA fornece quatro tipos de serviços diferentes:

1. Serviços funcionais (ou seja, serviços empresariais), que são essenciais para aplicações empresariais.
2. Serviços empresariais, que servem para implementar funcionalidades.
3. Serviços de aplicativos, que são usados ​​para desenvolver e implantar aplicativos.
4. Serviços de infraestrutura, que são fundamentais para processos de back-end, como segurança e autenticação.
