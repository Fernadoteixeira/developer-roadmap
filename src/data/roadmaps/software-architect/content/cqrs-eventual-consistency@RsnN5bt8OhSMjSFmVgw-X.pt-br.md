# Consistência eventual do CQRS

CQRS (Segregação de Responsabilidade para Consultas de Comando) é um padrão de arquitetura que vem com a ideia de separar as operações de leitura e gravação em dois processos lógicos distintos.

Visite os seguintes recursos para saber mais:

- [@artigo@CQRS](https://martinfowler.com/bliki/CQRS.html)
- [@artigo@Introdução ao CQRS](https://learn.microsoft.com/en-us/azure/architecture/patterns/cqrs)
