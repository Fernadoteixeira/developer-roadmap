# Algoritmos de hash

Algoritmos de hash são usados ​​para gerar um valor exclusivo para uma determinada entrada. Este valor é chamado de hash. Algoritmos de hash são usados ​​para verificar a integridade dos dados, armazenar senhas e gerar identificadores exclusivos para dados.
