# Filas de mensagens

O enfileiramento de mensagens possibilita que os aplicativos se comuniquem de forma assíncrona, enviando mensagens entre si por meio de uma fila. Uma fila de mensagens fornece armazenamento temporário entre o remetente e o destinatário para que o remetente possa continuar operando sem interrupção quando o programa de destino estiver ocupado ou não conectado.
