# SÓLIDO

SOLID é um conjunto de princípios aplicados ao design orientado a objetos (OOD) para criar código sustentável, compreensível e flexível, evitando cheiros e defeitos de código. Os princípios são:

- Responsabilidade Única
- Aberto/Fechado
- Substituição de Liskov
- Segregação de Interface
- Inversão de Dependência
