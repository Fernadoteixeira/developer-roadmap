# Modelos OSI e TCP/IP

O modelo OSI e TCP/IP é usado para ajudar o desenvolvedor a projetar seu sistema para interoperabilidade. O modelo OSI possui 7 camadas enquanto o modelo TCP/IP possui uma forma mais resumida do modelo OSI consistindo apenas de 4 camadas. Isto é importante se você estiver tentando projetar um sistema para se comunicar com outros sistemas.
