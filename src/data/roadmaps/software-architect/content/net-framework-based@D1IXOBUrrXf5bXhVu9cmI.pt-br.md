# .NET Framework

.NET é uma plataforma de código aberto com ferramentas e bibliotecas para construção de web, dispositivos móveis, desktop, jogos, IoT, nuvem e microsserviços.

Linguagens oficialmente suportadas em .NET: C#, F#, Visual Basic.
