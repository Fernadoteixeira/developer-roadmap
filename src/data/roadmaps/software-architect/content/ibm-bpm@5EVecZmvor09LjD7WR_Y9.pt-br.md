# IBM BPM

IBM BPM é uma plataforma abrangente de gerenciamento de processos de negócios. Ele fornece um conjunto robusto de ferramentas para criar, testar e implantar processos de negócios, bem como total visibilidade e insights para gerenciar esses processos de negócios.
