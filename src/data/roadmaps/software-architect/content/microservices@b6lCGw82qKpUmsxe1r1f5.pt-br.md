# Microsserviços

A arquitetura de microsserviços é um padrão no qual serviços altamente coesos e pouco acoplados são desenvolvidos, mantidos e implantados separadamente. Cada componente lida com uma função individual e, quando combinado, o aplicativo lida com uma função comercial geral.
