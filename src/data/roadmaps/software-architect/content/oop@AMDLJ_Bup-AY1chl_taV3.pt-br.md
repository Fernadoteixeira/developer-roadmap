# OOP

A programação orientada a objetos (OOP) é ​​um modelo de programação de computador que organiza o design de software em torno de dados ou objetos, em vez de funções e lógica. Um objeto pode ser definido como um campo de dados que possui atributos e comportamento exclusivos.
