# Microfront-ends

Microfrontends é um estilo arquitetônico onde aplicativos front-end entregues de forma independente, construídos por diferentes equipes usando diferentes tecnologias, são compostos em um todo maior. Simplesmente, um Micro-Frontend é uma parte de uma página da web (não a página inteira). Há uma página “Host” ou “Container” na página Micro-Frontend Architecture que pode hospedar um ou mais Micro-Frontends.
