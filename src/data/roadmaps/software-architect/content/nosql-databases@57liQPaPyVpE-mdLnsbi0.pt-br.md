# Bancos de dados Nosql

Os bancos de dados NoSQL (também conhecidos como "não apenas SQL") são bancos de dados não tabulares e armazenam dados de maneira diferente das tabelas relacionais. Os bancos de dados NoSQL vêm em vários tipos com base em seu modelo de dados. Os principais tipos são documento, valor-chave, coluna larga e gráfico. Eles fornecem esquemas flexíveis e escalam facilmente com grandes quantidades de dados e altas cargas de usuários.

Tipos de bancos de dados NoSQL

- Bancos de dados de documentos Ex. MongoDB
- Bancos de dados de valores-chave Ex. Redis
- Bancos de dados de coluna larga Ex. Cassandra
- Bancos de dados gráficos Ex. Neo4J
