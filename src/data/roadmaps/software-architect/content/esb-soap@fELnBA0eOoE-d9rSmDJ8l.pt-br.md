# ESB e SOAP

ESB (Enterprise Service Bus) e SOAP (Simple Object Access Protocol) são duas tecnologias que permitem a comunicação entre diferentes sistemas. ESB é uma arquitetura de software que permite a integração de diversos sistemas, como bancos de dados, serviços web e aplicativos móveis. SOAP é um protocolo de mensagens que permite a troca de dados estruturados entre sistemas pela Internet.
