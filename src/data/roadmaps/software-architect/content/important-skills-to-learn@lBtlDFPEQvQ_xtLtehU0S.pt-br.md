# Habilidades importantes

Para apoiar as atividades definidas são necessárias competências específicas. Pela minha experiência, lendo livros e discussões, podemos resumir essas dez habilidades que todo arquiteto de software deve ter:

- Projeto
- Decidir
- Simplificar
- Código
- Documento
- Comunicar
- Estimativa
- Equilíbrio
- Consultar
- Mercado
