# Linguagens de programação

Uma linguagem de programação é um sistema de notação para escrever programas de computador. As linguagens de programação são descritas em termos de sintaxe e semântica, geralmente definidas por uma linguagem formal. As linguagens geralmente fornecem recursos como sistema de tipos, variáveis ​​e mecanismos para tratamento de erros.
