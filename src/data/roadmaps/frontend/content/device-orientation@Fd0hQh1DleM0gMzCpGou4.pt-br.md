# API de orientação de dispositivo

A API de orientação de dispositivo é uma API da web que fornece acesso aos dados de orientação e movimento do dispositivo, como inclinação, rotação e guinada. Ele permite que os desenvolvedores da web criem aplicativos que possam responder à orientação e ao movimento do dispositivo, como realidade aumentada e jogos controlados por movimento. Para usar a API Device Orientation, uma página da web deve primeiro solicitar permissão do usuário para acessar os dados de orientação do dispositivo. Se a permissão for concedida, a página poderá usar o objeto DeviceOrientationEvent para acessar os dados de orientação do dispositivo e responder às alterações na orientação. A API fornece diversas propriedades para acessar os dados de orientação e movimento do dispositivo, bem como eventos para detectar mudanças na orientação.
