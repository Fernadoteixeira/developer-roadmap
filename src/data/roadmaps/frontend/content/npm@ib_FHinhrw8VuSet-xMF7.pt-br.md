# npm

npm (Node Package Manager) é o gerenciador de pacotes padrão para Node.js, fornecendo um vasto ecossistema de código JavaScript reutilizável. Ele permite que os desenvolvedores compartilhem, descubram e instalem facilmente pacotes (bibliotecas e ferramentas) para seus projetos. npm consiste em uma interface de linha de comando para instalação e gerenciamento de pacotes e um repositório online de pacotes de código aberto. Ele lida com gerenciamento de dependências, controle de versão e execução de scripts para projetos Node.js. O registro npm é o maior registro de software do mundo, contendo mais de um milhão de pacotes. O arquivo package.json do npm define metadados e dependências do projeto, permitindo compilações reproduzíveis em diferentes ambientes. Apesar da concorrência de alternativas como o Yarn, o npm continua sendo o gerenciador de pacotes mais utilizado no ecossistema JavaScript.
