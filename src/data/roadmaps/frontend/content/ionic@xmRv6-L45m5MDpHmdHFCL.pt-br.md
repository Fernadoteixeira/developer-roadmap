# Iônico

Ionic é um kit de ferramentas de UI de código aberto para a construção de aplicativos móveis e desktop multiplataforma de alta qualidade usando tecnologias da web (HTML, CSS e JavaScript). Ele aproveita estruturas da web populares como Angular, React ou Vue.js para lógica de aplicativo, ao mesmo tempo que fornece um rico conjunto de componentes de UI pré-construídos e funcionalidades nativas de dispositivos. Ionic usa Cordova ou Capacitor para empacotar aplicativos da web para implantação nativa, permitindo que os desenvolvedores criem aplicativos híbridos que podem acessar recursos do dispositivo por meio de plug-ins. A estrutura enfatiza o desempenho e a aparência nativa, oferecendo estilo adaptável para diferentes plataformas. Com foco em padrões web e compatibilidade entre plataformas, o Ionic permite que os desenvolvedores mantenham uma única base de código para múltiplas plataformas, tornando-o uma escolha popular para o rápido desenvolvimento de aplicativos móveis.
