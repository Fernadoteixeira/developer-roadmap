# HTML semântico

HTML semântico refere-se ao uso de marcação HTML para reforçar o significado do conteúdo da web, em vez de apenas definir sua aparência. Envolve o uso de elementos HTML que descrevem claramente sua finalidade e conteúdo. O HTML semântico melhora a acessibilidade, o SEO e a legibilidade do código. Os principais elementos incluem `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>` e `<footer>`. Também abrange o uso de níveis de cabeçalho apropriados (`<h1>` a `<h6>`), listas (`<ul>`, `<ol>`,`<li>`) e tabelas de dados (`<table>`, `<th>`, `<td>`). O HTML semântico ajuda os leitores de tela a interpretar o conteúdo da página, permite uma melhor renderização do navegador e fornece uma estrutura mais clara para os desenvolvedores. Ao usar elementos semanticamente corretos, os desenvolvedores criam documentos da Web mais significativos, acessíveis e de fácil manutenção, que são mais fáceis de serem compreendidos e processados ​​por humanos e máquinas.
