# Padrão PRPL

O padrão PRPL é uma estratégia de arquitetura de aplicações web projetada para melhorar o desempenho, especialmente em dispositivos móveis. PRPL significa Push, Render, Pré-cache e Lazy-load. Ele se concentra na otimização do tempo de carregamento inicial e na velocidade de navegação subsequente. O padrão envolve enviar recursos críticos para a rota inicial, renderizar a rota inicial o mais rápido possível, pré-armazenar em cache as rotas restantes e carregar lentamente outras rotas e ativos não críticos. Essa abordagem visa oferecer uma experiência de carregamento quase instantânea aos usuários, especialmente em redes mais lentas e dispositivos menos potentes. PRPL é frequentemente implementado usando tecnologias web modernas, como service workers, e é comumente associado a Progressive Web Apps (PWAs), embora possa ser aplicado a várias arquiteturas de aplicativos web.
