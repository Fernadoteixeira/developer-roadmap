# Acúmulo

Rollup é um empacotador de módulos para JavaScript que compila pequenos pedaços de código em estruturas maiores e mais complexas. É especializada na produção de pacotes menores e mais eficientes para módulos ES. Rollup é excelente em agitar árvores, eliminando código não utilizado para resultados mais enxutos. É particularmente adequado para bibliotecas e aplicativos que usam o formato de módulo ES. Rollup oferece suporte a vários formatos de saída, incluindo UMD e CommonJS, tornando-o versátil para diferentes cenários de implantação. Embora possa exigir mais configuração do que algumas alternativas, o foco do Rollup em módulos ES e seu empacotamento eficiente o tornam popular para projetos que priorizam pacotes pequenos e práticas modernas de JavaScript.
