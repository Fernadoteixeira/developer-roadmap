# API de credenciais

A API de gerenciamento de credenciais é um padrão da web que permite que sites interajam com o gerenciador de credenciais do navegador para armazenar, recuperar e gerenciar credenciais de usuários. Ele fornece uma interface programática para autenticação de usuário segura e contínua, permitindo recursos como login automático e inscrição com um toque. A API oferece suporte a vários tipos de credenciais, incluindo senhas, identidades federadas e credenciais de chave pública. Ao aproveitar esta API, os desenvolvedores podem melhorar a experiência do usuário, reduzindo o atrito de login, implementando uma troca de conta mais suave e melhorando a segurança geral. Ele funciona em conjunto com gerenciadores de senhas e autenticadores de plataforma, ajudando a agilizar os processos de autenticação em dispositivos e navegadores, ao mesmo tempo que adere às práticas modernas de segurança.
