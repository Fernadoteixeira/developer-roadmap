# DNS

DNS (Domain Name System) é um sistema de nomenclatura hierárquico e descentralizado para computadores, serviços ou outros recursos conectados à Internet ou a uma rede privada. Ele traduz nomes de domínio legíveis por humanos (como www.example.com) em endereços IP (como 192.0.2.1) que os computadores usam para se identificarem. Os servidores DNS distribuídos em todo o mundo trabalham juntos para resolver essas dúvidas, formando um serviço de diretório global. O sistema usa uma estrutura semelhante a uma árvore com servidores raiz no topo, seguidos por servidores de domínio de nível superior (.com, .org, etc.), servidores de nomes autorizados para domínios específicos e servidores DNS locais. O DNS é crucial para o funcionamento da Internet, permitindo aos utilizadores aceder a websites e serviços utilizando nomes memoráveis ​​em vez de endereços IP numéricos.
