# Buscar API

A API Fetch é uma interface JavaScript moderna para fazer solicitações HTTP em navegadores da web. Ele fornece uma maneira mais poderosa e flexível de enviar e receber dados em comparação com métodos mais antigos, como XMLHttpRequest. Fetch usa Promises, permitindo um código assíncrono mais limpo. Suporta vários formatos de dados, cabeçalhos personalizados e diferentes tipos de solicitações (GET, POST, etc.). A API foi projetada para ser extensível e se integrar bem com outras tecnologias da web. Embora seja mais simples para casos de uso básicos, o Fetch também lida com cenários complexos, como cancelamento de solicitações e leitura de respostas transmitidas. É amplamente suportado em navegadores modernos e tornou-se o padrão para solicitações de rede em aplicativos JavaScript do lado do cliente.
