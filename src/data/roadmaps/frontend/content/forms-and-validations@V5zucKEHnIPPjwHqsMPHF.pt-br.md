# Formulários e Validações

Antes de enviar os dados ao servidor, é importante garantir que todos os controles obrigatórios do formulário sejam preenchidos, no formato correto. Isso é chamado de validação de formulário do lado do cliente e ajuda a garantir que os dados enviados correspondam aos requisitos estabelecidos nos vários controles de formulário.

Visite os seguintes recursos para saber mais:

- [@article@MDN Web Docs: validação de formulário do lado do cliente](https://developer.mozilla.org/en-US/docs/Learn/Forms/Form_validation)
- [@article@Aprenda Formulários por web.dev](https://web.dev/learn/forms/)
- [@article@W3Schools: Validação de formulário JavaScript](https://www.w3schools.com/js/js_validation.asp)
