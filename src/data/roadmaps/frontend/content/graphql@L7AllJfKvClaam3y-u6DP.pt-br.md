# Gráficoql

GraphQL é uma linguagem de consulta e tempo de execução para APIs, desenvolvida pelo Facebook. A flexibilidade e eficiência do GraphQL o tornam popular para a construção de aplicativos complexos, especialmente aqueles com diversos requisitos de clientes. É particularmente útil para aplicações móveis onde a eficiência da largura de banda é crucial. Embora exija uma mudança de paradigma do REST, muitos desenvolvedores e organizações consideram que os benefícios do GraphQL superam a curva de aprendizado, especialmente para APIs em grande escala ou em rápida evolução.
