# esbuild

esbuild é um empacotador e minificador JavaScript de alto desempenho projetado para velocidade e eficiência. Criado por Evan Wallace, é escrito em Go e compilado em código nativo, tornando-o significativamente mais rápido do que as ferramentas de construção tradicionais baseadas em JavaScript. esbuild oferece suporte a recursos modernos de JavaScript, TypeScript e JSX prontos para uso, com tempos de empacotamento quase instantâneos, mesmo para projetos grandes. Ele oferece uma API simples e uma interface de linha de comando, facilitando a integração em pipelines de construção existentes. Embora focado principalmente na velocidade, o esbuild também fornece divisão básica de código, agitação de árvore e geração de mapa de origem. Seu desempenho extremo o torna particularmente adequado para ambientes de desenvolvimento e como base para outras ferramentas de construção, embora possa faltar alguns recursos avançados encontrados em empacotadores mais maduros.
