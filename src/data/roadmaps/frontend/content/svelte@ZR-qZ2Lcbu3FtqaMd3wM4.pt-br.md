# Esbelto

Svelte é uma estrutura JavaScript moderna para construção de interfaces de usuário que adota uma abordagem única para desenvolvimento web. Ao contrário das estruturas tradicionais que fazem a maior parte do trabalho no navegador, o Svelte transforma esse trabalho em uma etapa de compilação que ocorre quando você cria seu aplicativo. Ele compila seu código para JavaScript vanilla eficiente, resultando em pacotes menores e melhor desempenho de tempo de execução. Svelte usa uma arquitetura baseada em componentes e apresenta uma sintaxe simples e intuitiva que permite aos desenvolvedores escrever menos código. Inclui gerenciamento de estado integrado, escopo CSS e animações. A abordagem do Svelte elimina a necessidade de um DOM virtual, levando a carregamentos e atualizações iniciais mais rápidas. Sua simplicidade e benefícios de desempenho têm ganhado popularidade crescente na comunidade de desenvolvimento front-end.
