# Métricas de desempenho

As métricas de desempenho da Web são medidas quantitativas do desempenho de uma página ou aplicativo da Web. Eles são usados ​​para avaliar a velocidade e a eficiência de uma página da web e podem ajudar a identificar áreas de melhoria. Algumas métricas comuns de desempenho da web incluem:

- Tempo de carregamento: O tempo que leva para uma página da web carregar totalmente e se tornar interativa.
- Primeira pintura com conteúdo (FCP): O tempo que leva para o primeiro conteúdo aparecer na página.
- Tempo para interação (TTI): O tempo que leva para a página se tornar totalmente interativa.
- Atraso na primeira entrada (FID): O tempo que a página leva para responder à primeira entrada do usuário.
- Tempo total de bloqueio (TBT): Tempo que leva para a página se tornar totalmente interativa, levando em consideração o tempo gasto no bloqueio do thread principal.
