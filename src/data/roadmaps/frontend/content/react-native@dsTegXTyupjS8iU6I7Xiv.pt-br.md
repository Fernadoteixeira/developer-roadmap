# Reagir nativo

React Native é uma estrutura de desenvolvimento de aplicativos móveis de código aberto criada pelo Facebook. Ele permite que os desenvolvedores criem aplicativos móveis nativos para iOS e Android usando JavaScript e React. React Native traduz código JavaScript em componentes nativos, fornecendo desempenho quase nativo e uma interface de usuário nativa genuína. Ele permite a reutilização de código entre plataformas, acelerando o desenvolvimento e reduzindo custos. A estrutura oferece recarga a quente para iterações rápidas, acesso a APIs nativas e um grande ecossistema de plug-ins de terceiros. A filosofia "aprender uma vez, escrever em qualquer lugar" do React Native e sua capacidade de unir o desenvolvimento web e móvel o tornam popular para a criação de aplicativos móveis multiplataforma, especialmente entre equipes já familiarizadas com o React para desenvolvimento web.
