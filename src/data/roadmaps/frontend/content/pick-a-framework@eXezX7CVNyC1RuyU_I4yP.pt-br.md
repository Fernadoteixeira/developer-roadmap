# Escolha uma estrutura

Frameworks da Web são projetados para escrever aplicativos da Web. Frameworks são coleções de bibliotecas que auxiliam no desenvolvimento de um produto de software ou site. Frameworks para desenvolvimento de aplicações web são coleções de diversas ferramentas. As estruturas variam em suas capacidades e funções, dependendo das tarefas definidas. Eles definem a estrutura, estabelecem as regras e fornecem as ferramentas de desenvolvimento necessárias.
