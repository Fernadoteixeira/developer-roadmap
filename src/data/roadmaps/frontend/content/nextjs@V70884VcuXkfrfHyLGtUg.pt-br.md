# Próximo.js

Next.js é uma estrutura de código aberto baseada em React para a construção de aplicativos da web renderizados e gerados estaticamente no lado do servidor. Ele fornece recursos como divisão automática de código, desempenho otimizado e roteamento simplificado pronto para uso. Next.js suporta geração de site estático (SSG) e renderização do lado do servidor (SSR), permitindo que os desenvolvedores escolham o método de renderização mais apropriado para cada página. A estrutura oferece suporte CSS integrado, rotas de API para funcionalidade de back-end e opções fáceis de implantação. Next.js é conhecido por sua experiência amigável ao desenvolvedor, com recursos como substituição de módulo a quente e pré-busca automática. Sua capacidade de criar aplicativos híbridos que combinam páginas estáticas e renderizadas pelo servidor o torna popular para a construção de aplicativos da web escalonáveis ​​e amigáveis ​​para SEO.
