# Estratégias de autenticação

Estratégias de autenticação são métodos ou técnicas utilizadas para verificar a identidade de um usuário ou sistema a fim de conceder acesso a um recurso protegido. Existem várias estratégias de autenticação diferentes que podem ser usadas, incluindo:

- Autenticação Básica
- Autenticação baseada em sessão
- Autenticação baseada em token
- Autenticação JWT
- OAuth
- SSO

Você não precisa necessariamente aprender tudo isso, como implementar e os detalhes desde o início. Mas é importante saber o que são e como funcionam. Isso o ajudará a tomar melhores decisões ao escolher uma estratégia de autenticação para seu aplicativo.
