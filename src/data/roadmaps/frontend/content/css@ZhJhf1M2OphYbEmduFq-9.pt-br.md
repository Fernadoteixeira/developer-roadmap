# CSS

CSS (Cascading Style Sheets) é uma linguagem de estilo usada para descrever a apresentação de um documento escrito em HTML ou XML. Define como os elementos devem ser exibidos na tela, no papel ou em outras mídias. CSS separa o design do conteúdo, permitindo maior flexibilidade e controle sobre o layout, cores e fontes das páginas da web. Ele usa um sistema de seletores para direcionar elementos HTML e aplicar estilos a eles. CSS suporta design responsivo por meio de media queries, possibilitando a criação de layouts que se adaptam a diferentes tamanhos de tela e dispositivos. A cascata, a herança e a especificidade são conceitos-chave em CSS que determinam como os estilos são aplicados quando várias regras têm como alvo o mesmo elemento. CSS moderno inclui recursos como Flexbox e Grid para controle avançado de layout, animações e transições para a criação de interfaces de usuário dinâmicas.
