# Onze

Eleventy (11ty) é um gerador de site estático simples de usar, fácil de personalizar, de alto desempenho e poderoso, com um conjunto útil de plug-ins (por exemplo, navegação, transformações de imagem em tempo de construção, ativos de cache). As páginas podem ser construídas e escritas com uma variedade de linguagens de modelo (HTML, Markdown, JavaScript, Liquid, Nunjucks, Handlebars, Moustache, EJS, Haml, Pug ou literais de modelo JS). Mas também oferece a possibilidade de criar páginas dinamicamente a partir de dados locais ou fontes externas que são compiladas em tempo de construção. Não possui nenhuma dependência de JavaScript do lado do cliente.
