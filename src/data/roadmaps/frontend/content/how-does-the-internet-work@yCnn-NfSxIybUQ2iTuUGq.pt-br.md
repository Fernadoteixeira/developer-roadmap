# Como funciona a Internet

A internet é uma rede global que conecta computadores e dispositivos para que eles possam compartilhar informações entre si. É como você navega em sites, envia e-mails, assiste a vídeos e usa aplicativos. Pense nisso como uma teia gigante que liga tudo.
