# Dureza

Tauri é uma estrutura de código aberto para a construção de aplicativos de desktop leves e seguros usando tecnologias da web. Ele permite que os desenvolvedores criem aplicativos multiplataforma com HTML, CSS e JavaScript, enquanto usam um back-end Rust para funcionalidades principais. Tauri oferece pacotes menores em comparação com Electron, pois aproveita a visualização web nativa do sistema operacional em vez de agrupar o Chromium. Ele fornece recursos de segurança robustos, incluindo um protocolo personalizado para IPC (Comunicação entre processos) e permissões refinadas. Tauri oferece suporte a várias estruturas JavaScript e oferece ligações de API para várias operações em nível de sistema. Sua ênfase em desempenho, segurança e tamanhos binários pequenos o tornam uma opção atraente para desenvolvedores que buscam criar aplicativos de desktop eficientes com tecnologias web.
