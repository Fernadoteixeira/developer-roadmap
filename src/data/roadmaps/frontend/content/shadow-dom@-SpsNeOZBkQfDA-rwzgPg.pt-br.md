# Sombra DOM

O Shadow DOM é um padrão da web que fornece encapsulamento para JavaScript, CSS e modelos em componentes da web. Ele permite que os desenvolvedores criem árvores DOM isoladas dentro de elementos, separadas do DOM do documento principal. Esse encapsulamento evita que estilos e scripts entrem ou saiam, garantindo que os componentes internos permaneçam separados do restante da página. Shadow DOM permite código mais modular e de fácil manutenção, reduzindo conflitos de nomenclatura e problemas de especificidade de CSS. É particularmente útil para criar elementos personalizados reutilizáveis ​​com estilo e comportamento independentes. Embora usado principalmente em componentes da web, o Shadow DOM também pode ser aproveitado em vários cenários para melhorar a organização do código e reduzir efeitos colaterais indesejados em aplicativos da web complexos.
