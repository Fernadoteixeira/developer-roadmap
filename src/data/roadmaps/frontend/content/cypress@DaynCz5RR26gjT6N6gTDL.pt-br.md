# Cipreste

A estrutura Cypress é uma estrutura de teste ponta a ponta baseada em JavaScript construída sobre Mocha – uma estrutura de teste JavaScript rica em recursos executada no navegador, tornando os testes assíncronos simples e convenientes. Ele também usa uma biblioteca de asserções BDD/TDD e um navegador para emparelhar com qualquer estrutura de teste de JavaScript.
