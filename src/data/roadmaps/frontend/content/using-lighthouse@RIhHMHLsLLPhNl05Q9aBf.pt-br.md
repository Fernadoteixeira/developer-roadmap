# Farol

Lighthouse é uma ferramenta de código aberto desenvolvida pelo Google que é usada para auditar o desempenho, acessibilidade e SEO de páginas da web. Está disponível como extensão do navegador e como ferramenta de linha de comando, podendo ser executado em qualquer página da web para gerar um relatório com recomendações de melhorias. O Lighthouse funciona simulando o carregamento e a interação de uma página da web e medindo várias métricas de desempenho, como tempo de carregamento, tempo para a primeira pintura e tempo para interação. Ele também verifica problemas comuns, como tamanhos de imagem incorretos, texto alternativo ausente e links quebrados. O Lighthouse fornece uma ferramenta abrangente e fácil de usar para identificar e corrigir problemas de desempenho e acessibilidade em páginas da web. É amplamente utilizado por desenvolvedores web e está integrado a muitas ferramentas de desenvolvimento populares.
