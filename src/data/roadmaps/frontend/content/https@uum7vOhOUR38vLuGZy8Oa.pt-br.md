# HTTPS

O protocolo de transferência de hipertexto seguro (HTTPS) é a versão segura do HTTP, que é o protocolo principal usado para enviar dados entre um navegador da web e um site. HTTPS é criptografado para aumentar a segurança da transferência de dados. Isto é particularmente importante quando os usuários transmitem dados confidenciais, como ao fazer login em uma conta bancária, serviço de e-mail ou operadora de seguro saúde.
