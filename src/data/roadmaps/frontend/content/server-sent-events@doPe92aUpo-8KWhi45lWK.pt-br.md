# eventos enviados pelo servidor

Server-Sent Events (SSE) é uma tecnologia que permite que um servidor web envie dados para um cliente em tempo real. Ele usa uma conexão HTTP para enviar um fluxo de dados do servidor para o cliente, e o cliente pode ouvir esses eventos e agir quando eles forem recebidos. O SSE é útil para aplicativos que exigem atualizações em tempo real, como sistemas de bate-papo, cotações de ações e feeds de mídia social. É uma maneira simples e eficiente de estabelecer uma conexão duradoura entre um cliente e um servidor e é suportada pela maioria dos navegadores modernos.

Para usar o SSE, o cliente deve criar um objeto EventSource e especificar a URL do script do lado do servidor que enviará os eventos. O servidor pode então enviar eventos gravando-os no fluxo de resposta com a formatação adequada.
