# API de armazenamento na Web

A API Web Storage fornece mecanismos para armazenar pares de valores-chave em um navegador da web. Inclui dois objetos de armazenamento: localStorage e sessionStorage, que permitem salvar dados no lado do cliente e persisti-los em várias sessões do navegador, respectivamente. A API Web Storage foi projetada para ser simples e fácil de usar e é amplamente suportada em navegadores da web modernos. É frequentemente utilizado como alternativa aos cookies, pois permite armazenar maiores quantidades de dados e é mais eficiente em termos de desempenho.
