# Sockets da Web

Web Sockets é uma tecnologia que permite comunicação full-duplex em uma única conexão TCP. Ele permite a comunicação bidirecional em tempo real entre um cliente e um servidor e é normalmente usado em aplicativos que exigem comunicação de alta velocidade e baixa latência, como jogos online e streaming de dados em tempo real. Web Sockets utiliza uma conexão persistente entre um cliente e um servidor, permitindo a troca contínua de dados sem a necessidade do cliente enviar solicitações adicionais ao servidor. Isso o torna mais eficiente e rápido do que outras tecnologias, como HTTP, que exigem o envio de uma nova solicitação para cada dado. Web Sockets é compatível com a maioria dos navegadores modernos e pode ser usado com uma variedade de linguagens de programação e estruturas.
