# Geradores de sites estáticos

Geradores de sites estáticos (SSGs) são ferramentas que criam sites HTML a partir de dados brutos e modelos, produzindo páginas pré-renderizadas em tempo de construção e não em tempo de execução. Eles combinam os benefícios dos sites estáticos (velocidade, segurança, simplicidade) com a flexibilidade dos sites dinâmicos. SSGs normalmente usam linguagens de marcação como Markdown para conteúdo, mecanismos de modelagem para layouts e geram um site totalmente estático que pode ser hospedado em servidores web simples ou redes de distribuição de conteúdo. SSGs populares incluem Jekyll, Hugo, Gatsby e Eleventy. Eles são adequados para blogs, sites de documentação e sites focados em conteúdo. Os SSGs oferecem vantagens em desempenho, integração de controle de versão e redução da complexidade do lado do servidor, tornando-os cada vez mais populares para uma ampla variedade de projetos web.
