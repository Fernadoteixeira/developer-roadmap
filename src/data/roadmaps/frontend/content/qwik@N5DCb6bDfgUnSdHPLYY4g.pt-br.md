# Rápido

Qwik é uma estrutura front-end de código aberto projetada para desempenho ideal e carregamento quase instantâneo de aplicativos da web. Ele se concentra em fornecer um modelo de aplicativo "recuperável", onde o aplicativo pode começar a ser executado com o mínimo de download de JavaScript. O Qwik consegue isso por meio de carregamento lento refinado, serialização do estado do aplicativo e pré-busca. Ele usa uma abordagem única para hidratação, carregando JavaScript apenas para elementos interativos quando necessário. O Qwik foi desenvolvido para padrões web modernos e tem como objetivo resolver problemas de desempenho comuns em aplicações web de grande escala. Embora ainda seja relativamente nova em comparação com estruturas estabelecidas, a abordagem inovadora do Qwik para otimização de desempenho está atraindo atenção na comunidade de desenvolvimento web.
