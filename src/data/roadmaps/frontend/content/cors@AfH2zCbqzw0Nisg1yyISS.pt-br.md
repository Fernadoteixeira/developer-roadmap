# CORS

O Cross-Origin Resource Sharing (CORS) é um mecanismo de segurança implementado por navegadores da web para controlar o acesso a recursos (como APIs ou fontes) em uma página da web de um domínio diferente daquele que atende a página da web. Ela amplia e adiciona flexibilidade à Política de Mesma Origem, permitindo que os servidores especifiquem quem pode acessar seus recursos. O CORS funciona por meio de um sistema de cabeçalhos HTTP, onde os navegadores enviam uma solicitação de comprovação ao servidor que hospeda o recurso de origem cruzada, e o servidor responde com cabeçalhos indicando se a solicitação real é permitida. Esse mecanismo ajuda a impedir o acesso não autorizado a dados confidenciais, ao mesmo tempo que permite solicitações legítimas entre origens. O CORS é crucial para aplicações web modernas que muitas vezes integram serviços e recursos de vários domínios, equilibrando as necessidades de segurança com os requisitos de funcionalidade de sistemas web complexos e distribuídos.
