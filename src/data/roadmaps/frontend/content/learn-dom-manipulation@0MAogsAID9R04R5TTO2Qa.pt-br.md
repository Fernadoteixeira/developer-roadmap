# Manipulação de DOM

O Document Object Model (DOM) é uma interface de programação construída para documentos HTML e XML. Representa a página que permite que programas e scripts atualizem dinamicamente a estrutura, o conteúdo e o estilo do documento. Com o DOM, podemos acessar e manipular facilmente tags, IDs, classes, atributos, etc.
