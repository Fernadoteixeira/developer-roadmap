# Elementos personalizados

Um dos principais recursos do padrão Web Components é a capacidade de criar elementos personalizados que encapsulam sua funcionalidade em uma página HTML, em vez de ter que se contentar com um lote longo e aninhado de elementos que juntos fornecem um recurso de página personalizado.
