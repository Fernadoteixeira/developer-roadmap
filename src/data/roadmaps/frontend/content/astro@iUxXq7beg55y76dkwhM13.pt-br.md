# Astro

Astro é um moderno gerador de sites estáticos (SSG) e estrutura da web projetada para construir sites rápidos e focados em conteúdo. Ele permite que os desenvolvedores usem vários frameworks frontend (como React, Vue ou Svelte) dentro do mesmo projeto, renderizando automaticamente componentes em HTML estático no momento da construção. A abordagem exclusiva de “hidratação parcial” do Astro envia JavaScript ao navegador apenas quando necessário, resultando em pacotes significativamente menores e tempos de carregamento mais rápidos. A estrutura oferece suporte a roteamento baseado em arquivo, conteúdo de remarcação e otimizações integradas para imagens e ativos. A arquitetura de ilhas de componentes do Astro permite que os desenvolvedores criem componentes interativos enquanto mantêm os benefícios de desempenho do HTML estático, tornando-o particularmente adequado para sites ricos em conteúdo, como blogs, documentação e páginas de marketing.
