# JavaScript

JavaScript é uma linguagem de programação interpretada de alto nível que é uma tecnologia central da World Wide Web. Ele permite scripts dinâmicos do lado do cliente em navegadores da Web, permitindo páginas da Web e interfaces de usuário interativas. JavaScript oferece suporte a estilos de programação orientados a objetos, imperativos e funcionais. Também é usado no lado do servidor por meio do Node.js, para desenvolvimento de aplicativos de desktop com estruturas como Electron e em vários outros contextos. A linguagem apresenta digitação dinâmica, funções de primeira classe e orientação a objetos baseada em protótipos. A onipresença do JavaScript no desenvolvimento web, juntamente com sua versatilidade e evolução contínua através dos padrões ECMAScript, tornou-o uma das linguagens de programação mais populares em uso atualmente.
