# API de notificações

A API de notificações é uma API da web que permite que as páginas da web exibam notificações no nível do sistema para o usuário. Essas notificações podem ser utilizadas para alertar o usuário sobre eventos importantes, como novas mensagens ou atualizações, mesmo quando a página web não está aberta no navegador. Para usar a API de Notificações, uma página da web deve primeiro solicitar permissão do usuário para exibir notificações. Se a permissão for concedida, a página poderá usar o construtor `Notification` para criar uma nova notificação e exibi-la ao usuário. A notificação pode incluir um título, corpo de texto e um ícone, e pode ser personalizada com opções como tempo limite e ação de clique.
