# API de localização

A API de geolocalização é uma API web que fornece acesso aos dados de localização do dispositivo, como latitude e longitude. Ele permite que desenvolvedores web criem aplicativos baseados em localização, como mapeamento e compartilhamento de localização, usando o GPS, Wi-Fi e outros sensores do dispositivo para determinar a localização do usuário. Para usar a API de geolocalização, uma página da web deve primeiro solicitar permissão do usuário para acessar sua localização. Se a permissão for concedida, a página poderá usar o objeto `navigator.geolocation` para acessar os dados de localização do dispositivo. A API fornece vários métodos para obter a localização atual do usuário, observar alterações de localização e calcular distâncias entre dois locais.
