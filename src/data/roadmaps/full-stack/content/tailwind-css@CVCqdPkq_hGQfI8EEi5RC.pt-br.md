# Tailwind CSS

CSS Framework que fornece classes CSS atômicas para ajudá-lo a estilizar componentes, por exemplo. `flex`, `pt-4`, `text-center` e `rotate-90` que podem ser compostos para construir qualquer projeto, diretamente na sua marcação.
