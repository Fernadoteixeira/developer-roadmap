# Ponto de verificação

Neste ponto, você deverá ser capaz de construir um aplicativo front-end completo, incluindo:

- Estruturando suas páginas da web com HTML
- Estilizando suas páginas da web com CSS
- Adicionando interatividade às suas páginas da web com JavaScript
- Usando a API DOM para manipular suas páginas da web
- Usando a API Fetch para fazer solicitações HTTP
- Compreenda as promessas e use a sintaxe `async`/`await` para escrever código assíncrono
- Instalando e usando bibliotecas externas com npm
- Versão controlando seu código com Git
- Enviando seu código para GitHub

Se você decidiu pular o React e o Tailwind por enquanto, tudo bem também, mas você deverá ser capaz de construir um aplicativo front-end completo usando HTML, CSS e JavaScript simples. No entanto, tenha em mente que os aplicativos frontend modernos são construídos principalmente com estruturas como React, Vue e Angular. Portanto, você deve aprender pelo menos um deles a qualquer momento.

Isso marca o fim dos conceitos básicos de front-end que você precisava. Agora iremos passar para o desenvolvimento de back-end. Enquanto você continua com o desenvolvimento de back-end, saiba que há mais no desenvolvimento de front-end e lembre-se de verificar o [roteiro de front-end](/frontend) posteriormente em sua jornada.
