# Linux/Unix

O conhecimento de UNIX é obrigatório para quase todos os tipos de desenvolvimento, já que a maioria dos códigos que você escreve provavelmente serão finalmente implantados em uma máquina UNIX/Linux. O Linux tem sido a espinha dorsal do movimento do software livre e de código aberto, fornecendo um sistema operacional simples e elegante para quase todas as suas necessidades.
