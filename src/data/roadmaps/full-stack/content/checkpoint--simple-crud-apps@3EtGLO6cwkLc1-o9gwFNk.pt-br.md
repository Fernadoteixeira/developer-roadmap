# Ponto de verificação

**CRUD** significa **Criar, Ler, Atualizar e Excluir**. Estas são as quatro operações básicas que você pode realizar em qualquer dado ao trabalhar com aplicativos web, bancos de dados e APIs.

Agora que você conhece a linguagem de programação e os bancos de dados, deverá ser capaz de construir um aplicativo CLI simples que interaja com o banco de dados. Ainda não falamos sobre APIs, mas você não precisa de uma API para praticar operações CRUD. Aqui estão alguns dos aplicativos CLI que você pode construir para praticar operações CRUD:

- Um aplicativo simples de lista de tarefas para CLI com as seguintes opções:
  - `--new` para adicionar um novo item de tarefa
  - `--list [all|pending|done]` para listar os itens de tarefas
  - `--done [id]` para atualizar um item de tarefa
  - `--delete [id]` para excluir um item de tarefa
  - `--help` para listar todas as opções disponíveis
  - `--version` para imprimir a versão do aplicativo
