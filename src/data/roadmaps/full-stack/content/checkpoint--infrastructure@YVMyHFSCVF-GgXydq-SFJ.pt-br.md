# Ponto de verificação

Se você se lembra, no início do roteiro, você efetuou login manualmente no console AWS e teve que configurar os serviços. Agora que você conhece o terraform, vá em frente e automatize o processo de criação da infraestrutura para sua aplicação usando o terraform e com isso suas implantações serão totalmente automatizadas ou seja, você deverá ter:

- Configuração de infraestrutura usando terraform
- Provisionamento usando Ansible
- CI/CD usando ações do GitHub
- Monitoramento usando Monit

E é isso! Você concluiu o roteiro com sucesso e agora é um desenvolvedor full stack. Parabéns! 🎉
