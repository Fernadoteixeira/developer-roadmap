# Ponto de verificação

Neste ponto, você deve ter tudo o que precisa para construir um aplicativo completo que:

- Possui um front-end responsivo com o qual os usuários podem interagir
- Possui uma API de back-end protegida com autenticação JWT
- Possui um banco de dados que armazena dados

Neste ponto, você deve praticar a construção sozinho o máximo que puder para solidificar seu conhecimento. Se precisar de inspiração, aqui estão algumas ideias:

- Crie um aplicativo de blog simples onde os usuários possam se registrar, fazer login, configurar seu blog e escrever postagens.
- Um construtor de sites de página única onde os usuários podem escolher um modelo, modificá-lo e publicá-lo. **Dica** você precisará de um sistema de arquivos para armazenar os modelos de design. Os arquivos de modelo terão espaços reservados que você precisará substituir pelos dados do usuário.
- Crie um aplicativo de comércio eletrônico simples que terá dois tipos de usuários, ou seja, **Vendedores** que podem: registrar-se como vendedor, fazer login, configurar sua loja, adicionar produtos, editar produtos, excluir produtos, visualizar pedidos recebidos, atualizar o status do pedido (pendente, enviado, entregue), **compradores** que podem se registrar, fazer login, navegar pelos produtos de todos os vendedores, adicionar produtos ao carrinho, finalizar a compra, visualizar o histórico do pedido, visualizar o status do pedido, cancelar o pedido, visualizar o perfil do vendedor, visualizar os produtos do vendedor

Estas são apenas algumas ideias para você começar. Você pode construir o que quiser. O objetivo é praticar a construção de um aplicativo completo do zero.
