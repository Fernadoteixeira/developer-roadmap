# JWT

JWT significa JSON Web Token é um padrão/metodologia aberta de criptografia baseada em token que é usado para transferir informações com segurança como um objeto JSON. Clientes e servidores usam JWT para compartilhar informações com segurança, com o JWT contendo declarações e objetos JSON codificados. Os JWTs são projetados para serem compactos, seguros para uso em URLs e ideais para contextos de SSO.
