# Ansible

Ansible é uma ferramenta de gerenciamento de configuração, implantação de aplicativos e provisionamento de código aberto que usa sua própria linguagem declarativa em YAML. Ansible não tem agente, o que significa que você só precisa de conexões remotas via SSH ou gerenciamento remoto do Windows via Powershell para funcionar
