# Ponto de verificação

Agora que você aprendeu git e GitHub, você deve estar pronto para trabalhar com outras pessoas. Agora você deve configurar seu perfil GitHub e enviar todos os projetos que você construiu até agora para seu perfil GitHub. Aqui estão algumas das minhas recomendações para o seu perfil GitHub:

- Mantenha os nomes dos repositórios em letras minúsculas e use hífens para separar palavras, por exemplo. `todo-app` em vez de `TodoApp` ou `Todo-App`.
- Adicione um arquivo `README.md` a cada repositório que você criar. Este arquivo deve conter uma descrição do projeto. Coloque algum esforço no leia-me e certifique-se de que ele detalha claramente do que se trata o projeto e como qualquer pessoa pode executá-lo localmente.
- Adicione instantâneos do seu projeto ao arquivo leia-me para que qualquer pessoa possa ver a aparência do projeto sem precisar executá-lo localmente.
- Adicione um arquivo `LICENSE` a cada repositório que você criar. Este arquivo deve conter a licença que você deseja usar para o projeto. Você pode usar [choosealicense.com](https://choosealicense.com/) para ajudá-lo a escolher uma licença.

Você pode dar uma olhada em [meu perfil do GitHub](https://github.com/kamranahmedse) e ver como estruturei meus repositórios e como [alguns dos meus arquivos leia-me se parecem](https://github.com/kamranahmedse/aws-cost-cli).
