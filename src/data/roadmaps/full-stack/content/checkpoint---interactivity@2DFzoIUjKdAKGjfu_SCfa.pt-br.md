# Ponto de verificação

Neste ponto, você poderá adicionar interatividade às suas páginas da web usando JavaScript. Você deve se certificar de que aprendeu o seguinte:

- Conhecer variáveis, loops, tipos de dados, condicionais, funções.
- Conhecer arrays e objetos e diferentes formas de acessar seus dados.
- Saber selecionar elementos DOM.
- Adicione ouvintes de eventos aos elementos DOM (por exemplo, clique, foco, envio de formulário).
- Use JavaScript para adicionar e remover elementos DOM
- Adicionar e remover classes de elementos DOM
- Use JavaScript para fazer solicitações HTTP para APIs externas (ou seja, `fetch`)
- Use JavaScript para armazenar dados no armazenamento local do navegador

Aqui estão algumas idéias para praticar suas habilidades:

- Crie um aplicativo simples de lista de tarefas que permite aos usuários pesquisar, adicionar, editar e excluir itens. Use armazenamento local para armazenar os dados.
- Crie uma página da web simples onde o usuário pode inserir o nome de usuário do GitHub de qualquer pessoa e ver as informações do perfil. Você pode usar a API do GitHub para buscar os dados. Por exemplo, aqui está o [exemplo de URL para buscar meus dados](https://api.github.com/users/kamranahmedse). Certifique-se de adicionar validação e tratamento de erros.
- Crie um aplicativo de calculadora básico que permita aos usuários realizar operações aritméticas básicas.
