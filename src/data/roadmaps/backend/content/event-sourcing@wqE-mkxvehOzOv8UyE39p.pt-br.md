# Fonte de eventos

Fonte de eventos é um padrão de design no qual o estado de um sistema é representado como uma sequência de eventos que ocorreram ao longo do tempo. Em um sistema com origem em eventos, as alterações no estado do sistema são registradas como eventos e armazenadas em um armazenamento de eventos. O estado atual do sistema é obtido pela reprodução dos eventos do armazenamento de eventos. Um dos principais benefícios do Event sourcing é que ele fornece um histórico claro e auditável de todas as alterações que ocorreram no sistema. Isso pode ser útil para depuração e para acompanhar a evolução do sistema ao longo do tempo. O fornecimento de eventos é frequentemente usado em conjunto com outros padrões, como Command Query Responsibility Segregation (CQRS) e design orientado a domínio, para construir sistemas escaláveis ​​e responsivos com lógica de negócios complexa. Também é útil para construir sistemas que precisam suportar funcionalidades de desfazer/refazer ou que precisam ser integrados com sistemas externos.
