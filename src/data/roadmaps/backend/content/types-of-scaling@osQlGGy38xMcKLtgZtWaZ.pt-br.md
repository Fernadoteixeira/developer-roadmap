# Escala horizontal/vertical

O dimensionamento horizontal (expansão/redução horizontal) envolve a adição ou remoção de instâncias de recursos, como servidores ou contêineres, para lidar com cargas aumentadas ou diminuídas. Ele distribui a carga de trabalho entre várias instâncias para melhorar o desempenho e a redundância. Este método aumenta a capacidade do sistema expandindo o número de nós em um sistema distribuído.

O escalonamento vertical (aumento/redução de escala) envolve aumentar ou diminuir os recursos (CPU, memória, armazenamento) de uma única instância ou servidor para lidar com mais carga ou reduzir a capacidade. Este método melhora o desempenho ao atualizar o hardware ou a máquina virtual existente, mas tem limites baseados na capacidade máxima do recurso individual.
