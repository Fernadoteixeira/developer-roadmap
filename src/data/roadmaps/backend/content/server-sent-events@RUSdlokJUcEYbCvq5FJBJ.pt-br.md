# eventos enviados pelo servidor

Server-Sent Events (SSE) é uma tecnologia para enviar atualizações em tempo real de um servidor para um cliente web por meio de uma conexão HTTP única e persistente. Ele permite que os servidores enviem atualizações aos clientes com eficiência e se reconectem automaticamente se a conexão for perdida. O SSE é ideal para aplicativos que precisam de comunicação unidirecional, como notificações ao vivo ou feeds de dados em tempo real, e usa um formato simples baseado em texto para transmitir dados de eventos, que pode ser facilmente manipulado por clientes usando a API `EventSource` em JavaScript.
