# OAuth

OAuth é um padrão aberto de autorização que permite que aplicativos de terceiros acessem os recursos de um usuário sem expor suas credenciais. Ele funciona emitindo tokens de acesso depois que os usuários concedem permissão, que os aplicativos usam para interagir com servidores de recursos em nome do usuário. Este processo envolve um proprietário de recursos (o usuário), um servidor de recursos (que contém os dados) e um servidor de autorização (que emite tokens). OAuth permite o gerenciamento de acesso seguro baseado em token, comumente usado para conceder permissões a aplicativos para interagir com serviços como contas de mídia social ou armazenamento em nuvem.
