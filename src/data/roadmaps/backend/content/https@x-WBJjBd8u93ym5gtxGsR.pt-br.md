# HTTPS

HTTPS (Hypertext Transfer Protocol Secure) é uma extensão do HTTP projetada para proteger a transmissão de dados entre um cliente (por exemplo, navegador) e um servidor. Ele usa criptografia por meio de protocolos SSL/TLS para garantir a confidencialidade, integridade e autenticidade dos dados. Isso evita que informações confidenciais, como credenciais de login ou detalhes de pagamento, sejam interceptadas ou adulteradas por invasores. HTTPS é essencial para proteger aplicativos da web e se tornou um padrão para a maioria dos sites, especialmente aqueles que lidam com dados do usuário, pois ajuda a proteger contra ataques man-in-the-middle e espionagem.
