# Base

O Oracle Base Database Service permite que você mantenha controle absoluto sobre seus dados enquanto usa os recursos combinados do Oracle Database e do Oracle Cloud Infrastructure. O Oracle Base Database Service oferece sistemas de banco de dados (sistemas de banco de dados) em máquinas virtuais. Eles estão disponíveis como sistemas de banco de dados de nó único e sistemas de banco de dados RAC de vários nós no Oracle Cloud Infrastructure (OCI). Você pode gerenciar esses sistemas de banco de dados usando o Console do OCI, a API do OCI, a CLI do OCI, a CLI do banco de dados (DBCLI), o Enterprise Manager ou o SQL Developer.
