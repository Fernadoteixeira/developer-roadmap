# Escala de tempo

TimescaleDB é um banco de dados de série temporal de código aberto construído como uma extensão do PostgreSQL. Ele foi projetado para lidar com grandes volumes de dados com registro de data e hora de forma eficiente, tornando-o adequado para aplicativos que exigem análises de alto desempenho em dados de séries temporais, como sistemas de monitoramento, aplicativos de IoT e serviços financeiros. O TimescaleDB aproveita os recursos do PostgreSQL ao mesmo tempo que fornece recursos adicionais para dados de série temporal, incluindo ingestão eficiente de dados, consultas avançadas baseadas em tempo e particionamento automático de dados (hipertabelas). Ele oferece suporte a consultas e agregações complexas, o que o torna uma ferramenta poderosa para analisar tendências e padrões em dados de séries temporais.
