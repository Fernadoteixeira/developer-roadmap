# Degradação Graciosa

A degradação graciosa é um princípio de design que afirma que um sistema deve ser projetado para continuar funcionando, mesmo que alguns de seus componentes ou recursos não estejam disponíveis. No contexto do desenvolvimento web, a degradação normal refere-se à capacidade de uma página web ou aplicativo continuar funcionando, mesmo que o navegador ou dispositivo do usuário não suporte determinados recursos ou tecnologias. A degradação graciosa é frequentemente usada como uma alternativa ao aprimoramento progressivo, um princípio de design que afirma que um sistema deve ser projetado para aproveitar recursos e tecnologias avançadas, se estiverem disponíveis.
