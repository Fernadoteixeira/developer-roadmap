# Linguagem de marcação de declaração de segurança (SAML)

Security Assertion Markup Language (SAML) é uma estrutura baseada em XML usada para logon único (SSO) e federação de identidade, permitindo que os usuários se autentiquem uma vez e obtenham acesso a vários aplicativos ou serviços. Permite a troca de dados de autenticação e autorização entre um provedor de identidade (IdP) e um provedor de serviços (SP). Asserções SAML são documentos XML que contêm informações e atributos de identidade do usuário e são usados ​​para transmitir credenciais e permissões de autenticação. Ao implementar SAML, as organizações podem agilizar o gerenciamento de usuários, aumentar a segurança por meio de autenticação centralizada e simplificar a experiência do usuário, reduzindo a necessidade de vários logins em diferentes sistemas.
