# SQLite

SQLite é um mecanismo de banco de dados SQL leve, sem servidor e independente, projetado para simplicidade e eficiência. É amplamente utilizado em sistemas embarcados e aplicativos onde não é necessário um servidor de banco de dados completo, como aplicativos móveis, aplicativos de desktop e sites de pequeno e médio porte. SQLite armazena dados em um único arquivo, o que facilita a implantação e o gerenciamento. Ele oferece suporte a consultas SQL padrão e fornece conformidade com ACID (Atomicidade, Consistência, Isolamento, Durabilidade) para garantir a integridade dos dados. O tamanho reduzido, a configuração mínima e a facilidade de uso do SQLite o tornam uma escolha popular para aplicativos que precisam de uma solução de banco de dados compacta e de alto desempenho.
