# MariaDB

O servidor MariaDB é um fork do servidor MySQL desenvolvido pela comunidade. Iniciado por membros principais da equipe original do MySQL, o MariaDB trabalha ativamente com desenvolvedores externos para fornecer o servidor SQL aberto mais rico em recursos, estável e devidamente licenciado do setor. MariaDB foi criado com a intenção de ser uma versão mais versátil e substituta do MySQL
