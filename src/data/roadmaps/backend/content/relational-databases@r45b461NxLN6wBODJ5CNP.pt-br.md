# Bancos de dados relacionais

Bancos de dados relacionais são um tipo de sistema de gerenciamento de banco de dados (SGBD) que organiza os dados em tabelas estruturadas com linhas e colunas, usando um esquema para definir relacionamentos e restrições de dados. Eles empregam Linguagem de Consulta Estruturada (SQL) para consultar e gerenciar dados, suportando operações como recuperação, inserção, atualização e exclusão de dados. Os bancos de dados relacionais reforçam a integridade dos dados por meio de chaves (primárias e estrangeiras) e restrições (como exclusivas e não nulas) e são projetados para lidar com consultas, transações e relacionamentos de dados complexos com eficiência. Exemplos de bancos de dados relacionais incluem MySQL, PostgreSQL e Oracle Database. Eles são comumente usados ​​para aplicações que exigem armazenamento estruturado de dados, forte consistência e recursos de consulta complexos.
