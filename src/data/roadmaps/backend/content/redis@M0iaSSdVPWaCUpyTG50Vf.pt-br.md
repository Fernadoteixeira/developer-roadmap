# Redis

Redis é um armazenamento de estrutura de dados na memória de código aberto, conhecido por sua velocidade e versatilidade. Ele oferece suporte a vários tipos de dados, incluindo strings, listas, conjuntos, hashes e conjuntos classificados, e fornece funcionalidades como cache, gerenciamento de sessão, análise em tempo real e corretagem de mensagens. O Redis opera como um armazenamento de valores-chave, permitindo operações rápidas de leitura e gravação, e é frequentemente usado para melhorar o desempenho e a escalabilidade em aplicativos. Ele oferece suporte a opções de persistência para salvar dados em disco, replicação para alta disponibilidade e clustering para escalabilidade horizontal. O Redis é amplamente utilizado em cenários que exigem acesso de baixa latência aos dados e desempenho de alto rendimento.
