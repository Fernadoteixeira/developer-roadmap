# Ódios

HATEOAS (Hypermedia As The Engine Of Application State) é uma restrição da arquitetura RESTful que permite aos clientes navegar dinamicamente em uma API por meio de links hipermídia fornecidos nas respostas. Em vez de URLs ou endpoints codificados, o cliente descobre as ações disponíveis por meio desses links, da mesma forma que um navegador segue links em uma página da web. Isso permite maior flexibilidade e separa os clientes das alterações no servidor, tornando o sistema mais adaptável e escalável sem interromper os clientes existentes. É um elemento-chave do princípio de apatridia e mensagens autodescritivas do REST.
