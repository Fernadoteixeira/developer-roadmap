# Autenticação de token

A autenticação baseada em token é um protocolo que permite aos usuários verificar sua identidade e, em troca, receber um token de acesso exclusivo. Durante a vida do token, os usuários acessam o site ou aplicativo para o qual o token foi emitido, em vez de precisar inserir novamente as credenciais sempre que voltarem à mesma página da Web, aplicativo ou qualquer recurso protegido com o mesmo token. Os tokens de autenticação funcionam como um ticket carimbado. O usuário mantém o acesso enquanto o token permanecer válido. Depois que o usuário sai ou sai de um aplicativo, o token é invalidado. A autenticação baseada em token é diferente das técnicas tradicionais de autenticação baseadas em senha ou em servidor. Os tokens oferecem uma segunda camada de segurança e os administradores têm controle detalhado sobre cada ação e transação.
