# Aplicativos de doze fatores

A metodologia Twelve-Factor App é um conjunto de princípios para a construção de aplicações web modernas, escaláveis ​​e de fácil manutenção, particularmente adequadas para ambientes em nuvem. Ele enfatiza as melhores práticas para o desenvolvimento de aplicativos de uma forma que facilite a portabilidade, a escalabilidade e a facilidade de implantação. Os princípios-chave incluem:

1. **Codebase**: uma base de código rastreada no controle de versão, com muitas implantações.
2. **Dependências**: declare e isole explicitamente as dependências.
3. **Config**: Armazena a configuração no ambiente.
4. **Serviços de apoio**: trate os serviços de apoio como recursos anexados.
5. **Construir, Liberar, Executar**: estágios separados de compilação e execução.
6. **Processos**: execute o aplicativo como um ou mais processos sem estado.
7. **Port Binding**: exporta serviços por meio de port binding.
8. **Simultaneidade**: expansão por meio do modelo de processo.
9. **Descartável**: Maximize a robustez com inicialização rápida e desligamento suave.
10. **Paridade Dev/Prod**: Mantenha os ambientes de desenvolvimento, preparação e produção o mais semelhantes possível.
11. **Logs**: trate os logs como fluxos de eventos.
12. **Processos administrativos**: execute tarefas administrativas ou de gerenciamento como processos únicos.
