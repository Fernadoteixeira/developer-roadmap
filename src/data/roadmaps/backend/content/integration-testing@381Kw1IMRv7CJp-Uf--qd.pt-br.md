# Teste de Integração

Os testes de integração concentram-se na verificação das interações entre diferentes componentes ou módulos de um sistema de software para garantir que funcionem juntos conforme esperado. Ele vem após testes unitários e testa como os módulos se comunicam entre si, geralmente usando APIs, bancos de dados ou serviços de terceiros. O objetivo é detectar problemas relacionados aos pontos de integração, como incompatibilidades de dados, erros de protocolo ou configurações incorretas. Os testes de integração ajudam a garantir que os componentes desenvolvidos de forma independente possam funcionar perfeitamente como parte de um sistema maior, tornando-os cruciais para identificar bugs que não surgiriam em testes unitários isolados.
