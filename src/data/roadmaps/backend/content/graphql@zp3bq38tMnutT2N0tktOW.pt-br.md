# GráficoQL

GraphQL é uma linguagem de consulta para APIs e um tempo de execução para execução dessas consultas, desenvolvida pelo Facebook. Ao contrário do REST, onde endpoints fixos retornam dados predefinidos, o GraphQL permite que os clientes solicitem exatamente os dados de que precisam, tornando as interações da API mais flexíveis e eficientes. Ele usa um único endpoint e depende de um esquema que define os tipos e a estrutura dos dados disponíveis. Essa abordagem reduz a busca excessiva e insuficiente de dados, tornando-a ideal para aplicativos complexos com diversas necessidades de dados em diversas plataformas (por exemplo, web, dispositivos móveis).
