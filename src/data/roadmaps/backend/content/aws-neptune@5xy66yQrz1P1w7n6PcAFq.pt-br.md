# AWS Netuno

Amazon Neptune é um serviço de banco de dados gráfico totalmente gerenciado fornecido pela Amazon Web Services (AWS). Ele foi projetado para armazenar e navegar em dados altamente conectados, suportando gráficos de propriedades e modelos RDF (Resource Description Framework). Neptune usa linguagens de consulta gráfica como Gremlin e SPARQL, tornando-o adequado para aplicações que envolvem relacionamentos complexos, como redes sociais, mecanismos de recomendação, sistemas de detecção de fraude e gráficos de conhecimento. Ele oferece alta disponibilidade, com replicação em diversas zonas de disponibilidade, e suporta até 15 réplicas de leitura para melhorar o desempenho. O Neptune se integra a outros serviços da AWS, fornece criptografia em repouso e em trânsito e oferece recuperação rápida em caso de falhas. Sua escalabilidade e desempenho o tornam valioso para lidar com relacionamentos de dados complexos e em grande escala em aplicativos de nível empresarial.
