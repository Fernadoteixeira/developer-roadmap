# Transações

Em sistemas de banco de dados, uma transação é uma série de operações executadas como uma unidade atômica única para garantir a integridade e consistência dos dados. As transações aderem às propriedades ACID: A atomicidade garante que todas as operações sejam concluídas com êxito ou nenhuma seja aplicada; A consistência mantém o estado válido do banco de dados; O isolamento evita que as transações interfiram umas nas outras; e Durabilidade garante que, uma vez confirmada uma transação, suas alterações sejam permanentes. Essas propriedades garantem coletivamente que os bancos de dados lidam com operações simultâneas de maneira confiável e mantêm dados precisos e consistentes mesmo diante de falhas.
