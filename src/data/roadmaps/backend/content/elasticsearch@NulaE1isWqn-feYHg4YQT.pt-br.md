# Elasticsearch

A pesquisa elástica em sua essência é um mecanismo de pesquisa orientado a documentos. É um banco de dados baseado em documentos que permite INSERT, DELETE, RETRIEVE e até mesmo realizar análises nos registros salvos. Porém, o Elastic Search é diferente de qualquer outro banco de dados de uso geral com o qual você trabalhou no passado. É essencialmente um mecanismo de busca e oferece um arsenal de recursos que você pode usar para recuperar os dados nele armazenados, de acordo com seus critérios de pesquisa. E isso também, na velocidade da luz.
