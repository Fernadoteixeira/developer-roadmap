# Teste de unidade

O teste de unidade é um método de teste de software em que componentes ou unidades individuais de um programa são testados isoladamente para garantir que funcionem corretamente. Esta abordagem concentra-se na verificação das menores partes testáveis ​​de uma aplicação, como funções ou métodos, executando-as com entradas predefinidas e comparando os resultados com os resultados esperados. Os testes de unidade são normalmente automatizados e escritos pelos desenvolvedores durante a fase de codificação para detectar bugs antecipadamente, facilitar a refatoração do código e garantir que cada unidade de código tenha o desempenho esperado. Ao isolar e testar cada componente, o teste unitário ajuda a melhorar a confiabilidade e a capacidade de manutenção do código.
