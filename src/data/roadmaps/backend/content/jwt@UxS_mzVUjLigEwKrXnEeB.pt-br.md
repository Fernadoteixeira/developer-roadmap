# JWT

JWT (JSON Web Token) é um padrão aberto para transmissão segura de informações entre as partes como um objeto JSON. Consiste em três partes: um cabeçalho (que especifica o tipo de token e o algoritmo usado para assinatura), uma carga útil (que contém as declarações ou os dados que estão sendo transmitidos) e uma assinatura (que é usada para verificar a integridade e autenticidade do token). JWTs são comumente usados ​​para fins de autenticação e autorização, permitindo que os usuários transmitam e validem com segurança sua identidade e permissões em aplicativos web e APIs. Eles são compactos, independentes e podem ser facilmente transmitidos em cabeçalhos HTTP, o que os torna populares para aplicativos móveis e da Web modernos.
