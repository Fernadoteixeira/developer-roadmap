# github

GitHub é uma plataforma baseada na web para controle de versão e colaboração usando Git. Propriedade da Microsoft, fornece hospedagem para desenvolvimento de software e oferece recursos além da funcionalidade básica do Git. GitHub inclui ferramentas para gerenciamento de projetos, revisão de código e codificação social. Os principais recursos incluem repositórios para armazenar código, solicitações pull para propor e revisar alterações, problemas para rastrear bugs e tarefas e ações para automatizar fluxos de trabalho. Suporta repositórios públicos e privados, tornando-o popular para projetos de código aberto e desenvolvimento privado. Os recursos colaborativos do GitHub, como bifurcação de repositórios e comentários de código embutidos, facilitam o desenvolvimento da equipe e as contribuições da comunidade. Com suas extensas integrações e grande base de usuários, o GitHub se tornou um hub central para desenvolvedores, servindo como portfólio, plataforma de colaboração e ferramenta de implantação para projetos de software de todos os tamanhos.
