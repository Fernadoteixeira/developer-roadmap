# Java

Java é uma linguagem de programação orientada a objetos de alto nível, conhecida por sua portabilidade, robustez e escalabilidade. Desenvolvido pela Sun Microsystems (agora Oracle), o Java segue o princípio “escreva uma vez, execute em qualquer lugar”, permitindo que o código seja executado em qualquer dispositivo com uma Java Virtual Machine (JVM). É amplamente utilizado para criar aplicativos corporativos em grande escala, aplicativos móveis Android e serviços da web. Java apresenta gerenciamento automático de memória (coleta de lixo), uma vasta biblioteca padrão e fortes recursos de segurança, tornando-o uma escolha popular para sistemas back-end, aplicativos distribuídos e soluções baseadas em nuvem.
