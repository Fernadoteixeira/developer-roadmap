# SABÃO

Simple Object Access Protocol (SOAP) é um protocolo de mensagens para troca de informações entre sistemas e aplicativos. Quando se trata de interfaces de programação de aplicativos (APIs), uma API SOAP é desenvolvida de forma mais estruturada e formalizada. As mensagens SOAP podem ser transportadas por uma variedade de protocolos de nível inferior, incluindo o Hypertext Transfer Protocol (HTTP) relacionado à web.
