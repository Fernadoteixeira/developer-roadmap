# Estratégias de fragmentação

A estratégia de sharding é uma técnica para dividir um grande conjunto de dados em pedaços menores (fragmento lógico) em que distribuímos esses pedaços em diferentes máquinas/nós de banco de dados para distribuir a carga de tráfego. É um bom mecanismo para melhorar a escalabilidade de um aplicativo. Muitos bancos de dados suportam fragmentação, mas não todos.
