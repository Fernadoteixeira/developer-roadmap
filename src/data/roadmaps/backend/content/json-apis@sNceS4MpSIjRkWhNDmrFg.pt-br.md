# API JSON

JSON ou JavaScript Object Notation é um esquema de codificação projetado para eliminar a necessidade de um código ad-hoc para cada aplicativo se comunicar com servidores que se comunicam de uma maneira definida. O módulo JSON API expõe uma implementação para armazenamentos de dados e estruturas de dados, como tipos de entidade, pacotes configuráveis ​​e campos.
