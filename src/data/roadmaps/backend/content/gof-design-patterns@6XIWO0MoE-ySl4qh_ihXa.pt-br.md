# Padrões de design GoF

Os padrões de design da Gang of Four (GoF) são uma coleção de 23 padrões de design de software básicos que fornecem soluções para problemas comuns de design orientado a objetos. Esses padrões são agrupados em três categorias: _Creational_ (focado na criação de objetos como Singleton e Factory), _Structural_ (focado na composição de classes e objetos como Adapter e Composite) e _Behavioral_ (focado na comunicação entre objetos como Observer e Strategy). Cada padrão oferece um modelo comprovado para enfrentar desafios específicos de design, promovendo a reutilização, flexibilidade e capacidade de manutenção do código em sistemas de software.
