# Sistemas de controle de versão

Sistemas de controle de versão (VCS) são ferramentas que gerenciam e rastreiam alterações em códigos ou documentos ao longo do tempo, permitindo que vários usuários colaborem em um projeto de forma eficiente. Eles registram todas as alterações feitas nos arquivos, permitindo que os desenvolvedores revertam para versões anteriores, comparem as alterações e mantenham um histórico de modificações. O VCS pode ser centralizado, onde o repositório é hospedado em um servidor central (por exemplo, Subversion), ou distribuído, onde cada usuário possui uma cópia completa do repositório (por exemplo, Git, Mercurial). O controle de versão facilita a colaboração, melhora a integridade do código e oferece suporte à integração contínua, permitindo o gerenciamento tranquilo de alterações simultâneas e a resolução de conflitos.
