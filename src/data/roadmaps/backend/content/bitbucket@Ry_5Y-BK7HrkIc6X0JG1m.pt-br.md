# Bitbucket

Bitbucket é um serviço de hospedagem de repositório de controle de versão baseado na web de propriedade da Atlassian. Ele usa principalmente sistemas de controle de versão Git, oferecendo opções hospedadas na nuvem e auto-hospedadas. O Bitbucket fornece recursos como solicitações pull para revisão de código, permissões de ramificação e comentários embutidos no código. Ele se integra perfeitamente a outros produtos Atlassian, como Jira e Trello, tornando-o popular entre as equipes que já usam ferramentas Atlassian. O Bitbucket oferece suporte à integração e implantação contínuas por meio do Bitbucket Pipelines. Oferece repositórios privados ilimitados para equipes pequenas, tornando-o econômico para organizações menores.
