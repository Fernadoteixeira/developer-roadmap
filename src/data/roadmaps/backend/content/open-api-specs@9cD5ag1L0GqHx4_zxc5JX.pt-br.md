# Abra as especificações da API

A Especificação OpenAPI (OAS), anteriormente conhecida como Swagger, é um padrão para definir e documentar APIs RESTful. Ele fornece um formato estruturado em YAML ou JSON para descrever endpoints de API, formatos de solicitação e resposta, métodos de autenticação e outros metadados. Ao usar o OAS, os desenvolvedores podem criar uma descrição de API abrangente e legível por máquina que facilita a geração de clientes, documentação automatizada e testes. Esta especificação promove consistência e clareza no design de API, melhora a interoperabilidade entre diferentes sistemas e permite que ferramentas gerem bibliotecas de clientes, stubs de servidor e documentação de API interativa.
