# família SHA

SHA (Secure Hash Algorithm) é uma família de funções hash criptográficas projetadas para gerar um valor hash de tamanho fixo a partir de dados de entrada de tamanho variável, garantindo a integridade e segurança dos dados. As funções SHA são usadas para tarefas como verificação de integridade de dados, armazenamento seguro de senhas e criação de assinaturas digitais. A família SHA inclui várias versões, como SHA-1, SHA-2 e SHA-3. O SHA-1 produz um valor de hash de 160 bits, mas agora é considerado fraco devido a vulnerabilidades, enquanto o SHA-2, com tamanhos de hash de 224, 256, 384 e 512 bits, oferece segurança mais forte. SHA-3 é o membro mais recente, oferecendo recursos adicionais de segurança e flexibilidade.
