# LXC

LXC é uma abreviatura usada para Linux Containers, que é um sistema operacional usado para executar vários sistemas Linux virtualmente em um host controlado por meio de um único kernel Linux. LXC é uma interface de espaço de usuário para recursos de contenção do kernel Linux. Por meio de uma API poderosa e ferramentas simples, ele permite que os usuários do Linux criem e gerenciem facilmente contêineres de sistemas ou aplicativos.
