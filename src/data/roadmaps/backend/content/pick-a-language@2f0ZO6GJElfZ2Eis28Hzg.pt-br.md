# Aprenda um idioma

Mesmo se você for iniciante, a primeira coisa que aprenderá é que o desenvolvimento web é dividido principalmente em dois aspectos: Desenvolvimento Frontend e Desenvolvimento Backend, cada um com suas ferramentas e tecnologias exclusivas. Para desenvolvimento front-end, as tecnologias fundamentais incluem HTML, CSS e JavaScript. Da mesma forma, o desenvolvimento de back-end gira em torno de linguagens de programação do lado do servidor, como Python, Java ou Node.js, complementadas por bancos de dados, estruturas e servidores web que permitem a funcionalidade do site.
