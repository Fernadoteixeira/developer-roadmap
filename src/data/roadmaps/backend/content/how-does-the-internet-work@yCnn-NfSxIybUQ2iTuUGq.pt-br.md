# internet

A Internet é uma rede global de computadores interconectados que se comunicam usando protocolos padronizados, principalmente TCP/IP. Quando você solicita uma página da web, seu dispositivo envia um pacote de dados através do seu provedor de serviços de Internet (ISP) para um servidor DNS, que traduz o nome de domínio do site em um endereço IP. O pacote é então roteado através de várias redes (usando roteadores e switches) até o servidor de destino, que processa a solicitação e envia de volta a resposta. Essa troca permite a transferência de dados como páginas da web, e-mails e arquivos, tornando a Internet um sistema dinâmico e descentralizado para comunicação global.
