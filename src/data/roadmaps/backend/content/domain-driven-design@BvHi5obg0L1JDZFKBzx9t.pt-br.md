# Design baseado em domínio

Domain-Driven Design (DDD) é uma abordagem de desenvolvimento de software que se concentra na criação de uma compreensão profunda do domínio de negócios e no uso desse conhecimento para informar o design de sistemas de software. Enfatiza a estreita colaboração entre especialistas técnicos e de domínio para desenvolver uma linguagem compartilhada (linguagem onipresente) e um modelo que represente com precisão os principais conceitos e processos do negócio. O DDD promove a organização do código em torno de conceitos de negócios (contextos limitados), usando modelos de domínio ricos para encapsular a lógica de negócios e separando a lógica do domínio das preocupações de infraestrutura. Os principais padrões em DDD incluem entidades, objetos de valor, agregados, repositórios e serviços de domínio. Esta abordagem visa criar sistemas de software mais fáceis de manter e flexíveis, que se alinhem estreitamente com as necessidades do negócio e possam evoluir com a mudança dos requisitos. O DDD é particularmente valioso para domínios complexos onde as arquiteturas tradicionais baseadas em CRUD podem falhar na captura das nuances e regras do negócio.
