# JavaScript

JavaScript é uma linguagem de programação versátil e de alto nível usada principalmente para adicionar interatividade e recursos dinâmicos a sites. Ele é executado no navegador, permitindo scripts do lado do cliente que podem manipular HTML e CSS, responder a eventos do usuário e interagir com APIs da web. JavaScript também é usado no lado do servidor em ambientes como Node.js, permitindo o desenvolvimento full-stack. Ele oferece suporte a estilos de programação orientados a eventos, funcionais e imperativos e possui um rico ecossistema de bibliotecas e estruturas (como React, Angular e Vue) que aprimoram seus recursos e agilizam o desenvolvimento.
