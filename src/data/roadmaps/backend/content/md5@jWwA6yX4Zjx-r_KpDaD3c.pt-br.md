# MD5

MD5 (Message-Digest Algorithm 5) é uma função hash criptográfica amplamente usada que produz um valor hash de 128 bits, normalmente representado como um número hexadecimal de 32 caracteres. Ele foi projetado para fornecer um identificador exclusivo para dados, gerando uma saída de tamanho fixo (o hash) para qualquer entrada. Embora o MD5 já tenha sido popular para verificar a integridade de dados e armazenar senhas, agora é considerado criptograficamente quebrado e inadequado para aplicativos sensíveis à segurança devido a vulnerabilidades que permitem ataques de colisão (onde duas entradas diferentes produzem o mesmo hash). Como resultado, o MD5 foi amplamente substituído por funções hash mais seguras, como SHA-256.
