# Padrões Arquitetônicos

Um padrão arquitetural é uma solução geral e reutilizável para um problema que ocorre comumente na arquitetura de software em um determinado contexto. Os padrões de arquitetura abordam vários problemas na engenharia de software, como limitações de desempenho de hardware de computador, alta disponibilidade e minimização de riscos de negócios.
