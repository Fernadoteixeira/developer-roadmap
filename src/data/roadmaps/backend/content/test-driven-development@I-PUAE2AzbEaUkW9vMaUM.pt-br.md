# Desenvolvimento orientado a testes

Desenvolvimento orientado a testes (TDD) é o processo de escrever testes para requisitos de software que falharão até que o software seja desenvolvido para atender a esses requisitos. Depois que esses testes forem aprovados, o ciclo se repetirá para refatorar o código ou desenvolver outro recurso/requisito. Em teoria, isso garante que o software seja escrito para atender aos requisitos da forma mais simples e evita defeitos de código.
