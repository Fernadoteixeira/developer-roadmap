# DynamoDB

O Amazon DynamoDB é um serviço de banco de dados NoSQL totalmente gerenciado e sem servidor, fornecido pela Amazon Web Services (AWS). Ele oferece armazenamento de dados de alto desempenho, escalável e flexível para aplicações de qualquer escala. O DynamoDB oferece suporte a modelos de dados de documento e de valor-chave, proporcionando desempenho rápido e previsível com escalabilidade perfeita. Possui escalonamento automático, segurança integrada, opções de backup e restauração e tabelas globais para implantação em várias regiões. O DynamoDB se destaca no gerenciamento de aplicativos da Web de alto tráfego, back-ends de jogos, aplicativos móveis e soluções de IoT. Ele oferece latência consistente de milissegundos de um dígito em qualquer escala e suporta modelos de leitura fortemente consistentes e eventualmente consistentes. Com sua integração ao ecossistema AWS, modo de capacidade sob demanda e suporte para transações, o DynamoDB é amplamente utilizado para criar aplicativos altamente responsivos e escaláveis, especialmente aqueles com cargas de trabalho imprevisíveis ou que exigem acesso a dados de baixa latência.
