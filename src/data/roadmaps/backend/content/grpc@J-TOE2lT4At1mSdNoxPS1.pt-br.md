# gRPC

gRPC é uma estrutura RPC universal de código aberto e de alto desempenho, RPC significa Remote Procedure Call, há um debate contínuo sobre o que g significa. RPC é um protocolo que permite a um programa executar um procedimento de outro programa localizado em outro computador. A grande vantagem é que o desenvolvedor não precisa codificar os detalhes da interação remota. O procedimento remoto é chamado como qualquer outra função. Mas o cliente e o servidor podem ser codificados em linguagens diferentes.
