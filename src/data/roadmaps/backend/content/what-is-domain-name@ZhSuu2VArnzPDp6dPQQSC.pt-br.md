# Nome de Domínio

Um nome de domínio é um endereço legível usado para identificar um local específico na Internet, facilitando o acesso a sites e serviços online. Ele se traduz em um endereço IP, que é um identificador numérico usado por computadores para localizar e conectar-se a servidores. Um nome de domínio consiste em duas partes principais: o **domínio de segundo nível** (por exemplo, "exemplo" em "exemplo.com") e o **domínio de nível superior** (por exemplo, ".com"). Os nomes de domínio são gerenciados por registradores de nomes de domínio e são essenciais para estabelecer uma presença na web, fornecendo uma maneira fácil de navegar em sites, em vez de usar endereços IP numéricos.
