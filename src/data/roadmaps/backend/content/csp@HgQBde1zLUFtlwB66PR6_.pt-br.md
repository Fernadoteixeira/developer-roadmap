# Política de segurança de conteúdo

A Política de Segurança de Conteúdo (CSP) é um padrão de segurança implementado por navegadores da web para evitar scripts entre sites (XSS), clickjacking e outros ataques de injeção de código. Ele funciona permitindo que os desenvolvedores da web especifiquem quais fontes de conteúdo são confiáveis ​​e podem ser carregadas em uma página da web. O CSP normalmente é implementado por meio de cabeçalhos HTTP ou metatags, definindo regras para vários tipos de recursos, como scripts, folhas de estilo, imagens e fontes. Ao restringir as origens das quais o conteúdo pode ser carregado, o CSP reduz significativamente o risco de execução de código malicioso. Ele também oferece recursos como relatar violações para ajudar os desenvolvedores a identificar e corrigir possíveis problemas de segurança. Embora poderosa, a implementação do CSP requer uma configuração cuidadosa para equilibrar segurança e funcionalidade, especialmente para sites que usam recursos de terceiros ou scripts embutidos.
