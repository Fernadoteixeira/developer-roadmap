# Teste Funcional

O teste funcional é onde o software é testado para garantir que os requisitos funcionais sejam atendidos. Normalmente, é uma forma de teste de caixa preta em que o testador não entende o código-fonte; o teste é realizado fornecendo informações e comparando a saída esperada/real. Contrasta com os testes não funcionais, que incluem testes de desempenho, carga, escalabilidade e testes de penetração.
