# Bancos de dados

Um banco de dados é uma coleção de dados úteis de uma ou mais organizações relacionadas, estruturada de forma a tornar os dados um ativo para a organização. Um sistema de gerenciamento de banco de dados é um software projetado para auxiliar na manutenção e extração de grandes coleções de dados em tempo hábil.
