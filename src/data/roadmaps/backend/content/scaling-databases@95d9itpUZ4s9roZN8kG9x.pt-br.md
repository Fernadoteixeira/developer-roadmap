# Dimensionando bancos de dados

Dimensionar bancos de dados é o processo de adaptá-los para lidar com mais dados e usuários com eficiência. Isso é conseguido atualizando o hardware existente (escalonamento vertical) ou adicionando mais servidores (escalonamento horizontal). Técnicas como fragmentação e replicação são fundamentais. Isso garante que os bancos de dados continuem a ser um ativo robusto à medida que crescem.
