# Prometeu

Prometheus é um aplicativo de software gratuito usado para monitoramento e alertas de eventos. Ele registra métricas em tempo real em um banco de dados de série temporal construído usando um modelo pull HTTP, com consultas flexíveis e alertas em tempo real.
