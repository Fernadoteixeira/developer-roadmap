# DNS

DNS (Domain Name System) é um sistema de nomenclatura hierárquico e descentralizado para computadores, serviços ou outros recursos conectados à Internet ou a uma rede privada. Ele traduz nomes de domínio legíveis por humanos (como www.example.com) em endereços IP (como 192.0.2.1) que os computadores usam para se identificarem na rede. O DNS funciona como a lista telefônica da Internet, permitindo que os usuários acessem sites usando nomes fáceis de lembrar em vez de endereços IP numéricos. O sistema compreende servidores DNS, resolvedores e registros (como A, CNAME, MX), trabalhando juntos para rotear o tráfego da Internet de forma eficiente. O DNS é crucial para a funcionalidade da Internet, afetando tudo, desde navegação na web e e-mail até balanceamento de carga e descoberta de serviços em arquiteturas de nuvem modernas.
