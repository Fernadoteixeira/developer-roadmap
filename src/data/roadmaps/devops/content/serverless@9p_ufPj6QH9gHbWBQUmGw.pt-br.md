# Sem servidor

Serverless é um modelo de execução de computação em nuvem onde o provedor de nuvem gerencia dinamicamente a infraestrutura, permitindo que os desenvolvedores se concentrem apenas na escrita do código. Neste modelo, os recursos são alocados e dimensionados automaticamente com base na demanda, e o faturamento é baseado no uso real, e não na capacidade pré-adquirida. As arquiteturas sem servidor são frequentemente usadas para cargas de trabalho e microsserviços orientados a eventos, melhorando a eficiência do desenvolvimento e reduzindo a sobrecarga operacional. Plataformas populares para computação sem servidor incluem AWS Lambda, Azure Functions e Google Cloud Functions.
