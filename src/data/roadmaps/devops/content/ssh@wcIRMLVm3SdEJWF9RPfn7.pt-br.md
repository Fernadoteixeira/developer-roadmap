# SSH

SSH (Secure Shell) é um protocolo de rede criptográfico usado para acessar e gerenciar com segurança máquinas remotas em uma rede não segura. Ele fornece comunicação criptografada, garantindo confidencialidade e integridade, e permite transferências seguras de arquivos, execução de comandos e tunelamento. O SSH é amplamente utilizado para administração remota de servidores, infraestrutura em nuvem e dispositivos de rede, normalmente empregando autenticação ou senhas baseadas em chaves. Ferramentas como OpenSSH são comumente usadas para estabelecer conexões SSH, fornecendo uma alternativa segura a protocolos mais antigos e menos seguros, como o Telnet.
