# Prometeu

Prometheus é um kit de ferramentas de alerta e monitoramento de sistemas de código aberto projetado para confiabilidade e escalabilidade. Ele apresenta um modelo de dados multidimensional, uma linguagem de consulta flexível (PromQL) e um banco de dados de série temporal eficiente. O Prometheus coleta métricas de alvos configurados em determinados intervalos, avalia expressões de regras, exibe resultados e pode acionar alertas quando condições especificadas são observadas. Ele opera em um modelo pull, coletando métricas de endpoints HTTP e oferece suporte à descoberta de serviços para ambientes dinâmicos. O Prometheus é particularmente adequado para monitorar microsserviços e ambientes em contêineres, integrando-se perfeitamente com sistemas como o Kubernetes. Seu ecossistema inclui vários exportadores para sistemas de terceiros e um gerenciador de alertas integrado. Amplamente adotado em arquiteturas nativas da nuvem, o Prometheus é um componente central das pilhas modernas de observabilidade, frequentemente usado junto com ferramentas como o Grafana para visualização.
