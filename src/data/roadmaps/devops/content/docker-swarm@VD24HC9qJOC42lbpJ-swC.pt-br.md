# Enxame Docker

Um Docker Swarm é um grupo de máquinas físicas ou virtuais que executam o aplicativo Docker e que foram configuradas para se unirem em um cluster. Depois que um grupo de máquinas tiver sido agrupado em cluster, você ainda poderá executar os comandos do Docker com os quais está acostumado, mas agora eles serão executados pelas máquinas em seu cluster. As atividades do cluster são controladas por um gerenciador de enxame e as máquinas que ingressaram no cluster são chamadas de nós.
