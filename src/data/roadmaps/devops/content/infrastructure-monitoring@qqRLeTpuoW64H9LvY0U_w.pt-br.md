# Monitoramento de Infraestrutura

A monitorização refere-se à prática de tornar visível o desempenho e o estado da infraestrutura. Esta seção contém ferramentas comuns usadas para monitoramento. Este é um espaço com muitos fornecedores – tenha cuidado ao estudar materiais exclusivamente de um determinado produto ou projeto, pois há muitas opiniões e estratégias conflitantes em uso. Não existe uma solução única para os aplicativos voltados para a Internet mais complexos, portanto, compreender os prós e os contras dessas ferramentas será útil para ajudá-lo a planejar como monitorar um sistema para um determinado objetivo.
