# Proxy reverso

Um proxy reverso é um servidor que fica entre dispositivos clientes e servidores backend, interceptando solicitações de clientes e encaminhando-as para servidores backend apropriados. Ele atua em nome dos servidores, proporcionando benefícios como balanceamento de carga, cache, terminação SSL e segurança. Os proxies reversos podem distribuir o tráfego de entrada em vários servidores para melhorar o desempenho e a confiabilidade, armazenar em cache o conteúdo solicitado com frequência para reduzir a carga do servidor, lidar com a criptografia e descriptografia SSL para descarregar essa tarefa dos servidores back-end e fornecer uma camada adicional de segurança, ocultando os detalhes do servidor. Os usos comuns incluem melhorar o desempenho de aplicativos web, habilitar arquiteturas de microsserviços e aumentar a segurança em ambientes de hospedagem web. O software popular de proxy reverso inclui NGINX, HAProxy e Apache com mod_proxy.
