# Vercel

A Vercel é um provedor de nuvem front-end que fornece a infraestrutura para construir, dimensionar e proteger uma web mais rápida e personalizada. Em outras palavras, é uma plataforma em nuvem projetada para simplificar o processo de implantação de aplicações web, principalmente aquelas construídas com frameworks modernos como React, Next, etc. onde vários projetos podem ser implantados conectando o repositório GitHub no Vercel, podemos implantar a ramificação GitHub selecionada para os domínios Vercel. Simultaneamente, fornece domínios personalizados para implantar código em servidores ativos. Esses servidores contêm `vercel.app` como sufixo no domínio.
