# Enviado

Originalmente criado na Lyft, o Envoy é um plano de dados de alto desempenho projetado para arquiteturas de malha de serviço. Lyft abriu o código-fonte e doou-o ao CNCF, onde agora é um dos projetos graduados de código aberto do CNCF. Envoy é um processo independente projetado para ser executado junto com todos os servidores de aplicativos. Todos os Envoys formam uma malha de comunicação transparente na qual cada aplicativo envia e recebe mensagens de e para o host local e não tem conhecimento da topologia da rede.
