# É isso

Istio é uma plataforma de malha de serviço de código aberto que fornece uma maneira de controlar como os microsserviços compartilham dados entre si. Inclui APIs que permitem a integração do Istio a qualquer plataforma de registro, telemetria ou sistema de política. O Istio foi projetado para ser executado em vários ambientes: no local, hospedado na nuvem, em contêineres Kubernetes, em serviços executados em máquinas virtuais e muito mais.
