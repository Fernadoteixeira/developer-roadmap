# OpenTelemetria

OpenTelemetry é uma estrutura de observabilidade de código aberto para software nativo da nuvem, que fornece uma maneira padronizada de coletar e exportar dados de telemetria, como métricas, logs e rastreamentos. Seu objetivo é tornar a observabilidade um recurso integrado de aplicativos nativos da nuvem, oferecendo um conjunto unificado e neutro de fornecedor de APIs, bibliotecas, agentes e instrumentação. OpenTelemetry simplifica a implementação da observabilidade em diferentes linguagens e plataformas, permitindo que os desenvolvedores instrumentem seu código uma vez e enviem dados para vários back-ends. Ele oferece suporte à instrumentação automática para muitas estruturas e bibliotecas populares, reduzindo o esforço necessário para adicionar observabilidade aos aplicativos. Ao fornecer uma abordagem consistente para coleta e exportação de dados, o OpenTelemetry facilita uma melhor interoperabilidade entre ferramentas e plataformas de observabilidade em ambientes de software distribuídos e modernos.
