# Gerenciamento de dados

O gerenciamento de dados é o elemento-chave dos aplicativos em nuvem e influencia a maioria dos atributos de qualidade. Os dados normalmente são hospedados em locais diferentes e em vários servidores por motivos como desempenho, escalabilidade ou disponibilidade, e isso pode apresentar uma série de desafios. Por exemplo, a consistência dos dados deve ser mantida e os dados normalmente precisarão ser sincronizados em diferentes locais. Além disso, os dados devem ser protegidos em repouso, em trânsito e através de mecanismos de acesso autorizados para manter garantias de segurança de confidencialidade, integridade e disponibilidade. Consulte o Controle de Proteção de Dados do Azure Security Benchmark para obter mais informações.
