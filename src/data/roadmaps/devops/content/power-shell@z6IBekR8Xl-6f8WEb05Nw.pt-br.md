# PowerShell

PowerShell é uma estrutura de automação de tarefas e gerenciamento de configuração da Microsoft, que consiste em um shell de linha de comando e uma linguagem de script associada. Construído na estrutura .NET, o PowerShell fornece acesso total a COM e WMI, permitindo que os administradores executem tarefas administrativas em sistemas Windows locais e remotos. Ele usa cmdlets (pronuncia-se "command-lets") para executar ações e um sistema de pipe para encadear esses comandos. A natureza baseada em objetos do PowerShell, em oposição à saída baseada em texto, permite uma manipulação de dados mais eficiente. Com seus amplos recursos de script, suporte para aliases e integração com vários produtos da Microsoft e de terceiros, o PowerShell se tornou uma ferramenta poderosa para automatizar tarefas de administração de sistemas, gerenciar recursos de nuvem e desenvolver práticas de DevOps em ambientes centrados no Windows.
