# FPS

Sender Policy Framework (SPF) é usado para autenticar o remetente de um e-mail. Com um registro SPF instalado, os provedores de serviços de Internet podem verificar se um servidor de e-mail está autorizado a enviar e-mails para um domínio específico. Um registro SPF é um registro DNS TXT que contém uma lista de endereços IP que têm permissão para enviar e-mails em nome do seu domínio.
