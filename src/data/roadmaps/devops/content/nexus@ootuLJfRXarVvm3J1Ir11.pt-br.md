# Nexo

O Nexus Repository Manager é um software gerenciador de repositório amplamente utilizado desenvolvido pela Sonatype. Ele foi projetado para gerenciar componentes binários, como bibliotecas Java, imagens Docker, pacotes npm, pacotes NuGet e muito mais. O Nexus Repository Manager permite que as organizações armazenem, gerenciem e distribuam componentes de software com segurança e eficiência.

- [@article@Práticas recomendadas do Nexus](https://help.sonatype.com/repomanager3/nexus-repository-best-practices)
