# SMTP

O e-mail está emergindo como um dos serviços mais valiosos da Internet atualmente. A maioria dos sistemas de Internet usa SMTP como método para transferir mensagens de um usuário para outro. SMTP é um protocolo push e é usado para enviar e-mails, enquanto POP (protocolo postal) ou IMAP (protocolo de acesso a mensagens da Internet) são usados ​​para recuperar esses e-mails no lado do destinatário. SMTP é um protocolo da camada de aplicação. O cliente que deseja enviar o email abre uma conexão TCP com o servidor SMTP e depois envia o email pela conexão. O servidor SMTP é um modo de escuta sempre ativo. Assim que escuta uma conexão TCP de qualquer cliente, o processo SMTP inicia uma conexão através da porta 25. Após estabelecer uma conexão TCP com sucesso, o processo cliente envia o email instantaneamente.
