# Serviços de hospedagem de repositório

Ao trabalhar em equipe, muitas vezes você precisa de um local remoto para colocar seu código para que outras pessoas possam acessá-lo, criar suas próprias ramificações e criar ou revisar solicitações pull. Esses serviços geralmente incluem rastreamento de problemas, revisão de código e recursos de integração contínua. Algumas escolhas populares são GitHub, GitLab, BitBucket e AWS CodeCommit.

Visite os seguintes recursos para saber mais:

- [@oficial@GitHub](https://github.com)
- [@oficial@GitLab](https://about.gitlab.com/)
- [@oficial@BitBucket](https://bitbucket.org/product/guides/getting-started/overview)
