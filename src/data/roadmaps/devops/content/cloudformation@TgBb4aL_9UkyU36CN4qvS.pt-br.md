# CloudFormação

AWS CloudFormation é um serviço de infraestrutura como código que permite aos usuários definir e provisionar recursos de infraestrutura da AWS usando modelos. Esses modelos, escritos em JSON ou YAML, descrevem os recursos desejados da AWS e suas propriedades. O CloudFormation automatiza a criação, atualização e exclusão de recursos, garantindo implantações consistentes e repetíveis em vários ambientes. Ele oferece suporte a uma ampla variedade de serviços AWS e pode gerenciar interdependências complexas entre recursos. O CloudFormation também fornece recursos como conjuntos de alterações para visualização de alterações, pilhas aninhadas para designs modulares e detecção de desvios para identificar alterações manuais. Este serviço permite que as equipes controlem a versão de sua infraestrutura, implementem práticas recomendadas e simplifiquem o gerenciamento de recursos da AWS durante todo o seu ciclo de vida.
