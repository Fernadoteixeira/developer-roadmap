# Análise Exploratória de Dados

A Análise Exploratória de Dados (EDA) é uma abordagem para analisar conjuntos de dados para resumir suas principais características, geralmente com métodos visuais. A EDA é usada para entender o que os dados podem nos dizer além da modelagem formal ou da tarefa de teste de hipóteses. É uma etapa crucial no processo de análise de dados.
