# Minificar JavaScript

> Todos os arquivos JavaScript são reduzidos, comentários, espaços em branco e novas linhas são removidos dos arquivos de produção (ainda válidos se usar HTTP/2).

Remover todos os espaços, comentários e quebras desnecessários reduzirá o tamanho dos seus arquivos JavaScript e acelerará o tempo de carregamento da página do seu site e, obviamente, facilitará o download para o seu usuário.

Use as ferramentas sugeridas abaixo para reduzir seus arquivos automaticamente antes ou durante a construção ou implantação.

- [terser - analisador JavaScript, mangler e kit de ferramentas de compressor para ES6+](https://github.com/terser/terser)
- [uglify-js - npm](https://www.npmjs.com/package/uglify-js)
- [Compressor JavaScript on-line](http://refresh-sf.com)
- [Leitura curta: Como o HTTP/2 é diferente? Ainda devemos reduzir e concatenar?](https://scaleyourcode.com/blog/article/28)
