# Otimização de imagens

> Suas imagens são otimizadas, compactadas sem impacto direto ao usuário final.

Imagens otimizadas carregam mais rápido no seu navegador e consomem menos dados.

- Tente usar efeitos CSS3 quando possível (em vez de uma imagem pequena
- Quando possível, use fontes em vez de texto codificado em suas imagens
- Usar SVG
- Use uma ferramenta e especifique um nível de compactação abaixo de 85.
