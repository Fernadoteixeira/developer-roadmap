# Minificar CSS

> Todos os arquivos CSS são reduzidos, comentários, espaços em branco e novas linhas são removidos dos arquivos de produção.

Quando os arquivos CSS são reduzidos, o conteúdo é carregado mais rapidamente e menos dados são enviados ao cliente. É importante sempre minimizar os arquivos CSS na produção. É benéfico para o usuário, assim como para qualquer empresa que deseja reduzir os custos de largura de banda e o uso de recursos.

Use ferramentas para reduzir seus arquivos automaticamente antes ou durante a construção ou implantação.

- [cssnano: Um minificador modular baseado no ecossistema PostCSS. -cssnano](https://cssnano.github.io/cssnano/)
- [Minificador CSS](https://goonlinetools.com/css-minifier/)
- [@neutrinojs/style-minify - npm](https://www.npmjs.com/package/@neutrinojs/style-minify)
- [Compressor CSS on-line](http://refresh-sf.com)
