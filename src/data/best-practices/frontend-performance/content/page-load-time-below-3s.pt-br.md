# Tempo de carregamento da página

> Reduza ao máximo o tempo de carregamento da página para entregar rapidamente seu conteúdo aos usuários.

Quanto mais rápido for o seu site ou aplicativo, menos você terá probabilidade de rejeição, ou seja, você terá menos chances de perder seu usuário ou futuro cliente. Pesquisas suficientes sobre o assunto comprovam esse ponto.

Use ferramentas online como [Page Speed ​​Insights](https://developers.google.com/speed/pagespeed/insights/) ou [WebPageTest](https://www.webpagetest.org/) para analisar o que pode estar deixando você lento e use a lista de verificação de desempenho de front-end para melhorar seus tempos de carregamento.

- [Compare a velocidade do seu site para celular](https://www.thinkwithgoogle.com/feature/mobile/)
- [Teste a velocidade e o desempenho do seu site para dispositivos móveis - Pense com o Google](https://testmysite.thinkwithgoogle.com/intl/en-us)
- [Tempo médio de carregamento de página para 2018 - Como se compara o seu? - Blog de velocidade MachMetrics](https://www.machmetrics.com/speed-blog/average-page-load-times-websites-2018/)
