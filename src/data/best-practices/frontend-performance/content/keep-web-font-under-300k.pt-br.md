# Mantenha o tamanho da fonte da Web abaixo de 300 KB

As fontes da Web são uma ótima maneira de adicionar estilo ao seu site. No entanto, eles também podem ser um grande gargalo de desempenho. Quanto mais fontes você usar, mais tempo levará para o navegador baixar e renderizar a página. Isso pode levar a uma experiência do usuário ruim e a uma alta taxa de rejeição.

Os tamanhos das fontes da Web não devem exceder 300 KB (todas as variantes incluídas) e são otimizados para desempenho.
