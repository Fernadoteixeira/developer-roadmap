# Minificar HTML

> O código HTML é reduzido, comentários, espaços em branco e novas linhas são removidos dos arquivos de produção.

A remoção de todos os espaços, comentários e atributos desnecessários reduzirá o tamanho do seu HTML e acelerará o tempo de carregamento da página do seu site e, obviamente, facilitará o download para o seu usuário.

A maioria dos frameworks possui plugins para facilitar a minificação das páginas web. Você pode usar vários módulos NPM que podem fazer o trabalho automaticamente.

- [Minificador HTML | Embelezamento de código](https://codebeautify.org/minify-html)
- [Compressor HTML on-line](http://refresh-sf.com)
- [Experimentando o minificador de HTML — Perfection Kills](http://perfectionkills.com/experimenting-with-html-minifier/#use_short_doctype)
