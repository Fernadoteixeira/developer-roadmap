# Complexidade da folha de estilo

> A análise de suas folhas de estilo pode ajudá-lo a sinalizar problemas, redundâncias e seletores CSS duplicados.

Às vezes você pode ter redundâncias ou erros de validação em seu CSS, analisar seus arquivos CSS e remover essas complexidades pode ajudá-lo a acelerar seus arquivos CSS (porque seu navegador irá lê-los mais rápido).

Seu CSS deve estar organizado; usar um pré-processador CSS pode ajudá-lo com isso. Algumas ferramentas online listadas abaixo também podem ajudá-lo a analisar e corrigir seu código.

- [TestMyCSS | Otimize e verifique o desempenho do CSS](http://www.testmycss.com/)
- [Estatísticas CSS](https://cssstats.com/)
- [macbre/analyze-css: analisador de complexidade e desempenho dos seletores CSS](https://github.com/macbre/analyze-css)
- [Projeto Wallace](https://www.projectwallace.com/) é como CSS Stats, mas armazena estatísticas ao longo do tempo para que você possa acompanhar suas alterações
