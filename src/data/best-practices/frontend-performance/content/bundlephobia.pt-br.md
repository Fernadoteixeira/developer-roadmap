# Bundlefobia

Bundlephobia é um site e pacote npm que permite aos desenvolvedores pesquisar o tamanho de qualquer pacote JavaScript antes de adicioná-lo ao seu projeto. Ele fornece informações sobre o tamanho do pacote, bem como o tamanho de suas dependências, para ajudar os desenvolvedores a tomarem decisões informadas sobre quais pacotes usar e como eles podem impactar o tamanho geral de sua aplicação. Bundlephobia também oferece emblemas que podem ser adicionados ao seu arquivo GitHub README.md para mostrar o tamanho do seu pacote.

- [Site Oficial - Bundlephobia](https://bundlephobia.com/)
