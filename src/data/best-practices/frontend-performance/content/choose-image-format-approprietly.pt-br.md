# Formato de imagem

> Escolha o formato da sua imagem adequadamente

Para garantir que suas imagens não deixem seu site lento, escolha o formato que corresponderá à sua imagem. Se for uma foto, JPEG é na maioria das vezes mais apropriado que PNG ou GIF. Porém, não se esqueça de observar os formatos mais modernos que podem reduzir o tamanho dos seus arquivos. Cada formato de imagem tem prós e contras, por isso é importante conhecê-los para fazer a melhor escolha possível.

Use [Lighthouse](https://developers.google.com/web/tools/lighthouse/) para identificar quais imagens podem eventualmente usar formatos modernos (como JPEG 2000m, JPEG XR ou WebP). Compare diferentes formatos, às vezes usar PNG8 é melhor que PNG16, às vezes não.
