# Concatenação CSS

> Arquivos CSS são concatenados em um único arquivo (nem sempre válido para HTTP/2)

Se você ainda estiver usando HTTP/1, talvez seja necessário concatenar seus arquivos, mas é menos verdadeiro se o seu servidor usar HTTP/2 (testes devem ser feitos).

- Use uma ferramenta online ou qualquer plug-in antes ou durante sua construção ou implantação para concatenar seus arquivos.
- Garanta, é claro, que a concatenação não interrompa seu projeto

- [HTTP: Otimizando a entrega de aplicativos - Rede de navegador de alto desempenho (O'Reilly)](https://hpbn.co/optimizing-application-delivery/#optimizing-for-http2)
- [Práticas recomendadas de desempenho na era HTTP/2](https://deliciousbrains.com/performance-best-practices-http2/)
