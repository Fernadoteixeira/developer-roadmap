# Carregamento lento

> As imagens fora da tela são carregadas lentamente (um substituto noscript é sempre fornecido).

Isso melhorará o tempo de resposta da página atual e evitará o carregamento de imagens desnecessárias que o usuário pode não precisar.

- Use o Lighthouse para identificar quantas imagens estão fora da tela.
- Use um plugin JavaScript como o seguinte para carregar lentamente suas imagens. Certifique-se de segmentar apenas imagens fora da tela.
- Certifique-se também de carregar lentamente imagens alternativas mostradas ao passar o mouse ou após outras ações do usuário.
