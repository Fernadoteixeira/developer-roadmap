# Desempenho JavaScript

> Verifique se há problemas de desempenho em seus arquivos JavaScript (e CSS também)

A complexidade do JavaScript pode diminuir o desempenho do tempo de execução. Identificar esses possíveis problemas é essencial para oferecer a experiência mais tranquila ao usuário.

Use a ferramenta Timeline na Chrome Developer Tool para avaliar eventos de scripts e encontrar aquele que pode levar muito tempo.
