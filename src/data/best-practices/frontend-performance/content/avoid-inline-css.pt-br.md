# Evite CSS embutido

> Evite usar CSS incorporado ou inline dentro do seu `<body>` (não válido para HTTP/2)

Uma das primeiras razões é porque é uma boa prática separar o conteúdo do design. Também ajuda você a ter um código mais sustentável e a manter seu site acessível. Mas em relação ao desempenho, é simplesmente porque diminui o tamanho do arquivo das suas páginas HTML e o tempo de carregamento.

Sempre use folhas de estilo externas ou incorpore CSS em seu `<head>` (e siga as outras regras de desempenho de CSS)

- [Observe as práticas recomendadas de CSS: evite estilos CSS embutidos](https://www.lifewire.com/avoid-inline-styles-for-css-3466846)
