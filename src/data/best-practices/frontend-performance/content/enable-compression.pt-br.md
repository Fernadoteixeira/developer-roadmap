# Habilitar compactação

Use um método de compactação como Gzip ou Brotli para reduzir o tamanho dos seus arquivos JavaScript. Com tamanhos de arquivo menores, os usuários poderão baixar o ativo com mais rapidez, resultando em melhor desempenho.

- [Verifique a compactação GZIP](https://checkgzipcompression.net/)
- [Verifique a compressão do Brotli](https://tools.keycdn.com/brotli-test)
- [Posso usar... Brotli](https://caniuse.com/#feat=brotli)
