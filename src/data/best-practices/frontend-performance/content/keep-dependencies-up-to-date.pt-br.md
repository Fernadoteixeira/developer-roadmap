# Atualizações de dependência

> Todas as bibliotecas JavaScript usadas em seu projeto são necessárias (prefira Vanilla JavaScript para funcionalidades simples), atualizadas para sua versão mais recente e não sobrecarregue seu JavaScript com métodos desnecessários.

Na maioria das vezes, novas versões vêm com otimização e correção de segurança. Você deve usar o código mais otimizado para acelerar seu projeto e garantir que não deixará seu site ou aplicativo lento sem um plugin desatualizado.

Se seu projeto utiliza pacotes NPM, [npm-check](https://www.npmjs.com/package/npm-check) é uma biblioteca bastante interessante para atualizar/atualizar suas bibliotecas. [Greenkeeper](https://greenkeeper.io/) pode procurar automaticamente suas dependências e sugerir uma atualização sempre que uma nova versão for lançada.
