# Pré-carregar URLs

> Navegadores populares podem usar a diretiva na tag `<link>` e no atributo `"rel"` com determinadas palavras-chave para pré-carregar URLs específicos

A pré-busca permite que um navegador busque silenciosamente os recursos necessários para exibir o conteúdo que um usuário poderá acessar em um futuro próximo. O navegador é capaz de armazenar esses recursos em seu cache e acelerar o carregamento das páginas da web quando usam domínios diferentes para recursos da página. Quando uma página da web termina de carregar e o tempo ocioso passa, o navegador começa a baixar outros recursos. Quando um usuário acessa um determinado link (já pré-buscado), o conteúdo será veiculado instantaneamente.
