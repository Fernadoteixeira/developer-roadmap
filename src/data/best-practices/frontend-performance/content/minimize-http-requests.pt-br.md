# Minimize solicitações HTTP

> Certifique-se sempre de que todos os arquivos solicitados são essenciais para o seu site ou aplicativo.
> Combine arquivos, habilite o cache, use uma rede de distribuição de conteúdo e elimine recursos desnecessários
