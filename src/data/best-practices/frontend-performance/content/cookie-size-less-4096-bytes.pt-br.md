# Tamanho do biscoito

> Se você estiver usando cookies, certifique-se de que cada cookie não exceda 4.096 bytes e que seu nome de domínio não tenha mais de 20 cookies.

Os cookies são trocados nos cabeçalhos HTTP entre servidores web e navegadores. É importante manter o tamanho dos cookies o mais baixo possível para minimizar o impacto no tempo de resposta do utilizador.
