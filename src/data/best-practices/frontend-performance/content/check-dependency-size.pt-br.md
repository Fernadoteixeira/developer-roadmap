# Verifique o tamanho da dependência

> Certifique-se de usar bibliotecas externas com sabedoria, na maioria das vezes, você pode usar uma biblioteca mais leve para a mesma funcionalidade.

Você pode ficar tentado a usar um dos 745.000 pacotes que pode encontrar no npm, mas precisa escolher o melhor pacote para suas necessidades. Por exemplo, MomentJS é uma biblioteca incrível, mas com muitos métodos que você talvez nunca use, é por isso que Day.js foi criado. São apenas 2kB contra 16,4kB gz do Moment.

Sempre compare e escolha a biblioteca melhor e mais leve para suas necessidades. Você também pode usar ferramentas como [tendências npm](http://www.npmtrends.com/) para comparar contagens de downloads de pacotes NPM ou [Bundlephobia](https://bundlephobia.com/) para saber o tamanho de suas dependências.

- [webpack-bundle-analisador - npm](https://www.npmjs.com/package/webpack-bundle-analyzer)
- [visualizador de dependência js - npm](https://www.npmjs.com/package/js-dependency-viewer)
- [Limite de tamanho: torne a Web mais leve](https://evilmartians.com/chronicles/size-limit-make-the-web-lighter)
