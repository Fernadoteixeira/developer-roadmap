# Use a fonte da Web WOFF 2.0

De acordo com o Google, o formato de compressão WOFF 2.0 Web Font oferece ganho médio de 30% em relação ao WOFF 1.0. Então é bom usar WOFF 2.0, WOFF 1.0 como substituto e TTF.

Antes de comprar sua nova fonte, verifique se o fornecedor oferece o formato WOFF2. Se estiver usando uma fonte gratuita, você sempre pode usar Font Squirrel para gerar todos os formatos necessários.

- [WOFF 2.0 – Saiba mais sobre o formato de fonte da Web de próxima geração e converta TTF em WOFF2](https://gist.github.com/sergejmueller/cf6b4f2133bcb3e2f64a)
- [Crie seus próprios kits @font-face » Font Squirrel](https://www.fontsquirrel.com/tools/webfont-generator)
- [Aplicativo IcoMoon - Gerador de fonte de ícone, SVG, PDF e PNG](https://icomoon.io/app/)
- [Usando @font-face | Truques CSS](https://css-tricks.com/snippets/css/using-font-face/?ref=frontendchecklist)
- [Posso usar... WOFF2](https://caniuse.com/#feat=woff2)
