# Chrome DevTools

Chrome DevTools é um conjunto de ferramentas de desenvolvimento web integradas ao navegador Google Chrome. Ele permite que os desenvolvedores inspecionem e depurem o front-end de aplicativos da web.

Alguns dos benefícios de usar o Chrome DevTools incluem:

- Inspecionar e editar HTML e CSS em tempo real, o que pode ser útil para identificar e corrigir problemas de layout
- Depurar código JavaScript, incluindo definir pontos de interrupção, percorrer o código e examinar a pilha de chamadas
- Criação de perfil de desempenho de páginas da web, incluindo identificação de código JavaScript de execução lenta e análise de solicitações de rede
- Inspecionar e depurar armazenamento do lado do navegador, incluindo cookies, armazenamento local e indexedDB
- Auditoria de páginas da web quanto a desempenho, acessibilidade e melhores práticas

Chrome DevTools é uma ferramenta poderosa e essencial para desenvolvedores web, pois ajuda a melhorar a depuração, teste e otimização do aplicativo web.

- [Documentos do Chrome DevTools](https://developer.chrome.com/docs/devtools/)
