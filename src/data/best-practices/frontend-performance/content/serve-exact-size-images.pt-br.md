# Imagens responsivas

> Certifique-se de veicular imagens próximas ao tamanho de sua exibição.

Dispositivos pequenos não precisam de imagens maiores que sua janela de visualização. É recomendado ter múltiplas versões de uma imagem em tamanhos diferentes.

- Crie diferentes tamanhos de imagem para os dispositivos que você deseja atingir
- Use `srcset` e `picture` para fornecer múltiplas variantes de cada imagem.

- [Imagens responsivas - Aprenda desenvolvimento web | MDN](https://developer.mozilla.org/en-US/docs/Learn/HTML/Multimedia_and_embedding/Responsive_images)
