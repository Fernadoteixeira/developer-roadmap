# Use HTTP

HTTPS não é apenas para sites de comércio eletrônico, mas para todos os sites que trocam dados. Dados partilhados por um utilizador ou dados partilhados com uma entidade externa. Os navegadores modernos hoje limitam funcionalidades para sites que não são seguros. Por exemplo: geolocalização, notificações push e service workers não funcionam se sua instância não estiver usando HTTPS. E hoje é muito mais fácil configurar um projeto com certificado SSL do que era antes (e de graça, graças ao Let's Encrypt).
