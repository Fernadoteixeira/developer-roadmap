# Remover CSS não utilizado

A remoção de seletores CSS não utilizados pode reduzir o tamanho dos seus arquivos e acelerar o carregamento dos seus ativos.

Sempre verifique se o CSS do framework que você deseja usar ainda não possui um código de redefinição/normalização incluído. Às vezes, você pode não precisar de tudo o que está dentro do arquivo de redefinição/normalização.

- [UnCSS Online](https://uncss-online.com/)
- [PurifyCSS](https://github.com/purifycss/purifycss)
- [PurgeCSS](https://github.com/FullHuman/purgecss)
- [Cobertura do Chrome DevTools](https://developers.google.com/web/updates/2017/04/devtools-release-notes#coverage)
