# Prepare uma lista

Em um processo de revisão de código, é essencial garantir que todos os requisitos ou histórias de usuários para um recurso específico ou correção de bug foram abordados adequadamente nas alterações de código enviadas para revisão. Para conseguir isso, preparar uma lista de verificação de itens ou requisitos a serem abordados nas mudanças pode ajudar a agilizar o processo de revisão e garantir que nada seja esquecido. Isso não apenas melhora a qualidade geral do código, mas também economiza tempo e esforço em possíveis retrabalhos. Nesta seção, daremos algumas dicas sobre como criar uma lista de itens que deveriam ter sido abordados nas alterações e garantir que o código esteja em conformidade com elas.

- Familiarize-se com os requisitos: Analise minuciosamente a documentação de requisitos do projeto ou histórias de usuários e identifique os principais componentes que precisam ser abordados nas alterações de código.

- Crie uma lista de verificação: Com base nos requisitos, crie uma lista de verificação abrangente de itens que devem ser abordados nas alterações do código. Divida os requisitos complexos em tarefas menores para garantir que todos os aspectos sejam abordados.

- Avalie as alterações no código: Ao revisar o código, verifique com sua lista de verificação para garantir que cada item foi levado em consideração. Se algo estiver faltando ou não estiver de acordo, forneça feedback específico nos comentários da revisão.

- Avalie a cobertura dos testes: certifique-se de que as alterações no código sejam suportadas por testes unitários ou de integração apropriados, que cubram os principais requisitos da lista de verificação. Testes de alta qualidade são cruciais para evitar regressões futuras e garantir que o código cumpra a finalidade pretendida.

- Garanta uma comunicação clara: compartilhe sua lista de verificação de requisitos com o desenvolvedor no início do processo de revisão de código. Isso os ajudará a compreender suas expectativas e fornecerá uma base sólida para uma revisão tranquila e construtiva.

Ao criar e utilizar uma lista de verificação de requisitos, os revisores de código podem garantir de forma mais eficaz que as alterações de código enviadas atendam aos requisitos do projeto e, em última análise, resultem em software de maior qualidade.
