# Atualizar documentação

No processo de melhoria e modificação do código, é crucial manter a documentação atualizada para garantir que outros desenvolvedores e usuários possam compreender e utilizar o software de forma eficiente. “Atualizar qualquer documentação que possa ter se tornado obsoleta devido às alterações” significa que sempre que houver uma alteração no código, a documentação relacionada também deverá ser revisada adequadamente. Esta prática ajuda a manter a coerência entre o código e a sua documentação e evita confusões que podem surgir de informações contraditórias ou desatualizadas. Para garantir que você esteja atualizando consistentemente a documentação, aqui estão algumas dicas:

- Crie o hábito de revisitar a documentação logo após qualquer alteração no código.
- Durante o processo de revisão de código, inclua verificações de documentação como etapa padrão.
- Sempre verifique as áreas afetadas na documentação para garantir que estejam alinhadas com as alterações do código.
- Use comentários inline e mensagens de commit claras para destacar quaisquer modificações feitas no código, o que facilitará a atualização da documentação.
- Colaborar com os membros da equipe para verificar o código e a documentação para garantir consistência e precisão.
