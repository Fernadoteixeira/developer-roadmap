# Sobre solicitações pull

Fornecer um título, uma descrição, capturas de tela, links relevantes e alterações de configuração adequados ajuda os revisores a compreender rapidamente o propósito, a funcionalidade e qualquer outro contexto importante associado às alterações introduzidas pelo PR. Para garantir a qualidade e eficácia da sua documentação de RP, siga estas dicas úteis:

- **Título**: Escolha um título claro e conciso, resumindo o objetivo principal ou funcionalidade adicionada pelas alterações.

- **Descrição**: Escreva uma descrição completa do que suas alterações fazem, como funcionam e quaisquer possíveis efeitos colaterais ou limitações. Certifique-se de incluir informações sobre o problema que você está resolvendo ou o recurso que está implementando.

- **Capturas de tela**: se suas alterações envolverem elementos visuais ou afetarem a interface do usuário, inclua capturas de tela para dar aos revisores uma melhor compreensão do impacto visual.

- **Links relevantes**: forneça links relevantes, como rastreadores de problemas, solicitações de recursos ou documentos de design, para ajudar os revisores a compreender o contexto do seu trabalho.

- **Alterações de configuração**: mencione quaisquer alterações nas definições de configuração ou introduza quaisquer novas configurações necessárias para executar ou testar seu código. Explique como essas configurações devem ser usadas e quais devem ser seus valores padrão.

Seguindo essas dicas, você pode agilizar o processo de revisão de código, tornando mais fácil para seus colegas entenderem e avaliarem seu trabalho, ao mesmo tempo que minimiza possíveis confusões ou falhas de comunicação.
