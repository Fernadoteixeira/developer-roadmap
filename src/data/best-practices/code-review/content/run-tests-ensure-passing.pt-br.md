# Verifique se todos os testes foram aprovados

Executar os testes e garantir que todos sejam aprovados após fazer alterações é um aspecto crucial das melhores práticas de “revisão de código”. Esta etapa ajuda a manter a qualidade do código, garantindo que quaisquer modificações no código não levem a erros ou problemas inesperados. À medida que a base de código fica maior e mais complexa, torna-se cada vez mais imperativo verificar se todos os testes estão sendo aprovados após qualquer atualização.

Para garantir que todos os testes sejam aprovados após fazer alterações, siga estas dicas:

- Sempre execute o conjunto de testes completo para todo o projeto após fazer modificações no código. Isso garantirá que suas alterações não introduzam efeitos colaterais ou bugs indesejados.
- Mantenha os testes atualizados e relevantes adicionando continuamente novos testes, modificando os existentes e removendo os obsoletos. Isso garante que o conjunto de testes cubra todos os aspectos da funcionalidade do projeto.
- Use uma ferramenta de Integração Contínua (CI) que executa automaticamente os testes sempre que um novo commit é enviado para o repositório. Isso ajuda a identificar quaisquer problemas no início do processo de desenvolvimento e economiza tempo durante a revisão do código.
- Preste atenção a quaisquer falhas de teste e resolva a causa raiz antes de enviar o código para revisão. É tão importante compreender o motivo de uma falha no teste quanto corrigir o problema.
- Incentive toda a equipe de desenvolvimento a seguir essas práticas e responsabilizar-se mutuamente. Isso promove uma cultura de desenvolvimento orientado a testes e ajuda a manter um código de alta qualidade.
