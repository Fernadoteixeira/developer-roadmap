# Observe as perguntas para revisão

Tomar notas sobre quaisquer dúvidas ou preocupações sobre a mudança durante uma revisão de código é essencial para aumentar a eficiência e permitir uma melhor comunicação entre os membros da equipe. Esta prática permite que você esteja preparado com uma lista clara de pontos a serem discutidos durante a reunião de revisão. Nesta seção do guia, descreveremos várias dicas para ajudá-lo a aproveitar ao máximo essas práticas recomendadas em seu processo de revisão de código, como reservar um tempo para fazer anotações, organizar suas anotações de maneira clara e lógica e usar exemplos específicos para ilustrar suas preocupações. Seguindo essas dicas, você aumentará a eficácia de suas revisões de código e promoverá uma melhor colaboração dentro de sua equipe.
