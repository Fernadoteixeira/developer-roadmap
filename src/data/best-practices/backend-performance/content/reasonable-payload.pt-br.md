# Impondo limites razoáveis ​​de tamanho de carga útil

O desempenho de back-end em aplicativos da web depende muito da rapidez com que os servidores são capazes de processar, armazenar e recuperar dados. Quando grandes cargas de dados são transferidas, isso impõe uma grande pressão aos recursos da rede e ao próprio servidor; resultando potencialmente em tempos de resposta lentos e baixo desempenho do aplicativo. Portanto, impor limites razoáveis ​​de tamanho de carga útil é vital para manter o desempenho ideal. Por exemplo, um aplicativo Web que lida com arquivos de imagem grandes pode implementar limites para garantir que os usuários não carreguem imagens além de um determinado tamanho. Isso não apenas ajuda a manter os custos de servidor e largura de banda gerenciáveis, mas também garante que o aplicativo funcione sem problemas para todos os usuários.
