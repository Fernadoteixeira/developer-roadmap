# Utilizando mecanismos de cache

O desempenho de back-end de aplicativos da web pode apresentar melhorias substanciais quando mecanismos de cache eficazes, como HTTP, servidor/cliente e CDN, são implementados adequadamente. O cache pode diminuir significativamente a carga no servidor, minimizando o esforço necessário para gerar uma resposta à solicitação de um usuário. Por exemplo, quando um usuário revisita uma página web acessada anteriormente, os mecanismos de cache recuperam as informações armazenadas mais rapidamente do que o servidor poderia gerá-las. Este processo reduz efetivamente a latência, o uso de largura de banda e o poder de processamento, acelerando os tempos de carregamento e contribuindo para uma experiência de usuário mais tranquila. Os caches baseados em CDN também ajudam a fornecer recursos estáticos aos usuários no local mais próximo possível, reduzindo a latência da rede.
