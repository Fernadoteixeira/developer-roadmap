# Utilizando Message Brokers para comunicação assíncrona entre serviços

A melhoria do desempenho de back-end depende fortemente da comunicação eficaz entre diversos serviços. Os message brokers, neste contexto, revelam-se um instrumento essencial, pois facilitam a comunicação assíncrona, método que potencia o desempenho global do sistema ao permitir a ocorrência simultânea de múltiplas operações. Por exemplo, numa aplicação web que processa pagamentos online, um corretor de mensagens pode permitir que o recebimento de pagamentos (um serviço) ocorra simultaneamente com a atualização do histórico de pagamentos do usuário (outro serviço). Isso evita atrasos e interrupções, o que significa que os usuários finais recebem experiências mais rápidas e tranquilas. Um desempenho de back-end aprimorado, caracterizado pela eficiência e economia de tempo, torna isso possível.
