# Utilização de HTTP Keep-Alive para reduzir sobrecarga de conexão

Melhorias significativas no desempenho de back-end para aplicativos da web podem ser alcançadas por meio da utilização de HTTP keep-alive. Este protocolo permite que várias solicitações HTTP sejam enviadas pela mesma conexão TCP. Normalmente, cada nova solicitação de um cliente para um servidor exigiria uma nova conexão TCP, e esse processo pode consumir muitos recursos e ser lento, pois envolve um handshake de três vias. Com o keep-alive HTTP, essas despesas gerais são bastante reduzidas, pois uma conexão pode ser reutilizada para diversas solicitações. Por exemplo, em um aplicativo da web onde os usuários interagem e solicitam dados constantemente, o uso desse método pode acelerar bastante o tempo de carregamento e a resposta, criando uma experiência de usuário mais tranquila.
