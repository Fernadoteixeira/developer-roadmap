# Utilizando linguagens compiladas como Go ou Rust

O desempenho de back-end de aplicativos da web pode ser substancialmente aumentado com a incorporação de linguagens compiladas como Go ou Rust. A essência disso reside na maneira como essas linguagens lidam com a conversão de código em linguagem de máquina. Ao contrário das linguagens interpretadas, que convertem o código em linguagem de máquina durante o tempo de execução, as linguagens compiladas realizam esta etapa antecipadamente. Essa maior eficiência na tradução resulta em um desempenho mais rápido do código, especialmente valioso para segmentos críticos de desempenho do seu back-end. Por exemplo, o Google usa a linguagem Go em vários de seus sistemas de produção justamente pelo motivo de maior desempenho e escalabilidade. Da mesma forma, Rust ganhou reconhecimento na construção de sistemas altamente simultâneos e rápidos. Assim, o uso de tais linguagens compiladas pode aumentar bastante o desempenho geral do back-end.
