# Otimizando o desempenho de back-end por meio de pré-busca ou pré-carregamento de recursos

A otimização do desempenho de back-end em aplicativos da web envolve a busca ou carregamento proativo de recursos, dados ou dependências necessárias para solicitações futuras. Ao realizar estas operações antecipadamente, os atrasos dispendiosos (latência) são reduzidos significativamente. Esse processo garante que os recursos estejam disponíveis assim que necessários, resultando em uma interação contínua e mais rápida para os usuários. Por exemplo, quando um usuário abre um site, se as imagens ou outros dados que provavelmente serão usados ​​em seguida já estiverem pré-carregados, o usuário não sofrerá nenhum atraso durante o carregamento desses elementos. Como tal, a pré-busca ou pré-carregamento é fundamental para melhorar a velocidade geral de uma aplicação web, melhorando diretamente a experiência do usuário.
