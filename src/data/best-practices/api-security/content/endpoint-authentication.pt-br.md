# Autenticação de terminal

> Verifique se todos os endpoints protegidos estão protegidos por autenticação
> para evitar processo de autenticação quebrado

Ao identificar e corrigir fluxos de trabalho de autenticação quebrados, a API pode evitar ataques como ataques de força bruta, preenchimento de credenciais, sequestro de sessão e outros ataques relacionados à autenticação. Isso pode ajudar a garantir que o sistema esteja seguro e que os dados confidenciais estejam protegidos.
