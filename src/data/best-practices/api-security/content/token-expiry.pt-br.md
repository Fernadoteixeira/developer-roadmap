# Expiração do token

> A expiração do token deve ser definida em um prazo razoável para reduzir a janela de vulnerabilidade, limitar o impacto do roubo de token e melhorar a segurança geral.

Definir um tempo curto de expiração de token (TTL, RTTL) é importante para fins de segurança, pois reduz a janela de vulnerabilidade, limita o impacto do roubo de token e melhora a segurança geral. No entanto, o prazo de validade deve ser equilibrado com a usabilidade, pois defini-lo muito curto pode incomodar os usuários e reduzir a produtividade.
