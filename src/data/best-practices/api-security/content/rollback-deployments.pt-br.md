# Solução de reversão

> Projete uma solução de reversão para implantações.

Às vezes, a implantação de uma nova versão da API pode apresentar bugs ou problemas inesperados que não foram detectados durante o teste. Nesses casos, reverter para a versão anterior da API pode ajudar a mitigar o impacto do problema e restaurar o serviço a um estado funcional. Uma solução de reversão bem projetada pode ajudar a reduzir o tempo de inatividade e minimizar o impacto sobre os usuários.
