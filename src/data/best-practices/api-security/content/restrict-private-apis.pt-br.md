# Restringir APIs privadas

> APIs privadas só devem ser acessíveis a partir de IPs listados como seguros

As APIs privadas só devem ser acessíveis a partir de IPs listados como seguros para garantir que apenas usuários ou sistemas autorizados possam acessar a API. Ao restringir o acesso a endereços IP específicos, você pode impedir o acesso não autorizado de redes externas ou de agentes mal-intencionados. Isso pode ajudar a proteger dados confidenciais e prevenir ataques como DDoS ou ataques de força bruta. Além disso, restringir o acesso a IPs listados como seguros pode ajudar a garantir a confiabilidade e o desempenho da API, evitando tráfego excessivo de fontes não autorizadas.
