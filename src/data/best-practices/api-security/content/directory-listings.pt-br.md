# Listagens de diretório

> Desativar listagens de diretório

As listagens de diretórios são um recurso dos servidores web que permitem aos usuários visualizar o conteúdo de um diretório em um servidor. Por padrão, os servidores web geralmente têm listagens de diretórios habilitadas, o que significa que qualquer pessoa que tenha acesso ao servidor pode ver todos os arquivos e diretórios em uma determinada pasta.

Desativar as listagens de diretórios é importante para a segurança da API porque evita que invasores obtenham acesso a arquivos e diretórios confidenciais no servidor. Se as listagens de diretórios estiverem habilitadas e um invasor obtiver acesso ao servidor, ele poderá visualizar e baixar facilmente quaisquer arquivos que não estejam devidamente protegidos. Ao desabilitar as listagens de diretórios, você pode garantir que apenas usuários autorizados possam acessar os arquivos e diretórios no servidor.
