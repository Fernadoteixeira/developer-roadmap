# Evite retornar dados confidenciais

> Retorne apenas os dados necessários para o funcionamento do cliente.

Retornar apenas os dados necessários para o funcionamento do cliente é uma prática recomendada importante para a segurança da API. Isso ocorre porque limitar a quantidade de dados retornados reduz a quantidade de informações confidenciais expostas. Ao retornar apenas os dados necessários, você pode ajudar a evitar vulnerabilidades de segurança, como vazamento de dados, ataques de injeção e outros tipos de ataques que dependem da exposição de muitas informações. Além disso, reduzir a quantidade de dados retornados pode melhorar o desempenho da sua API, reduzindo a quantidade de dados que precisam ser processados ​​e transmitidos.
