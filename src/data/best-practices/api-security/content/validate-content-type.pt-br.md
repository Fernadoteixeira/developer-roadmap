# Validação de tipo de conteúdo

> Valide `content-type` nos cabeçalhos de solicitação para evitar ataques XSS

A validação do cabeçalho `Content-Type` na solicitação pode ajudar a tornar as APIs mais seguras, garantindo que os dados da solicitação estejam no formato esperado e reduzindo o risco de ataques, como ataques de injeção ou scripts entre sites (XSS).
