# Validar a entrada do usuário

> Valide a entrada do usuário para evitar vulnerabilidades comuns

A entrada do usuário é uma fonte comum de vulnerabilidades em aplicativos da web. Isso ocorre porque a entrada do usuário geralmente não é validada, higienizada ou escapada adequadamente antes de ser usada em um aplicativo da web. Isso pode permitir que um invasor manipule a entrada e execute código malicioso ou faça com que o aplicativo se comporte de forma inesperada.
