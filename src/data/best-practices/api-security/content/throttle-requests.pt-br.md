# Solicitações de aceleração

> Limitar solicitações (estrangulamento) para evitar ataques DDoS/Força Bruta.

Limitar solicitações por meio de limitação é importante para evitar ataques DDoS e ataques de força bruta. Os ataques DDoS sobrecarregam o servidor com muitas solicitações, enquanto os ataques de força bruta tentam adivinhar as credenciais do usuário por meio de múltiplas tentativas de login.

A limitação limita o número de solicitações que podem ser enviadas dentro de um determinado período de tempo, tornando mais difícil para os invasores realizarem esses tipos de ataques. Isso pode proteger o sistema contra sobrecarga e impedir que invasores obtenham acesso não autorizado.
