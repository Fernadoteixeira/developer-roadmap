# Desligue o modo de depuração

> Certifique-se de desligar o modo de depuração na produção

O modo de depuração é um recurso usado para ajudar os desenvolvedores a depurar seu código. Não se destina a ser usado na produção. Ele pode expor informações confidenciais sobre o aplicativo e o servidor em que está sendo executado. Certifique-se de desligar o modo de depuração na produção.
