# Evite registrar dados confidenciais

> Certifique-se de não registrar nenhum dado confidencial.

Certifique-se de não registrar dados confidenciais, como senhas, números de cartão de crédito ou informações pessoais. Isso ocorre porque o registro de dados confidenciais pode expô-los a invasores, permitindo-lhes obter acesso não autorizado ao seu sistema ou aos seus dados. Além disso, registrar dados confidenciais pode violar leis e regulamentos de privacidade de dados, expondo você a responsabilidades legais.
