# Processo de revisão de código

> Use um processo de revisão de código e desconsidere a autoaprovação.

Ter um bom processo de revisão de código permite que pares adicionais de olhos revisem o código e identifiquem possíveis problemas ou vulnerabilidades de segurança. Um processo de revisão de código envolve a revisão do código por outros membros da equipe para garantir que ele siga as práticas recomendadas e seja seguro. Desconsiderar a autoaprovação significa que o desenvolvedor que escreveu o código não deve ser o único responsável por aprová-lo para lançamento. Isso ajuda a detectar possíveis erros ou omissões antes da implantação do código, reduzindo o risco de violações de segurança ou outros problemas.
