# Convenção de Nomenclatura

> Decida antecipadamente uma convenção de nomenclatura e cumpra-a.

Existem muitos recursos na AWS onde você pode alterar o nome posteriormente, mas também há muitos onde você não pode (nomes de grupos de segurança, etc.). Ter uma convenção de nomenclatura consistente ajudará a autodocumentar sua infraestrutura. Não se esqueça de usar tags também.
