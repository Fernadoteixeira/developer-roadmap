# Proteção contra rescisão

> Use proteção contra encerramento para instâncias sem escalonamento automático.

Se você tiver alguma instância única que não esteja em escalonamento automático, provavelmente deverá ativar a proteção contra encerramento, para impedir que alguém exclua acidentalmente a instância. Já aconteceu, é uma merda, aprenda com meu erro!
