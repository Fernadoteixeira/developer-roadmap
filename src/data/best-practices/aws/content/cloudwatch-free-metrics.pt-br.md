# Métricas Gratuitas

> Use as métricas gratuitas.

O CloudWatch monitora todos os tipos de coisas gratuitamente (largura de banda, uso de CPU, etc.) e você obtém até 2 semanas de dados históricos. Isso evita que você tenha que usar suas próprias ferramentas para monitorar seus sistemas. Se precisar de mais de duas semanas, infelizmente você precisará usar uma solução de monitoramento de terceiros ou personalizada.
