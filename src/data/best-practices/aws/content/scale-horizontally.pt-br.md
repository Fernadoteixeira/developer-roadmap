# Dimensionar horizontalmente

Descobri que usar muitas máquinas menores geralmente é mais confiável do que usar um número menor de máquinas maiores. Você precisa equilibrar isso, pois tentar executar seu aplicativo a partir de 100 instâncias t1.micro provavelmente não funcionará muito bem. Dividir seu aplicativo em muitas instâncias menores significa que você estará mais resistente a falhas em uma das máquinas. Se você estiver executando apenas duas máquinas de cluster de computação massivas e uma delas falhar, as coisas ficarão ruins.
