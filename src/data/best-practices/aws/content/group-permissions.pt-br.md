# Permissões de grupo

> Atribua permissões a grupos, não a usuários.

Gerenciar usuários pode ser uma tarefa difícil, se você estiver usando o Active Directory ou algum outro mecanismo de autenticação externo integrado ao IAM, isso provavelmente não importará tanto (ou talvez importe mais). Mas achei muito mais fácil gerenciar permissões atribuindo-as apenas a grupos, em vez de a usuários individuais. É muito mais fácil controlar as permissões e obter uma visão geral do sistema do que examinar cada usuário individual para ver quais permissões foram atribuídas.
