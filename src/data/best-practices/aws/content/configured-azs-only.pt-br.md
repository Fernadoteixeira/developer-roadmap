# AZs configuradas

> Use apenas as zonas de disponibilidade (AZs) para as quais seu ELB está configurado.

Se você adicionar seu grupo de escalabilidade a várias AZs, certifique-se de que seu ELB esteja configurado para usar todas essas AZs, caso contrário, sua capacidade aumentará e o balanceador de carga não poderá vê-las.
