# Ferramentas para registros

> Possui ferramentas para visualizar logs de aplicativos.

Você deve ter uma ferramenta administrativa, visualizador de syslog ou algo que permita visualizar informações de log atuais em tempo real sem precisar fazer SSH em uma instância em execução. Se você possui logs centralizados (o que realmente deveria), então você só quer ter certeza de que pode ler os logs sem precisar usar SSH. A necessidade de usar SSH em uma instância de aplicativo em execução para visualizar logs se tornará problemática.
