# Métricas personalizadas

> Use métricas personalizadas.

Se quiser monitorar itens não cobertos pelas métricas gratuitas, você pode enviar suas próprias informações métricas para o CloudWatch e usar alarmes e recursos gráficos. Isso pode ser usado não apenas para rastrear o uso do espaço em disco, mas também para métricas personalizadas de aplicativos. A página da AWS sobre [publicação de métricas personalizadas](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/publishingMetrics.html) tem mais informações.
