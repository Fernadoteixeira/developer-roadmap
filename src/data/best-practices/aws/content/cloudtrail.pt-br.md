# CloudTrail

> Use o CloudTrail para manter um log de auditoria.

O CloudTrail registrará qualquer ação executada por meio das APIs ou do console da web em um bucket S3. Configure o bucket com controle de versão para garantir que ninguém possa modificar seus logs e você terá uma trilha de auditoria completa de todas as alterações em sua conta. Você espera nunca precisar usar isso, mas vale a pena tê-lo quando precisar.
